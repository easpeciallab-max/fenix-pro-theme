Spread, Commission และ Slippage เป็นส่วนหนึ่งของผลตอบแทน ไม่ใช่รายละเอียดเล็ก ๆ ที่ใส่ภายหลัง EA ที่มี Gross Edge ต่ำหรือเทรดถี่อาจดูมีกำไรใน Backtest แบบต้นทุนอุดมคติ แต่กลายเป็นติดลบเมื่อใช้ Bid/Ask จริงและหักค่าธรรมเนียมครบ

ก่อนเปรียบเทียบ EA หรือ Preset ต้องทำต้นทุนใน Tester ให้สอดคล้องกับบัญชีเป้าหมาย และทำ Stress Test มากกว่าหนึ่งระดับ เพราะค่าใช้จ่ายจริงเปลี่ยนตามเวลา ข่าว Liquidity, Symbol และขนาด Order

สารบัญ

  • ต้นทุนแต่ละชนิด
  • Spread ใน Real/Generated Ticks
  • ตั้ง Commission ให้ถูกหน่วย
  • Slippage และ Delay
  • วิธีทำ Cost Stress Test
  • อ่านผลว่าระบบเปราะหรือไม่

ต้นทุนที่ Backtest ควรครอบคลุม

  • Spread: ส่วนต่าง Bid/Ask ที่เกิดทุกการเข้าออก
  • Commission: ค่าธรรมเนียมตาม Lot, Deal หรือ Turnover
  • Swap/Financing: ค่าใช้จ่าย/เครดิตเมื่อถือข้ามวันตามเงื่อนไข Symbol
  • Slippage: ราคาที่ Fill ต่างจากราคาคาด
  • Execution Delay: เวลาระหว่างส่ง Request และ Process
  • Requote/Reject: คำสั่งไม่ Fill ในเงื่อนไขบางประเภท
  • Currency Conversion: การแปลงกำไร/Commission/Margin เป็นสกุลบัญชี

นอกจากนี้ยังมีต้นทุนภายนอกเช่น VPS, License หรือค่า Data แต่ไม่อยู่ใน Trade Report โดยตรง ควรรวมเมื่อตัดสินความคุ้มค่าระดับธุรกิจ

Spread ถูกคิดอย่างไร

คำสั่ง Buy เปิดที่ Ask ปิดที่ Bid ส่วน Sell เปิดที่ Bid ปิดที่ Ask ดังนั้นแม้กราฟแสดง Bid EA จะเริ่มติดลบประมาณ Spread เมื่อเปิด Position (ก่อน Commission/Slippage)

ใน MT5:

  • Real Ticks สามารถสะท้อน Spread ที่เปลี่ยนใน Tick History
  • Every Tick ที่สร้างจาก M1 ใช้ Ask = Bid + Spread ของ Minute Bar ตามกฎแพลตฟอร์ม
  • Fixed/Custom Specification ใช้ทดสอบ Scenario ที่กำหนดเองได้

ค่าเฉลี่ย Spread ทั้งวันไม่เหมาะกับ EA ที่เทรดเฉพาะ Rollover หรือข่าว ควรวัด Distribution ใน Session เดียวกับกลยุทธ์และทดสอบ Tail เช่น Percentile สูง ไม่ใช้ Minimum Spread จากหน้าโฆษณา

รายละเอียด Tick อ่านที่ Every Tick Based on Real Ticks

ตั้ง Commission ให้ถูกหน่วย

โบรกเกอร์อาจเสนอ Commission เป็นเงินต่อ Lot ต่อ Side, Round Turn, ต่อ Million หรือ Percent ของ Turnover หากตีความผิดสองเท่า Report จะผิดทันที

ก่อนกรอกให้จด:

  • สกุลเงินของ Commission
  • คิดต่อ Lot หรือ Notional/Turnover
  • คิดตอน Entry, Exit หรือทั้งคู่
  • Minimum Fee ต่อ Deal หรือไม่
  • Tier เปลี่ยนตาม Volume หรือไม่
  • Symbol บางกลุ่มใช้อัตราต่างกันหรือไม่

MT5 Advanced Testing Settings รองรับ Commission หลายรูปแบบและสามารถใช้ Predefined Commission ของบัญชีปัจจุบันได้ แต่ต้องตรวจว่า Server ส่งข้อมูลครบและตรงกับประเภทบัญชีจริง ไม่สมมติว่าเลือก Checkbox แล้วถูกทุกกรณี

Slippage กับ Execution Delay ต่างกันอย่างไร

Delay คือเวลาที่ผ่านไประหว่างส่ง Request กับ Execution Process ส่วน Slippage คือส่วนต่างราคา ผลของ Delay อาจนำไปสู่ Slippage แต่ไม่ใช่สิ่งเดียวกัน เพราะ Liquidity และ Execution Policy ก็มีผล

Strategy Tester มี No Delay, Fixed Delay และ Random Delay เอกสาร MT5 ระบุว่า Delay ใช้กับ Action ที่ EA ส่ง เช่นวาง Order หรือแก้ Stop ส่วน Pending Order ที่ถูก Trigger บน Server ไม่ได้เพิ่ม Network Delay แบบเดียวกับตอนวาง

การใช้ No Delay เหมาะกับ Debug “Ideal Case” ไม่ควรเป็น Report ตัดสิน Production เพียงรอบเดียว ทำอย่างน้อย:

  1. Baseline ด้วย Delay ใกล้ Ping จริง
  2. Stress ด้วย Delay สูงขึ้น
  3. เพิ่ม Spread/Commission แยกเพื่อหาตัวแปรหลัก
  4. สุ่ม Slippage ทั้งบวก/ลบตามข้อมูลจริงหากเครื่องมือรองรับ
  5. ตรวจ Reject/Requote Handling ใน EA

ตัวอย่าง Cost Stress Matrix

Scenario Spread Commission Delay
Ideal Debug ต่ำ/คงที่ จริง No Delay
Baseline Median/Real Ticks จริง ใกล้ Ping จริง
Busy Market Percentile สูง จริง สูงขึ้น
Adverse สูงกว่าปกติ จริง + Safety Buffer Random/Fixed สูง

ตัวเลขต้องมาจากบัญชี/ข้อมูลของคุณ ไม่ใช้ค่าตายตัวจากบทความทั่วไป เป้าหมายคือดู Curve ของผลลัพธ์เมื่อ Cost เพิ่ม ไม่ใช่หาค่า Scenario เดียวที่ EA ผ่าน

สัญญาณว่าระบบไวต่อต้นทุนเกินไป

  • Profit Factor ลดต่ำกว่า 1 เมื่อเพิ่ม Spread เล็กน้อย
  • Average Trade ใกล้หรือต่ำกว่าต้นทุนรวม
  • กำไรส่วนใหญ่มาจาก Fill ที่ดีผิดปกติ
  • ผล Real Ticks ต่างจาก Open Prices มาก
  • Trade Frequency สูงแต่ Gross Edge ต่อ Trade บาง
  • เปลี่ยน Broker/Server แล้ว Distribution เปลี่ยนมาก
  • Delay ทำให้ Stop/Entry คลาดจนกลยุทธ์เปลี่ยน

ไม่ควรแก้ด้วยการเพิ่ม Lot เพราะ Lot ขยายทั้งกำไรและขาดทุน แต่ไม่เพิ่ม Edge ต่อหน่วยต้นทุน การลดจำนวน Trade หรือปรับตรรกะให้มี Margin ต่อ Cost มากขึ้นเป็นคนละเรื่องกับ Position Sizing

เปรียบเทียบเงื่อนไขโบรกเกอร์ที่ เลือกโบรกเกอร์สำหรับ EA และบันทึกการทดสอบตาม วิธี Backtest EA บน MT5

คำเตือนความเสี่ยง: ต้นทุนและ Execution เปลี่ยนได้ตามสภาพตลาด Backtest ที่รวมค่าเฉลี่ยแล้วก็ยังประเมิน Tail Event ต่ำกว่าจริงได้ ผลในอดีตไม่รับประกันผลในอนาคต
