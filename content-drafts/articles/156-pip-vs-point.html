point คือหน่วยที่เล็กที่สุดที่ราคาขยับได้ตามจำนวนทศนิยมของสัญลักษณ์นั้น ส่วน pip เป็นหน่วยนับตามธรรมเนียมของตลาดค่าเงิน ซึ่งบนกราฟคู่เงินที่มีทศนิยม 5 ตำแหน่ง 1 pip จะเท่ากับ 10 point พอดี ความสับสนเกือบทั้งหมดเกิดจากการหยิบเลขที่แพลตฟอร์มรายงานเป็น point ไปอ่านเป็น pip แล้วตัวเลขจึงผิดไปสิบเท่าตั้งแต่ต้น

เรื่องนี้ไม่ใช่การเล่นคำ เพราะช่องกรอกของระบบอัตโนมัติเกือบทุกตัวรับค่าเป็น point ไม่ใช่ pip ถ้ากรอกเลขที่คิดมาเป็น pip ลงไปตรง ๆ ระยะที่ได้จะสั้นกว่าที่ตั้งใจสิบเท่า และขนาดไม้ที่คำนวณจากระยะนั้นก็จะใหญ่กว่าที่ควรเป็นสิบเท่าตามไปด้วย วิธีคิดขนาดไม้จากระยะหยุดขาดทุนและทุนที่มีอยู่ที่ คำนวณ lot size ยังไงให้เหมาะกับทุน บทความนี้ทำหน้าที่แค่อย่างเดียวคือทำให้หน่วยที่ใช้คุยกันตรงกันก่อน

point คือหน่วยของทศนิยมตัวสุดท้าย

คำว่า point ในแพลตฟอร์มมีความหมายตรงตัวและตรวจได้ คู่มือหน้าสเปกสัญลักษณ์ของ MetaTrader 5 อธิบายช่อง Digits ว่าเป็นจำนวนตำแหน่งทศนิยมในราคาของสัญลักษณ์นั้น และเอกสารฝั่งโปรแกรมของ MQL5 ก็มีค่าคู่กันสองตัว คือ SYMBOL_DIGITS ที่หมายถึงจำนวนหลักหลังจุดทศนิยม และ SYMBOL_POINT ที่หมายถึงค่าของหนึ่ง point ของสัญลักษณ์

พูดแบบใช้งานได้คือ หนึ่ง point เท่ากับการขยับของเลขหลักสุดท้ายของราคาไปหนึ่งขั้น ถ้าราคาแสดงทศนิยม 5 ตำแหน่ง หนึ่ง point คือ 0.00001 ถ้าแสดงทศนิยม 3 ตำแหน่ง หนึ่ง point คือ 0.001 และถ้าแสดงทศนิยม 2 ตำแหน่ง หนึ่ง point คือ 0.01 ค่านี้ไม่ใช่ธรรมเนียมที่ใครตีความเอง มันถูกตั้งไว้ในสเปกของสัญลักษณ์และอ่านออกมาได้ตรง ๆ

มีอีกค่าหนึ่งที่อยู่ใกล้กันและคนมักสลับกับ point คือ Tick size ซึ่งคู่มือเรียกว่าขั้นการเปลี่ยนแปลงราคาที่น้อยที่สุด และเอกสาร MQL5 เรียก SYMBOL_TRADE_TICK_SIZE ว่าการเปลี่ยนแปลงราคาที่น้อยที่สุด สองค่านี้มักเท่ากันในคู่เงินทั่วไป แต่ไม่จำเป็นต้องเท่ากันเสมอ สินทรัพย์บางประเภทตั้งขั้นราคาให้ใหญ่กว่าหนึ่งหลักทศนิยมสุดท้าย เวลาเจอกรณีแบบนั้น ตัวเลขที่ใช้คำนวณระยะจริงคือ Tick size ไม่ใช่ point

pip คือหน่วยนับตามธรรมเนียม ไม่ใช่ค่าที่โปรแกรมตั้งไว้

ต่างจาก point คำว่า pip ไม่มีช่องในสเปกสัญลักษณ์ ไม่มีค่าคงที่ในเอกสารโปรแกรม และไม่มีปุ่มไหนในแพลตฟอร์มที่ตั้งค่ามันได้ มันเป็นหน่วยที่คนในตลาดค่าเงินใช้คุยกันมาก่อนที่ราคาจะแสดงทศนิยมละเอียดอย่างทุกวันนี้ สมัยที่ราคาคู่เงินทั่วไปแสดงแค่ทศนิยม 4 ตำแหน่ง หน่วยที่เล็กที่สุดที่ขยับได้ก็คือหลักที่สี่ และคนเรียกหลักนั้นว่า pip

เมื่อแพลตฟอร์มเพิ่มความละเอียดของราคาขึ้นมาอีกหนึ่งหลัก เป็นทศนิยม 5 ตำแหน่งสำหรับคู่เงินทั่วไป หน่วยที่เล็กที่สุดที่ขยับได้เลื่อนลงไปเป็นหลักที่ห้า แต่ธรรมเนียมการเรียก pip ยังค้างอยู่ที่หลักที่สี่เหมือนเดิม ผลคือหนึ่ง pip กลายเป็นสิบเท่าของหนึ่ง point บนสัญลักษณ์เหล่านั้น และนี่คือต้นตอของตัวเลขคลาดสิบเท่าที่เจอกันบ่อยที่สุด

เพราะเหตุนี้ pip จึงเป็นหน่วยที่ต้องถามต่อว่าหมายถึงเท่าไร ส่วน point เป็นหน่วยที่ตอบได้ด้วยการเปิดสเปกดู เวลาอ่านบทความ ดูวิดีโอ หรือคุยกับคนอื่นเรื่องระยะ นิสัยที่ปลอดภัยที่สุดคือแปลงทุกอย่างกลับมาเป็นราคาจริงก่อน เช่นแทนที่จะจำว่า 20 ให้จำว่า 0.00020 แล้วค่อยเทียบกับสเปกของสัญลักษณ์ที่กำลังจะใช้ ศัพท์อื่นที่คนใช้สลับกันแบบเดียวกันนี้รวมไว้ที่ คำศัพท์บอทเทรดและ forex ที่มือใหม่ต้องรู้

ทศนิยม 4 กับ 5 ตำแหน่ง และ 2 กับ 3 ตำแหน่ง

กรณีที่เจอจริงมีไม่กี่แบบ และแยกออกจากกันด้วยช่อง Digits ในสเปกเท่านั้น คู่เงินที่ไม่มีเยนญี่ปุ่นอยู่ด้วยมักตั้งไว้ที่ 4 หรือ 5 ตำแหน่ง ส่วนคู่ที่มีเยนอยู่ด้วยมักตั้งไว้ที่ 2 หรือ 3 ตำแหน่ง เหตุผลคือระดับราคาของเยนอยู่ในหลักสิบถึงหลักร้อย ขณะที่คู่เงินทั่วไปอยู่ราวหนึ่งหน่วย จำนวนหลักที่ให้ความละเอียดใกล้เคียงกันจึงต่างกันสองตำแหน่ง

ตารางข้างล่างสรุปความสัมพันธ์ของทั้งสี่กรณี ตัวเลขในตารางเป็นผลของนิยามล้วน ๆ ไม่ใช่ค่าของสัญลักษณ์ใดโดยเฉพาะ ให้เทียบกับช่อง Digits ที่อ่านได้จากสเปกจริงก่อนใช้

Digits ในสเปก 1 point เท่ากับ 1 pip ตามธรรมเนียม 1 pip คิดเป็น point
4 ตำแหน่ง 0.0001 0.0001 1 point
5 ตำแหน่ง 0.00001 0.0001 10 point
2 ตำแหน่ง 0.01 0.01 1 point
3 ตำแหน่ง 0.001 0.01 10 point

สังเกตว่ากรณีที่ pip เท่ากับ point พอดีก็มีอยู่ นั่นคือเมื่อสเปกตั้งทศนิยมไว้เท่ากับหลักที่ธรรมเนียมเรียกว่า pip อยู่แล้ว ปัญหาคือเราไม่รู้ว่าสัญลักษณ์ตรงหน้าเป็นแบบไหนจนกว่าจะเปิดดู และสัญลักษณ์ของสินทรัพย์เดียวกันที่มีตัวต่อท้ายต่างกันก็อาจตั้งสเปกไม่เหมือนกันได้ เรื่องตัวต่อท้ายของชื่อสัญลักษณ์อยู่ที่ ชื่อสินค้าใน MT5 ลงท้าย .c .s .m คืออะไร

ทองกับคู่เงินนับไม่เหมือนกัน

ทองเป็นจุดที่คำว่า pip พังที่สุด เพราะมันไม่ใช่คู่เงินและไม่มีธรรมเนียมกลางที่ทุกคนยอมรับเหมือนกัน ในวงสนทนาเดียวกันจะเจอคนที่นับการขยับ 0.01 ดอลลาร์ว่าหนึ่ง pip คนที่นับ 0.1 ดอลลาร์ว่าหนึ่ง pip และคนที่นับ 1 ดอลลาร์เต็มว่าหนึ่ง pip ทั้งสามแบบมีคนใช้จริง และไม่มีแบบไหนผิดในเชิงภาษา สิ่งที่ผิดคือการสมมติว่าอีกฝ่ายนับแบบเดียวกับเรา

ทางออกที่ใช้ได้กับทองมีสองทาง ทางแรกคือเลิกใช้คำว่า pip กับทองไปเลย แล้วคุยด้วย point ตามสเปกหรือคุยด้วยราคาจริงเป็นดอลลาร์ เช่นพูดว่าระยะหยุดขาดทุนห่างจากราคาเข้า 5 ดอลลาร์ ซึ่งไม่ต้องตีความอะไรเพิ่ม ทางที่สองคือเวลาคัดลอกค่ามาจากแหล่งอื่น ให้ถามหรือหาให้แน่ก่อนว่าเลขนั้นนับบนฐานอะไร แล้วแปลงเป็นราคาจริงก่อนกรอกลงช่อง

ความต่างของหน่วยยังลากไปถึงมูลค่าต่อการขยับหนึ่งขั้นด้วย เพราะทองมีขนาดสัญญาต่อหนึ่งล็อตไม่เท่ากับคู่เงิน การคิดมูลค่าต่อจุดและขนาดไม้ของทองจึงต้องเริ่มจากสเปกของทองเอง ไม่ใช่เอาสูตรของคู่เงินมาใช้ซ้ำ รายละเอียดเฉพาะของทองอยู่ที่ คำนวณ lot size ทอง XAUUSD ยังไง ทอง 1 lot เท่ากับเท่าไร

ถ้าคัดค่าระยะหยุดขาดทุน ระยะกริด หรือระยะเลื่อนจุดคุ้มทุนมาจากบทความหรือคลิปที่ไม่ได้บอกว่านับเป็น point หรือ pip ให้ถือว่าค่านั้นยังใช้ไม่ได้จนกว่าจะแปลงกลับเป็นราคาจริงและเทียบกับสเปกของสัญลักษณ์ที่จะใช้ การกรอกเลขผิดหน่วยสิบเท่าไม่ได้ทำให้โปรแกรมเตือนอะไร มันทำงานตามเลขที่ได้รับอย่างซื่อสัตย์

ทำไมสเปรด 20 point ไม่ได้แปลว่า 20 pip

คู่มือหน้าสเปกสัญลักษณ์ของ MetaTrader 5 เขียนช่องสเปรดไว้ตรง ๆ ว่าเป็นสเปรดในหน่วย point และเอกสาร MQL5 ก็นิยาม SYMBOL_SPREAD ว่าเป็นค่าสเปรดในหน่วย point เหมือนกัน นั่นหมายความว่าเลขสเปรดที่แพลตฟอร์มแสดงให้เห็นเป็นหน่วย point เสมอ ไม่ใช่ pip

ตัวอย่างสมมติเพื่อให้เห็นภาพ ถ้าสัญลักษณ์หนึ่งตั้ง Digits ไว้ 5 ตำแหน่ง และแพลตฟอร์มรายงานสเปรด 20 ค่านั้นคือ 20 point ซึ่งเท่ากับราคาต่างกัน 0.00020 และเท่ากับ 2 pip ตามธรรมเนียม ไม่ใช่ 20 pip คนที่อ่านผิดจะสรุปว่าต้นทุนการเข้าออกแพงกว่าความจริงสิบเท่า แล้วตัดสินใจเรื่องบัญชีหรือเรื่องระยะทำกำไรบนตัวเลขที่ผิด

ความผิดนี้ไปได้ทั้งสองทาง บางคนอ่านเลข point เป็น pip แล้วตกใจว่าสเปรดกว้างเกินไป บางคนได้ยินว่าสเปรด 2 pip แล้วไปกรอกเลข 2 ลงในช่องที่รับค่าเป็น point ซึ่งกลายเป็นหนึ่งในสิบของค่าที่ตั้งใจ ทั้งสองกรณีมาจากรากเดียวกันคือไม่ได้ตรวจว่าเลขที่ถืออยู่เป็นหน่วยอะไร

อีกเรื่องที่ต้องแยกให้ออกคือสเปรดไม่ใช่ค่าคงที่ตลอดวัน ตัวเลขที่เห็นตอนตลาดเงียบกับตอนข่าวออกไม่เท่ากัน และช่วงที่สเปรดกว้างขึ้นมีผลกับระบบที่ใช้ระยะสั้นมากกว่าระบบที่ใช้ระยะยาว ถ้าระบบที่ใช้เปิดไม้ถี่และกินระยะสั้น การนับหน่วยผิดจะยิ่งเห็นผลเร็ว เพราะต้นทุนต่อรอบกินสัดส่วนของระยะทำกำไรมากกว่า

วิธีอ่านค่าจากสเปกสัญลักษณ์

ค่าที่ต้องการทั้งหมดอยู่ในหน้าต่างสเปกของสัญลักษณ์ ซึ่งเปิดได้จากรายการราคาในแพลตฟอร์ม คู่มือหน้านั้นไล่ช่องไว้ยาว แต่ช่องที่เกี่ยวกับการนับหน่วยมีไม่กี่ช่อง

ช่องแรกคือ Digits ซึ่งบอกจำนวนตำแหน่งทศนิยมของราคา ค่านี้บอกขนาดของหนึ่ง point ทันที ช่องที่สองคือ Tick size ซึ่งคู่มือเรียกว่าขั้นการเปลี่ยนแปลงราคาที่น้อยที่สุด ถ้าค่านี้ใหญ่กว่าขนาดของหนึ่ง point แปลว่าราคาขยับทีละหลายหลักสุดท้าย ไม่ใช่ทีละหนึ่ง ช่องที่สามคือ Tick value ซึ่งเป็นต้นทุนหรือรายได้ต่อการขยับหนึ่งขั้น ช่องนี้คือสะพานไปสู่การคิดเป็นเงิน

ช่องที่สี่คือ Contract size ซึ่งคู่มือนิยามว่าจำนวนหน่วยของสินค้า สกุลเงิน หรือสินทรัพย์ทางการเงินในหนึ่งล็อต ค่านี้จำเป็นเวลาคิดมูลค่าต่อจุดด้วยมือ และช่องที่ห้ากับหกคือ Margin currency และ Profit currency ซึ่งบอกว่าผลกำไรขาดทุนของสัญลักษณ์นั้นออกมาเป็นสกุลเงินอะไร ถ้าสกุลนั้นไม่ตรงกับสกุลเงินบัญชี จะมีการแปลงค่าเพิ่มอีกชั้น

ขั้นตอนตรวจที่เร็วที่สุดมีสามขั้น ขั้นแรกเปิดสเปกของสัญลักษณ์ที่จะใช้จริง ไม่ใช่สัญลักษณ์ที่ชื่อคล้ายกัน ขั้นที่สองอ่าน Digits แล้วเขียนขนาดของหนึ่ง point ลงไว้เป็นตัวเลขราคา ขั้นที่สามเอาค่าทุกค่าที่จะกรอกลงช่องของระบบมาแปลงเป็นหน่วยเดียวกับที่ช่องนั้นรับ แล้วอ่านทวนอีกครั้งว่าจำนวนศูนย์ครบ ถ้าอยากข้ามการคิดด้วยมือ ใส่ค่าลงใน เครื่องคำนวณขนาดล็อต แล้วเทียบผลกับที่คิดไว้ก็ได้

จุดที่การนับผิดทำให้ตั้งค่าพัง

ผลของการนับผิดไม่ได้หยุดอยู่ที่ความเข้าใจ มันลงไปถึงตัวเลขที่ระบบใช้ทำงานจริง จุดแรกคือระยะหยุดขาดทุน ถ้าตั้งใจให้ห่าง 30 pip แต่กรอกเลข 30 ลงช่องที่รับ point บนสัญลักษณ์ทศนิยม 5 ตำแหน่ง ระยะที่ได้คือ 3 pip ซึ่งใกล้ราคาเข้ามากจนความผันผวนปกติก็ชนได้

จุดที่สองคือขนาดไม้ เพราะการคิดขนาดไม้ตามความเสี่ยงต่อไม้ใช้ระยะหยุดขาดทุนเป็นตัวหาร ถ้าระยะที่ใส่เข้าไปเล็กกว่าความจริงสิบเท่า ขนาดไม้ที่ได้จะใหญ่กว่าที่ควรเป็นสิบเท่า ความเสี่ยงต่อไม้ที่คิดว่าตั้งไว้หนึ่งเปอร์เซ็นต์จะกลายเป็นสิบเปอร์เซ็นต์โดยไม่มีใครบอก กรอบการตั้งความเสี่ยงต่อไม้อยู่ที่ ความเสี่ยงต่อไม้ ตั้งกี่เปอร์เซ็นต์ดีเมื่อใช้บอทเทรด

จุดที่สามคือระยะห่างระหว่างไม้ของระบบที่เปิดหลายไม้ ระยะที่สั้นกว่าที่ตั้งใจสิบเท่าทำให้ไม้ถูกเปิดถี่กว่าที่ออกแบบไว้มาก มาร์จิ้นที่ถูกกันไว้จึงโตเร็วกว่าที่คาด และจุดที่สี่คือการเปรียบเทียบผลทดสอบ ถ้าค่าที่ใช้ตอนทดสอบกับค่าที่ใช้ตอนรันจริงนับหน่วยไม่เหมือนกัน ผลสองชุดนั้นเทียบกันไม่ได้เลย

วิธีกันพลาดที่ถูกที่สุดคือเขียนหน่วยกำกับไว้ข้างตัวเลขทุกครั้งที่จดอะไรลงกระดาษหรือลงไฟล์ และเวลาส่งค่าให้คนอื่นก็ส่งเป็นราคาจริงพร้อมชื่อสัญลักษณ์ ไม่ส่งเป็นเลขเปล่า ถ้ากำลังเตรียมตั้งค่าระบบของเราให้เริ่มใช้งาน ขั้นตอนและไฟล์อยู่ที่ หน้าเริ่มใช้งานและดาวน์โหลด

สรุป

สรุป: point เป็นหน่วยของแพลตฟอร์ม เท่ากับการขยับหนึ่งขั้นของเลขทศนิยมหลักสุดท้ายตามช่อง Digits ในสเปกสัญลักษณ์ ซึ่งคู่มือนิยามว่าจำนวนตำแหน่งทศนิยมในราคา ส่วน pip เป็นหน่วยนับตามธรรมเนียมของตลาดค่าเงินที่ค้างอยู่ที่หลักที่สี่ของคู่เงินทั่วไป ผลคือบนสัญลักษณ์ที่ตั้งทศนิยม 5 ตำแหน่ง 1 pip เท่ากับ 10 point และบนคู่ที่มีเยนซึ่งตั้งทศนิยม 3 ตำแหน่ง 1 pip ก็เท่ากับ 10 point เหมือนกัน ขณะที่สัญลักษณ์ที่ตั้งทศนิยม 4 หรือ 2 ตำแหน่งจะมี 1 pip เท่ากับ 1 point พอดี ทองไม่มีธรรมเนียม pip ที่เป็นมาตรฐานกลาง มีทั้งคนนับ 0.01 0.1 และ 1 ดอลลาร์ จึงควรคุยด้วย point ตามสเปกหรือคุยด้วยราคาจริงแทน เลขสเปรดที่แพลตฟอร์มแสดงเป็นหน่วย point ตามที่คู่มือและเอกสาร MQL5 ระบุไว้ทั้งสองที่ ดังนั้นสเปรด 20 บนสัญลักษณ์ทศนิยม 5 ตำแหน่งคือ 2 pip ไม่ใช่ 20 pip ค่าที่ต้องอ่านจากสเปกเพื่อไม่ให้พลาดมีห้าช่อง คือ Digits, Tick size, Tick value, Contract size และสกุลเงินของมาร์จิ้นกับกำไร นิสัยที่ลดความผิดพลาดได้มากที่สุดคือแปลงทุกค่าเป็นราคาจริงก่อนกรอก และเขียนหน่วยกำกับไว้ข้างตัวเลขทุกครั้ง

คำเตือนความเสี่ยง: การเทรดด้วยมาร์จิ้นมีความเสี่ยงสูงและอาจทำให้สูญเงินลงทุนทั้งจำนวน การนับหน่วยให้ถูกเป็นเพียงการป้องกันความผิดพลาดด้านการตั้งค่า ไม่ได้ลดความเสี่ยงของตลาดลง และไม่ได้ทำให้ผลลัพธ์ดีขึ้นด้วยตัวมันเอง ตัวเลขทุกชุดในบทความนี้เป็นตัวอย่างสมมติที่ใช้อธิบายความสัมพันธ์ของหน่วยเท่านั้น ค่าจริงของแต่ละสัญลักษณ์และแต่ละบัญชีต่างกัน ต้องเปิดสเปกดูเอง เนื้อหานี้เป็นข้อมูลทั่วไปเกี่ยวกับการใช้งานโปรแกรมและการนับหน่วยราคา ไม่ใช่คำแนะนำการลงทุน ใช้เฉพาะเงินที่พร้อมรับความเสียหายและไม่มีกำหนดต้องใช้ อ่าน คำเตือนความเสี่ยงฉบับเต็ม

คำถามที่พบบ่อย

pip คืออะไร สรุปสั้น ๆ

pip คือหน่วยนับการเปลี่ยนแปลงราคาตามธรรมเนียมของตลาดค่าเงิน โดยยึดที่หลักทศนิยมที่สี่ของคู่เงินทั่วไป และหลักที่สองของคู่ที่มีเยนญี่ปุ่น มันไม่ใช่ค่าที่ตั้งอยู่ในแพลตฟอร์ม จึงต้องเทียบกับจำนวนทศนิยมจริงของสัญลักษณ์ก่อนใช้

1 pip เท่ากับกี่ point

ขึ้นกับช่อง Digits ของสัญลักษณ์นั้น ถ้าตั้งไว้ 5 หรือ 3 ตำแหน่ง 1 pip เท่ากับ 10 point ถ้าตั้งไว้ 4 หรือ 2 ตำแหน่ง 1 pip เท่ากับ 1 point วิธีตรวจที่แน่นอนคือเปิดสเปกของสัญลักษณ์ที่จะใช้จริงแล้วอ่านค่า Digits

ช่องตั้งค่าของระบบอัตโนมัติรับค่าเป็น pip หรือ point

ส่วนมากรับเป็น point เพราะเป็นหน่วยเดียวกับที่โปรแกรมใช้ภายใน แต่ไม่ใช่ทุกตัว บางระบบเขียนหน่วยกำกับไว้ที่ชื่อช่องหรือในเอกสาร ถ้าไม่มีกำกับ ให้ทดลองตั้งค่าบนบัญชีทดลองแล้วดูระยะที่เกิดขึ้นจริงบนกราฟก่อน

ทองนับ pip ยังไงให้ถูก

ไม่มีคำตอบเดียวที่ถูก เพราะทองไม่มีธรรมเนียมกลาง วิธีที่ไม่พลาดคือเลิกใช้คำว่า pip กับทอง แล้วคุยด้วย point ตามสเปกหรือคุยด้วยราคาจริงเป็นดอลลาร์ เช่นบอกว่าห่างจากราคาเข้า 5 ดอลลาร์

สเปรดที่เห็นในแพลตฟอร์มเป็นหน่วยอะไร

เป็น point คู่มือหน้าสเปกสัญลักษณ์เขียนช่องสเปรดว่าเป็นสเปรดในหน่วย point และเอกสาร MQL5 นิยาม SYMBOL_SPREAD ว่าเป็นค่าสเปรดในหน่วย point เช่นกัน ถ้าจะแปลงเป็น pip ต้องหารด้วยจำนวน point ต่อหนึ่ง pip ของสัญลักษณ์นั้น
