ไฟล์ EX5 คือไฟล์โปรแกรมที่คอมไพล์แล้วสำหรับ MetaTrader 5 และเป็นไฟล์ที่แพลตฟอร์มเรียกใช้เมื่อติดตั้ง EA, Indicator หรือ Script ส่วนไฟล์ MQ5 คือ Source Code ภาษา MQL5 ที่มนุษย์สามารถเปิดอ่านและแก้ไขใน MetaEditor ได้ หากคอมไพล์ MQ5 สำเร็จ ระบบจะสร้าง EX5 สำหรับนำไปรัน

ผู้ใช้ EA ทั่วไปมักได้รับเพียงไฟล์ EX5 ซึ่งเพียงพอสำหรับการใช้งาน หากผู้ขายไม่ได้ให้ Source Code นั่นไม่ได้แปลว่าไฟล์เสีย แต่ผู้ใช้จะไม่สามารถแก้ตรรกะหรือคอมไพล์เวอร์ชันใหม่ด้วยตนเอง ต้องพึ่งการอัปเดตจากผู้พัฒนาและปฏิบัติตาม License ที่กำหนด

สารบัญ

  • EX5 กับ MQ5 ต่างกันอย่างไร
  • ต้องวางไฟล์ไว้ที่ไหน
  • วิธีติดตั้งทีละขั้นตอน
  • ไฟล์ไม่แสดงใน Navigator แก้อย่างไร
  • Library และไฟล์ประกอบ
  • ความปลอดภัยและการสำรอง

EX5 กับ MQ5 ต่างกันอย่างไร

หัวข้อ EX5 MQ5
สถานะไฟล์ Executable ที่คอมไพล์แล้ว Source Code ภาษา MQL5
เปิดอ่านตรรกะ ไม่ได้ออกแบบให้เปิดอ่านหรือแก้ไข เปิดและแก้ไขผ่าน MetaEditor ได้เมื่อมีสิทธิ์
ใช้งานบนกราฟ นำไปรันบน MT5 ได้ ต้อง Compile ให้ได้ EX5 ก่อน
การส่งต่อ ขึ้นกับ License ของผู้พัฒนา Source Code มีทรัพย์สินทางปัญญาและเงื่อนไขใช้งาน

อย่าสับสน EX5 กับ EX4 เพราะ EX4 สร้างสำหรับ MetaTrader 4 การเปลี่ยนชื่อ `.ex4` เป็น `.ex5` ไม่ทำให้ไฟล์ทำงานบน MT5 หากระบบรองรับทั้งสองแพลตฟอร์มต้องได้รับไฟล์คนละชุด

ไฟล์ EA ต้องวางไว้ที่ไหน

เอกสาร MetaTrader ระบุว่าโปรแกรมประเภท Expert Advisor อยู่ในโฟลเดอร์ MQL5\Experts ภายใน Data Folder ของ Terminal วิธีที่แม่นที่สุดคือเปิด MT5 แล้วเลือก File > Open Data Folder จากนั้นเข้า MQL5 > Experts

ไม่ควรเดาตำแหน่งจากโฟลเดอร์ Program Files เพราะในโหมดปกติ Windows จะแยกไฟล์โปรแกรมแบบอ่านอย่างเดียวออกจากข้อมูลที่แก้ไขได้ MT5 แต่ละชุดอาจมี Data Folder คนละ Instance ID โดยเฉพาะเครื่องที่ติดตั้งหลาย Terminal

โฟลเดอร์ที่มักเกี่ยวข้องมีดังนี้:

  • MQL5\Experts สำหรับ EA แบบ EX5/MQ5
  • MQL5\Indicators สำหรับ Custom Indicator
  • MQL5\Libraries สำหรับ Library ที่โปรแกรมเรียกใช้
  • MQL5\Include สำหรับไฟล์ Include ที่ใช้ตอน Compile
  • MQL5\Presets สำหรับไฟล์พารามิเตอร์ SET บาง Workflow
  • MQL5\Logs สำหรับ Log ของ EA

วิธีติดตั้งไฟล์ EX5 ลง MT5

  1. ปิดหรือหยุด EA เดิมก่อน หากกำลังอัปเดตไฟล์ที่ใช้งานอยู่
  2. เปิด MT5 ชุดและบัญชีที่ต้องการใช้งาน
  3. เลือก File > Open Data Folder
  4. เข้าโฟลเดอร์ MQL5 > Experts
  5. คัดลอกไฟล์ EX5 และโฟลเดอร์ประกอบตามโครงที่ผู้พัฒนาให้มา
  6. กลับ MT5 คลิกขวาที่ Navigator แล้วเลือก Refresh หรือปิดเปิด Terminal ใหม่
  7. ตรวจว่า EA ปรากฏใต้ Expert Advisors
  8. เปิดกราฟ Symbol/Timeframe ที่คู่มือกำหนด แล้วลาก EA ลงกราฟ
  9. โหลด Preset หากมี ตรวจค่าทุกช่อง และอนุญาต Algo Trading ตามความจำเป็น
  10. ดู Experts/Journal ว่าเริ่มทำงานโดยไม่มี Error

ดูคู่มือภาพรวมได้ที่ คู่มือติดตั้ง FENIX PRO EA และ วิธีลง EA บน MT5

ถ้ามีไฟล์ MQ5 ต้องทำอย่างไร

บันทึก MQ5 ในโฟลเดอร์ให้ตรงประเภท จากนั้นเปิด MetaEditor ด้วยปุ่ม F4 เลือกไฟล์จาก Navigator และกด F7 เพื่อ Compile ตรวจแท็บ Errors ด้านล่าง หากสำเร็จ MetaEditor จะสร้าง EX5 ในตำแหน่งเดียวกันหรือโครง Build ที่เกี่ยวข้อง

Warning ไม่เท่ากับ Error แต่ไม่ควรมองข้ามโดยไม่เข้าใจ โดยเฉพาะ Warning เรื่อง Type Conversion, Loss of Data หรือการใช้ฟังก์ชันที่ล้าสมัย หากคุณไม่ใช่ผู้พัฒนา ไม่ควรแก้โค้ดสุ่มเพื่อให้ Compile ผ่าน เพราะอาจเปลี่ยนตรรกะการส่งคำสั่งและความเสี่ยง

EA ไม่แสดงใน Navigator ต้องตรวจอะไร

  1. วางผิด Data Folder: เปิด Data Folder จาก MT5 ชุดนั้นโดยตรง อย่าคัดลอกจาก Path ที่จำไว้
  2. วางผิดประเภท: EA ต้องอยู่ใน Experts ไม่ใช่ Indicators หรือ Scripts
  3. ไฟล์อยู่ใน ZIP: ต้องแตกไฟล์ก่อน MT5 ไม่อ่าน EA จาก ZIP
  4. เป็น EX4: ไฟล์ของ MT4 ไม่แสดงเป็น EA ที่ใช้งานได้บน MT5
  5. Compile ไม่ผ่าน: ถ้ามีเฉพาะ MQ5 ต้องเปิด MetaEditor ดู Error
  6. ไฟล์ถูก Antivirus กัก: ตรวจประวัติการป้องกัน แต่ไม่ควรปิดระบบรักษาความปลอดภัยแบบถาวร
  7. Navigator ยังไม่ Refresh: คลิกขวา Refresh หรือ Restart Terminal
  8. โครงโฟลเดอร์ไม่ครบ: บาง EA เรียก Library, Indicator หรือไฟล์ข้อมูลเพิ่มเติม

หากชื่อ EA แสดงแล้วแต่ลากลงกราฟไม่ได้หรือไม่ส่งคำสั่ง ปัญหาอาจไม่ใช่ไฟล์อีกต่อไป ให้ตรวจ Algo Trading, Permission, Symbol, Account และข้อความใน Experts/Journal ตามคู่มือ EA ไม่ทำงานบน MT5 แก้อย่างไร

ไฟล์ EX5 อาจต้องมีอะไรประกอบ

EA บางตัวเป็นไฟล์เดียวจบ แต่บางระบบพึ่ง Custom Indicator, Library, Image, Preset หรือข้อมูลในโฟลเดอร์ Files หากผู้พัฒนาให้ ZIP ที่มีหลายโฟลเดอร์ ต้องคงโครงสร้างเดิม ไม่รวบทุกไฟล์ไปไว้ใน Experts

ก่อนติดตั้งให้ตรวจรายการส่งมอบ:

  • ไฟล์ EA หลักและเลข Version
  • Custom Indicator หรือ Library ที่จำเป็น
  • Preset แยกตาม Symbol/Timeframe
  • คู่มือการอนุญาต DLL หรือ WebRequest หากระบบต้องใช้จริง
  • เงื่อนไข License เช่นผูกบัญชี ผูกเครื่อง หรือวันหมดอายุ
  • Checksum หรือแหล่งดาวน์โหลดทางการเมื่อผู้พัฒนามีให้

อย่าเปิด Allow DLL Imports หรือเพิ่ม URL ใน WebRequest เพียงเพราะ EA ไม่ทำงาน ต้องตรวจคู่มือและความน่าเชื่อถือของแหล่งไฟล์ก่อน เพราะ Permission เหล่านี้เพิ่มขอบเขตที่โปรแกรมเข้าถึงได้

ความปลอดภัยและการสำรองไฟล์

  • ดาวน์โหลดจากเว็บไซต์หรือช่องทางที่ผู้พัฒนายืนยัน
  • ไม่ใช้ไฟล์ Crack, Decompile หรือไฟล์ที่ถูกส่งต่อโดยไม่มีที่มา
  • เก็บไฟล์ต้นฉบับแบบ Read-only พร้อมชื่อ Version และวันที่ได้รับ
  • สำรอง Preset และบันทึกค่า Input ก่อนอัปเดต
  • ทดสอบไฟล์ใหม่บน Demo หรือสภาพแวดล้อมแยกก่อนแทนของเดิม
  • ไม่ส่ง Login, Password, License Key หรือข้อมูลส่วนตัวไปพร้อม Screenshot/Log สาธารณะ

EX5 ไม่ใช่เอกสารที่เปิดอ่านรายละเอียดกลยุทธ์ได้ ผู้ใช้จึงต้องพึ่งคู่มือ Version History และหลักฐานการทดสอบจากผู้พัฒนาเพิ่ม การมีไฟล์เพียงอย่างเดียวไม่บอกว่า EA ปลอดภัย เหมาะกับบัญชี หรือมีความเสี่ยงระดับใด

คำเตือนความเสี่ยง: การติดตั้งไฟล์สำเร็จไม่ได้รับประกันว่า EA เหมาะกับเงินทุนหรือสภาพบัญชี ควรตรวจการตั้งค่าและทดลองบน Demo ก่อนใช้เงินจริงทุกครั้ง
