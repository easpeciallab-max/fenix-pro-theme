License ของ EA คือเงื่อนไขอนุญาตให้ใช้ซอฟต์แวร์ ไม่ได้หมายความว่าผู้ซื้อเป็นเจ้าของ Source Code หรือมีสิทธิ์คัดลอก แจกต่อ และแก้ไขทุกอย่าง License อาจผูกกับ Trading Account, Broker, Device/Hardware ID, MQL5 Account, Subscription หรือ License Server ของผู้พัฒนา

ก่อนซื้อควรขอเงื่อนไขเป็นลายลักษณ์อักษร เพราะการย้าย VPS, เปลี่ยน Windows, เปลี่ยน Broker หรือ Format เครื่องอาจใช้ Activation ใหม่ แม้ผู้ใช้เป็นคนเดิม การรู้เพียงว่า “ใช้ได้ 1 License” ไม่พอ ต้องรู้ว่า 1 License วัดจากอะไร

สารบัญ

  • รูปแบบ License ที่พบบ่อย
  • Scope และ Activation ต่างกันอย่างไร
  • ย้าย VPS/บัญชีต้องทำอะไร
  • License Server และการใช้งาน Offline
  • Update, Expiry และสิทธิ์หลังหมดอายุ
  • Checklist คำถามก่อนซื้อ

รูปแบบ License ที่ต้องแยก

รูปแบบ ผูกกับอะไร ผลเมื่อเปลี่ยนระบบ
Account Lock Login/Server/Broker ที่อนุญาต เปลี่ยนบัญชีอาจต้องแก้ License
Device/Hardware Lock Hardware/OS Fingerprint ย้าย/Format/Update ใหญ่อาจเปลี่ยน ID
Activation Count จำนวน Environment ที่เปิดใช้งาน การย้ายเครื่องอาจใช้ Activation เพิ่ม
Subscription ช่วงเวลาที่ชำระ หมดอายุแล้วอาจหยุดทำงานหรือหยุด Update
Online License Server Token/Account และการตรวจผ่าน Internet Server/Network ล่มอาจกระทบการเริ่มหรือใช้งาน
Marketplace DRM บัญชี Marketplace และ Activation Rules เป็นไปตามกติกา Platform ที่ซื้อ

EA หนึ่งตัวอาจใช้หลายแบบพร้อมกัน เช่น ผูก MQL5 Account และมี Activation ต่อ Hardware หรือผูก Trading Account แล้วต้องตรวจ License Server ทุกครั้งที่เริ่ม จึงต้องขอ Diagram/ขั้นตอนจริงจากผู้ขาย

“ใช้ได้กี่เครื่อง” ไม่เท่ากับ “ใช้ได้กี่บัญชี”

ตัวอย่าง Scope ที่ต่างกัน:

  • หนึ่งเครื่อง เปิดหลาย Terminal แต่ใช้บัญชีเดียว
  • หนึ่งบัญชี เปิดได้บน Desktop และ VPS
  • หนึ่ง License ใช้ได้หนึ่ง Real Account แต่ Demo ไม่จำกัด
  • หนึ่ง Activation ผูก Windows Environment แม้มีหลายบัญชี
  • หนึ่งแพ็กเกจให้หลาย Activation แต่ห้ามใช้พร้อมกัน

ถามทั้ง Concurrent Use และ Total Activations การมี Activation ห้าครั้งอาจหมายถึงติดตั้งได้ห้า Environment ตลอดอายุ ไม่ใช่รันพร้อมกันห้าบัญชี และการลบโปรแกรมอาจไม่คืน Activation อัตโนมัติ

ย้าย VPS อย่างไรไม่ให้ EA หยุด

  1. แจ้งผู้ขาย/เปิด Ticket ก่อนย้าย พร้อม License ID ที่ไม่ใช่ Password
  2. ขอ Deactivate/Reset ตามกระบวนการ หากระบบรองรับ
  3. สำรอง Installer, EX5, Preset, Version และ Documentation
  4. ติดตั้งในเครื่องใหม่และทดสอบ Demo ก่อนตัดเครื่องเดิม
  5. ตรวจ Account/Server/Hardware Binding และ Journal
  6. ปิด Instance เก่าเพื่อป้องกัน License Conflict และออเดอร์ซ้ำ
  7. เก็บหลักฐานการย้ายและ Activation ที่เหลือ

หากผู้ขายหายหรือตอบช้า การย้ายฉุกเฉินอาจทำไม่ได้ ควรถาม SLA และ Emergency Contact ก่อนซื้อ โดยเฉพาะ EA ที่ต้องออนไลน์ตลอด

License Server เป็น Dependency ของการเทรด

ถ้า EA ต้องตรวจสิทธิ์ออนไลน์ ให้ถาม:

  • ตรวจตอน Attach/Startup เป็นรอบ หรือทุกคำสั่ง
  • เมื่อ Server ตอบไม่ได้ EA หยุด Entry ปิด Position หรือทำงานต่อช่วง Grace Period
  • Domain/IP ใดต้อง Allow ใน Firewall/WebRequest
  • มี Status Page, Redundancy และ Maintenance Notice หรือไม่
  • ข้อมูลใดถูกส่งไปตรวจ License และเก็บนานเท่าไร
  • มี Offline/Emergency Mode หรือไม่

พฤติกรรม Fail-safe ต้องชัด ระบบที่ตรวจ License ไม่ผ่านไม่ควรเปิด Position ใหม่ แต่การหยุดจัดการ Position ที่มีอยู่โดยไม่แจ้งอาจสร้างความเสี่ยง ผู้ซื้อควรรู้ Lifecycle ของ EA เมื่อ License เปลี่ยนสถานะ

ซื้อขาดอาจไม่ได้แปลว่า Update ตลอดชีพ

แยกสิทธิ์ต่อไปนี้:

  • สิทธิ์ใช้ Version ที่ซื้อแบบถาวรหรือชั่วคราว
  • สิทธิ์ดาวน์โหลดไฟล์เดิมหลัง Product ถูกถอด
  • สิทธิ์รับ Bug Fix/Critical Compatibility Update
  • สิทธิ์รับ Feature/Major Version ใหม่
  • ระยะเวลา Support และค่า Renewal

กติกาของ MQL5 Market ระบุรายละเอียดผู้ซื้อ/ผู้ขายและ Activation ตามบริการของตน แต่หากซื้อจากเว็บไซต์ผู้พัฒนา ต้องใช้ Terms ของผู้ขายนั้น ห้ามนำกติกา Marketplace หนึ่งไปสมมติว่าใช้กับการขายตรง

Source Code กับ Compiled File

ไฟล์ .ex5 เป็นไฟล์ที่ Compile สำหรับรันบน MT5 ผู้ซื้อทั่วไปอาจไม่ได้ Source .mq5 และไม่มีสิทธิ์แก้ไข/แจกต่อ การได้รับ Source เป็นข้อตกลงแยกที่ควรระบุสิทธิ์ใช้งาน ความลับ และการบำรุงรักษา ไม่ควรพยายาม Decompile หรือหลีกเลี่ยง License

Checklist ก่อนชำระเงิน

  1. License ผูก Account, Broker, Device, MQL5 Account หรืออะไร
  2. ใช้ได้กี่ Real/Demo Account และพร้อมกันกี่ Instance
  3. จำนวน Activation เท่าไร ลบ/ย้ายแล้วคืนได้หรือไม่
  4. เปลี่ยน VPS, Windows, Disk หรือ Broker ต้องทำอะไร
  5. License Server ล่ม/อินเทอร์เน็ตขาด EA ทำงานแบบใด
  6. หมด Subscription แล้ว Version เดิมยังจัดการ Position/ใช้งานได้หรือไม่
  7. Update, Bug Fix และ Support รวมถึงวันใด
  8. ผู้ขายยุติบริการ มีวิธี Exit/Migrate อย่างไร
  9. Refund ใช้กับ License ที่ Activated แล้วหรือไม่

อ่านภาพรวมที่ วิธีเลือก EA, วิธีตรวจผู้ขาย EA และตรวจแพ็กเกจจริงที่ ราคา FENIX PRO EA

สรุป: License คือข้อกำหนดสิทธิ์และ Dependency ของระบบ ผู้ซื้อควรรู้ Scope, Activation, Migration, Availability, Update และ Exit Plan ก่อนจ่ายเงิน เพื่อไม่ให้การย้าย VPS หรือเปลี่ยนบัญชีทำให้ระบบหยุดโดยไม่พร้อม

คำเตือนความเสี่ยง: License ที่ใช้งานได้ไม่ได้รับประกันความถูกต้องหรือผลกำไรของ EA ระบบ License/Network อาจขัดข้อง ควรมี Monitoring และแผนจัดการ Position การเทรดมีความเสี่ยงสูง อ่าน คำเตือนความเสี่ยงฉบับเต็ม
