หลังโหลดไฟล์มาแล้ว ลำดับที่ต้องตรวจมีหกขั้น คือที่มาของไฟล์และใครดูแลต่อ นามสกุลไฟล์กับที่วางไฟล์ สิทธิ์ที่ตัวโปรแกรมขอโดยเฉพาะช่อง DLL imports การทดสอบย้อนหลังแล้วต่อด้วยบัญชีเดโม่ การอ่านแท็บ Journal และ Experts ทุกบรรทัด และการเริ่มด้วยเงินน้อยที่สุดในบัญชีที่แยกจากเงินก้อนหลัก ห้ามข้ามขั้นและห้ามสลับลำดับ

เหตุผลที่ลำดับสำคัญคือแต่ละขั้นคัดปัญหาคนละชนิดออกไป และขั้นที่ถูกกว่าควรมาก่อนขั้นที่แพงกว่า การตรวจที่มาของไฟล์ใช้เวลาไม่กี่นาที การค้นพบปัญหาเดียวกันตอนเงินจริงอยู่ในพอร์ตแล้วมีต้นทุนคนละเรื่อง บทความนี้ไล่ทีละขั้นพร้อมสิ่งที่ต้องเห็นจึงจะถือว่าผ่าน และอ้างคู่มือของแพลตฟอร์มตรงจุดที่ค่าเริ่มต้นสำคัญ ภาพรวมของการเทียบของแจกกับของที่จ่ายเงินอยู่ที่ EA ฟรีกับ EA เสียเงินต่างกันยังไง

ขั้น ตรวจอะไร ถือว่าผ่านเมื่อ
1 ที่มาของไฟล์และผู้รับผิดชอบ ระบุได้ว่าใครเขียน ใครแก้เมื่อพัง และมีช่องทางแจ้งปัญหา
2 นามสกุลไฟล์และที่วางไฟล์ เป็น EX5 หรือเป็น MQ5 ที่คอมไพล์เองได้ และวางในโฟลเดอร์เดียวที่ถูกต้อง
3 สิทธิ์ที่ตัวโปรแกรมขอ ทำงานได้โดยไม่ต้องเปิด DLL imports หรือมีคำอธิบายที่ตรวจได้ว่าใช้ทำอะไร
4 ทดสอบย้อนหลังแล้วต่อด้วยบัญชีเดโม่ ผลที่ได้เองใกล้กับที่ถูกอ้าง และผ่านช่วงตลาดหลายแบบบนเดโม่
5 บันทึกในแท็บ Journal และ Experts ไม่มีบรรทัดที่อธิบายไม่ได้ และพฤติกรรมตรงกับที่ทดสอบไว้
6 ขนาดเงินตั้งต้น เป็นจำนวนน้อยที่สุดที่เปิดได้ ในบัญชีที่แยกจากเงินก้อนหลัก

ขั้นที่หนึ่ง ที่มาของไฟล์และใครดูแลต่อ

ขั้นนี้ตอบได้ก่อนเปิดโปรแกรมเลย และตัดงานทีหลังออกได้มากที่สุด คำถามมีสามข้อ ใครเขียนไฟล์นี้ ใครจะแก้เมื่อมันพัง และแจ้งปัญหาได้ที่ไหน ถ้าคำตอบคือ "ได้มาจากกลุ่ม ไม่รู้ต้นทาง" ก็จบที่นี่ได้เลย ไม่ใช่เพราะไฟล์ต้องมีอะไรไม่ดี แต่เพราะไม่มีใครรับผิดชอบเมื่อสภาพแวดล้อมรอบตัวมันเปลี่ยน ซึ่งเป็นเรื่องที่เกิดแน่ ๆ ไม่ใช่เรื่องที่อาจเกิด

สิ่งที่เปลี่ยนได้และทำให้โปรแกรมที่เคยทำงานถูกต้องเพี้ยนไปมีอย่างน้อยสามอย่าง คือชื่อสินค้าในเทอร์มินัลที่โบรกตั้งต่างกัน สเปกสัญญาและเงื่อนไขของบัญชีที่ปรับได้ และเวอร์ชันของแพลตฟอร์มที่อัปเดต โปรแกรมที่คิดขนาดไม้จากสเปกสัญญาแล้วสเปกเปลี่ยน จะเปิดไม้ผิดขนาดโดยไม่มีข้อความเตือน จุดนี้คือเหตุผลที่ "ใครดูแลต่อ" มีน้ำหนักเท่ากับ "มันทำกำไรได้ไหม" ที่มาของของแจกแต่ละแบบและสิ่งที่คนแจกได้กลับไป อยู่ที่ แจก EA ฟรีในกลุ่มไลน์ เสี่ยงอะไรบ้าง

ขั้นที่สอง นามสกุลไฟล์และที่วางไฟล์

มีสองนามสกุลที่เกี่ยวข้อง ไฟล์ที่รันได้ในเทอร์มินัลคือไฟล์ EX5 ที่คอมไพล์แล้ว ส่วน MQ5 คือไฟล์ซอร์สโค้ดที่ต้องคอมไพล์ก่อน คู่มือของ MetaTrader 5 อธิบายขั้นตอนไว้ว่าการคอมไพล์ใน MetaEditor "creates an executable *.EX5 file that can be run in the trading platform" และเตือนไว้ด้วยว่า "Source files (*.MQ5) are not displayed in the Navigator window of the trading platform" คือไฟล์ซอร์สจะไม่โผล่ในหน้าต่าง Navigator จนกว่าจะคอมไพล์เสร็จ

ข้อนี้มีประโยชน์สองทาง ทางแรกคือถ้าวางไฟล์แล้ว Navigator ไม่เห็น อาการนั้นอธิบายได้ด้วยนามสกุลไฟล์ ไม่ต้องไปรื้ออย่างอื่น ทางที่สองคือการได้ไฟล์ MQ5 เป็นข่าวดี เพราะหมายความว่ามีซอร์สโค้ดให้ตรวจ ส่วนที่วางไฟล์ คู่มือระบุว่า "All Expert Advisors are stored in the /MQL5/Experts folder of the trading platform" และบอกทางเข้าโฟลเดอร์ข้อมูลไว้ว่าเปิดได้เร็วที่สุดจากเมนู File แล้วเลือกเปิดโฟลเดอร์ข้อมูล

กฎที่ควรถือไว้คือวางไฟล์ที่เดียว ไม่ก๊อปกระจายไว้หลายที่ เพราะเวลาต้องลบหรืออัปเดต ไฟล์ที่ลืมไว้จะกลายเป็นตัวที่รันอยู่โดยที่คุณไม่รู้ ชุดค่าที่บันทึกไว้เป็นอีกไฟล์แยกกัน คู่มือระบุว่าชุดค่าอินพุตเก็บในโฟลเดอร์ Presets ของแพลตฟอร์ม ความต่างของสองนามสกุลนี้แบบละเอียดอยู่ที่ ไฟล์ EX5 กับ MQ5 ต่างกันยังไง ต้องวางไว้ตรงไหน

ขั้นที่สาม สิทธิ์ที่ตัวโปรแกรมขอ

ขั้นนี้สำคัญที่สุดในบทความนี้ และเป็นขั้นที่คนข้ามบ่อยที่สุดเพราะมันดูเหมือนขั้นตอนติดตั้งธรรมดา จุดที่ต้องรู้คือ EA เรียกใช้ไลบรารีภายนอกของระบบปฏิบัติการได้ และคู่มือของแพลตฟอร์มเขียนผลของการอนุญาตไว้เอง หน้าช่วยเหลือเรื่อง EA ระบุว่าเมื่อเปิดตัวเลือก Allow DLL imports แล้วไลบรารีเหล่านั้น "can be used without any restrictions" คือใช้งานได้โดยไม่มีข้อจำกัด และสรุปว่าการใช้ DLL ภายนอก "is potentially dangerous"

หน้าตั้งค่าของแพลตฟอร์มไปไกลกว่านั้น มันตั้งชื่อช่องนี้ไว้เลยว่า "Allow DLL imports (potentially dangerous, enable only for trusted applications)" คือเตือนอยู่ในชื่อตัวเลือกว่าให้เปิดเฉพาะกับโปรแกรมที่ไว้ใจได้ และเพิ่มคำแนะนำไว้ว่า "It is recommended to disable import when working with unknown Expert Advisors" ถ้าคำแนะนำการติดตั้งที่ได้มาบอกให้ติ๊กช่องนี้ก่อนจึงจะใช้ได้ นั่นคือการขอให้คุณถอดข้อจำกัดที่ผู้ผลิตแพลตฟอร์มใส่ไว้ ไม่ใช่ขั้นตอนติดตั้งตามปกติ

วิธีตรวจที่ได้ผลคือทดลองไม่เปิดให้ก่อน ถ้าโปรแกรมต้องใช้ไลบรารีภายนอกจริง ๆ มันจะหยุดและบอกเอง เอกสารอ้างอิงของ MQL5 เรื่องการเรียกฟังก์ชันที่นำเข้าระบุว่าถ้าโหลดไลบรารีไม่ได้ หรือมีการห้ามใช้ DLL หรือหาฟังก์ชันที่นำเข้าไม่เจอ EA "stops its operation with the appropriate message" และข้อความนั้นลงในบันทึก ดังนั้นการปิดช่องนี้ไว้ก่อนแล้วไปอ่านบันทึกคือการทดสอบที่ได้คำตอบชัดเจน ไม่ใช่การเดา

ช่องอื่นในแท็บเดียวกันที่ควรดูด้วยมีสามช่อง ช่องแรกคือ "Allow WebRequest for listed URL" ซึ่งคู่มือระบุว่าปิดไว้เป็นค่าเริ่มต้น "For security reasons" ถ้าโปรแกรมขอให้เพิ่มที่อยู่เว็บเข้าไปในรายการ ต้องรู้ว่ามันคุยกับที่ไหนและคุยเรื่องอะไร ช่องที่สองคือการเทรดอัตโนมัติผ่าน Python API ภายนอก ที่คู่มือระบุว่าปิดเป็นค่าเริ่มต้นด้วยเหตุผลด้านความปลอดภัยเช่นกัน ช่องที่สามคือสวิตช์หลัก "Allow Auto Trading" ซึ่งคู่มือระบุว่าถ้าปิดไว้ จะไม่มี EA ตัวใดได้รับอนุญาตให้เทรด แม้จะเปิดอนุญาตให้เป็นรายตัวในการตั้งค่าของ EA นั้นแล้ว

จุดที่เข้าใจผิดกันมาก การปิดสวิตช์เทรดไม่ใช่การปิดโปรแกรม คู่มือของแพลตฟอร์มระบุว่าการปิด Expert Advisors ในการตั้งค่าไม่ได้ปิดมันทั้งหมด การกระทำนั้นเพียงห้าม EA ส่งคำสั่งเทรด ถ้าคุณไม่ไว้ใจไฟล์ใด วิธีที่ถูกคือถอดมันออกจากกราฟแล้วลบไฟล์ออกจากโฟลเดอร์ ไม่ใช่ปิดสวิตช์แล้วปล่อยไว้ และอีกเรื่องที่ควรจำคือการรัน EA บนเครื่องของคุณเองไม่ต้องใช้รหัสผ่านบัญชีเทรดของใครเลย

ขั้นที่สี่ ทดสอบย้อนหลังแล้วต่อด้วยบัญชีเดโม่

สองขั้นนี้ตอบคำถามคนละข้อ จึงทำแทนกันไม่ได้ การทดสอบย้อนหลังตอบว่าตรรกะของมันทำอะไรในอดีต เช่นเปิดไม้ถี่แค่ไหน ถือไม้นานเท่าไร ติดลบลึกสุดเท่าไร และเพิ่มไม้เมื่อติดลบหรือเปล่า ทั้งหมดนี้ดูได้โดยยังไม่ต้องต่อบัญชีจริงและยังไม่ต้องรอ การรันบนบัญชีเดโม่ตอบคำถามที่การทดสอบย้อนหลังตอบไม่ได้ คือมันอยู่รอดกับการเชื่อมต่อจริงไหม สเปรดจริงกินไปเท่าไร และมีช่วงไหนที่มันหยุดทำงานเองหรือเปล่า

สิ่งที่ต้องเห็นจึงจะถือว่าผ่านขั้นนี้มีสามข้อ ข้อแรกคือผลที่คุณกดทดสอบเองใกล้กับผลที่ถูกอ้าง ด้วยช่วงเวลาและชุดค่าที่คุณเลือกเอง ไม่ใช่จากภาพหน้าจอที่ได้รับมา ข้อที่สองคือบนเดโม่มันผ่านสภาพตลาดหลายแบบ รวมช่วงข่าวและช่วงที่สเปรดกว้างขึ้น ไม่ใช่ผ่านแค่สัปดาห์ที่ตลาดนิ่ง ข้อที่สามคือพฤติกรรมบนเดโม่สอดคล้องกับที่เห็นในการทดสอบย้อนหลัง ถ้าในการทดสอบมันเปิดวันละไม่กี่ไม้ แต่บนเดโม่เปิดชั่วโมงละหลายไม้ สองอย่างนี้ไม่ใช่โปรแกรมเดียวกันในทางปฏิบัติ วิธีตั้งการทดสอบย้อนหลังให้ผลเชื่อถือได้อยู่ที่ วิธี backtest EA บน MT5 ทีละขั้นตอน

ข้อควรรู้เพิ่มคือเมื่อแนบ EA เข้ากราฟ คู่มือระบุว่ากราฟหนึ่งรัน EA ได้ตัวเดียว ถ้าเริ่ม EA ตัวใหม่บนกราฟเดิม ตัวแรกจะถูกถอดออก ดังนั้นเวลาทดสอบของหลายตัวต้องแยกกราฟ และหน้าต่าง Navigator จะแสดงรายการ EA ทั้งหมดที่กำลังรันของบัญชีที่เชื่อมต่ออยู่ ใช้ตรวจได้ว่ามีตัวไหนค้างอยู่ที่คุณลืมถอด

ขั้นที่ห้า อ่านแท็บ Journal และ Experts

สองแท็บนี้คือที่ที่โปรแกรมบอกว่ามันทำอะไรไปจริง ซึ่งเป็นข้อมูลคนละชุดกับสิ่งที่คนส่งไฟล์มาบอกว่ามันทำ คู่มือของแพลตฟอร์มแยกหน้าที่ของสองแท็บไว้ชัด บันทึกของแพลตฟอร์ม "are shown on the Journal tab of the Toolbox window" และเก็บข้อมูลการทำงานของผู้ใช้และของตัวแพลตฟอร์มในรอบการใช้งานนั้น ส่วน Experts Journal "is displayed on the Experts tab of the Toolbox window" และเก็บข้อมูลของอินดิเคเตอร์และ EA ที่กำลังรัน รวมถึงการเปิดและปิดสถานะ การแก้ไขออเดอร์ และข้อความแจ้งเตือนกับคอมเมนต์ของ EA

คู่มือยังบอกที่เก็บไฟล์บันทึกไว้ด้วย ไฟล์บันทึกของแพลตฟอร์มอยู่ในไดเรกทอรี Logs ส่วนไฟล์บันทึกของ EA อยู่ใน MQL5\Logs และตั้งชื่อตามวันที่ในรูปแบบ YYYYMMDD.LOG ประโยชน์คือย้อนอ่านวันก่อน ๆ ได้ ไม่ใช่เห็นแค่รอบที่เปิดอยู่

สิ่งที่ต้องมองหาในสองแท็บนี้มีสี่อย่าง อย่างแรกคือข้อความที่บอกว่าโปรแกรมหยุดทำงาน ซึ่งเป็นอาการเดียวกับที่เกิดเมื่อโปรแกรมต้องใช้ไลบรารีภายนอกแต่ถูกห้าม อย่างที่สองคือคำสั่งที่ถูกปฏิเสธและเหตุผลของการปฏิเสธ อย่างที่สามคือจำนวนและเวลาของไม้ที่เปิด ซึ่งใช้เทียบกับที่เห็นในการทดสอบย้อนหลังได้ตรง ๆ อย่างที่สี่คือบรรทัดใดก็ตามที่คุณอธิบายไม่ได้ ข้อสุดท้ายนี้เป็นเกณฑ์ที่เข้มที่สุดและควรถือไว้ตามนั้น วิธีอ่านรายละเอียดของสองแท็บนี้อยู่ที่ วิธีอ่านแท็บ Experts และ Journal บน MT5

ขั้นที่หก เริ่มด้วยเงินน้อยที่สุด

ผ่านห้าขั้นแล้วก็ยังไม่ควรเริ่มด้วยเงินก้อนหลัก เหตุผลไม่ใช่ความระแวง แต่เป็นเพราะบัญชีจริงมีสิ่งที่เดโม่ไม่มี ทั้งการเลื่อนราคาตอนสภาพคล่องบาง การปฏิเสธคำสั่ง และต้นทุนที่คิดจริง ขั้นนี้จึงเป็นการทดสอบสิ่งที่เหลือด้วยเงินจำนวนที่ยอมเสียได้ทั้งก้อนโดยไม่กระทบอะไร

กฎที่ใช้ได้มีสี่ข้อ ข้อแรกคือใช้ขนาดไม้เล็กที่สุดที่บัญชีนั้นเปิดได้ ข้อที่สองคือแยกบัญชีออกจากเงินก้อนหลัก ไม่ใช่แบ่งเป็นสัดส่วนในบัญชีเดียวกัน ข้อที่สามคือเขียนเพดานขาดทุนเป็นจำนวนเงินไว้ก่อนเริ่ม แล้วหยุดเมื่อถึงเพดานนั้นโดยไม่ต้องต่อรองกับตัวเอง ข้อที่สี่คือกำหนดระยะเวลาสังเกตไว้ล่วงหน้า เช่นต้องผ่านรอบสภาพตลาดครบก่อนจึงพิจารณาเพิ่มขนาด ไม่ใช่เพิ่มเพราะสัปดาห์แรกผลดี

และถ้าผ่านทั้งหกขั้นแล้วยังตอบไม่ได้ว่าใครดูแลไฟล์นี้ต่อ ขั้นที่หนึ่งยังไม่ผ่าน การแยกประเภทของแจกเพื่อดูว่าของที่ได้มาอยู่กลุ่มไหนและควรคาดหวังอะไรจากมัน อยู่ที่ EA ฟรีมีกี่แบบ แยกยังไงว่าอันไหนพอใช้ได้ และถ้าจะเริ่มจากของที่มีคนดูแลและมีขั้นตอนติดตั้งที่เขียนไว้ครบ จุดเริ่มต้นอยู่ที่ หน้าเริ่มใช้งาน

สรุป

สรุป: ลำดับการตรวจมีหกขั้นและห้ามสลับ ขั้นที่หนึ่งคือที่มาของไฟล์และผู้รับผิดชอบ ถ้าตอบไม่ได้ว่าใครจะแก้เมื่อมันพัง ก็ไม่ควรไปต่อ ขั้นที่สองคือนามสกุลไฟล์และที่วาง ไฟล์ที่รันได้คือ EX5 ส่วนไฟล์ซอร์ส MQ5 คู่มือระบุว่าไม่แสดงใน Navigator จนกว่าจะคอมไพล์ และ EA ทั้งหมดเก็บในโฟลเดอร์ MQL5/Experts โดยเข้าโฟลเดอร์ข้อมูลได้จากเมนู File ขั้นที่สามคือสิทธิ์ที่โปรแกรมขอ ภาษา MQL5 คุมการเข้าถึงไฟล์ไว้ในกรอบที่กำหนดและห้ามทำงานกับไฟล์นอกกรอบ แต่กรอบนั้นหมดผลเมื่อเปิดช่อง Allow DLL imports ซึ่งคู่มือเตือนเองว่าอันตรายและให้เปิดเฉพาะกับโปรแกรมที่ไว้ใจได้ วิธีตรวจคือไม่เปิดให้ก่อน เพราะถ้าโปรแกรมต้องใช้จริง มันจะหยุดและเขียนข้อความลงบันทึก ขั้นที่สี่คือทดสอบย้อนหลังแล้วต่อด้วยบัญชีเดโม่ สองอย่างตอบคำถามคนละข้อจึงแทนกันไม่ได้ ขั้นที่ห้าคืออ่านแท็บ Journal และ Experts ซึ่งบันทึกการเปิดปิดสถานะ การแก้ออเดอร์ และข้อความของ EA โดยไฟล์บันทึกของ EA อยู่ใน MQL5\Logs ตั้งชื่อตามวันที่ ขั้นที่หกคือเริ่มด้วยขนาดไม้เล็กที่สุดในบัญชีที่แยกจากเงินก้อนหลัก พร้อมเพดานขาดทุนที่เขียนไว้ก่อนเริ่ม

คำเตือนความเสี่ยง: การเทรดด้วยมาร์จิ้นมีความเสี่ยงสูงและอาจทำให้สูญเงินลงทุนทั้งจำนวน การตรวจครบทั้งหกขั้นในบทความนี้ลดความเสี่ยงบางประเภทได้เท่านั้น เช่นความเสี่ยงจากไฟล์ที่ไม่รู้ที่มาและจากการตั้งค่าผิด แต่ไม่ได้ลดความเสี่ยงของตลาด ไม่ได้รับประกันผลกำไร และไม่ได้รับประกันว่าความเสียหายจะหยุดที่เพดานที่ตั้งไว้ เพราะช่องว่างราคาและสภาพคล่องที่บางลงในบางช่วงทำให้ปิดสถานะได้ที่ราคาแย่กว่าที่ตั้งใจ การตั้งค่าความปลอดภัยของแพลตฟอร์มที่อ้างถึงในบทความนี้เป็นค่าตามคู่มือของผู้ผลิต ซึ่งอาจเปลี่ยนตามเวอร์ชัน ให้ยืนยันกับหน้าคู่มือล่าสุดก่อนใช้ บทความนี้เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำการลงทุน และไม่ได้กล่าวถึงบุคคล กลุ่ม เพจ หรือผู้ให้บริการรายใดเป็นการเฉพาะ ใช้เฉพาะเงินที่พร้อมรับความเสียหายและไม่มีกำหนดต้องใช้ อ่าน คำเตือนความเสี่ยงฉบับเต็ม

คำถามที่พบบ่อย

โหลด EA ฟรีมาแล้ววางไฟล์ไว้ตรงไหน

คู่มือของแพลตฟอร์มระบุว่า EA ทั้งหมดเก็บอยู่ในโฟลเดอร์ MQL5/Experts ของแพลตฟอร์ม และเข้าโฟลเดอร์ข้อมูลได้เร็วที่สุดจากเมนู File แล้วเลือกเปิดโฟลเดอร์ข้อมูล วางที่เดียวเท่านั้น อย่าก๊อปกระจายไว้หลายที่

วางไฟล์แล้วไม่เห็นใน Navigator เพราะอะไร

สาเหตุที่พบบ่อยที่สุดคือไฟล์ที่ได้มาเป็นไฟล์ซอร์ส MQ5 ซึ่งคู่มือระบุว่าไม่แสดงในหน้าต่าง Navigator ต้องคอมไพล์ให้เป็นไฟล์ EX5 ก่อน หลังคอมไพล์เสร็จจึงจะเห็นในรายการ

ต้องเปิด Allow DLL imports ไหม

ไม่ควรเปิดให้โปรแกรมที่ไม่รู้ที่มา คู่มือตั้งชื่อช่องนี้เองว่าอาจเป็นอันตรายและให้เปิดเฉพาะกับโปรแกรมที่ไว้ใจได้ พร้อมแนะนำให้ปิดเมื่อทำงานกับ EA ที่ไม่รู้จัก ถ้าโปรแกรมต้องใช้จริง มันจะหยุดทำงานและเขียนข้อความลงบันทึกให้เห็น

ต้องรันบนบัญชีเดโม่นานแค่ไหนก่อนใช้เงินจริง

ไม่มีจำนวนวันตายตัว เกณฑ์ที่ใช้ได้คือต้องผ่านสภาพตลาดหลายแบบ รวมช่วงข่าวและช่วงที่สเปรดกว้างขึ้น และพฤติกรรมที่เห็นต้องสอดคล้องกับผลทดสอบย้อนหลัง ไม่ใช่นับวันแล้วถือว่าผ่าน

ลบ EA ที่ไม่ไว้ใจออกยังไงให้หมดจริง

ถอดออกจากกราฟก่อน แล้วลบไฟล์ออกจากโฟลเดอร์ การปิดสวิตช์เทรดไม่พอ เพราะคู่มือระบุว่าการปิด Expert Advisors ในการตั้งค่าไม่ได้ปิดโปรแกรมทั้งหมด เพียงห้ามส่งคำสั่งเทรดเท่านั้น
