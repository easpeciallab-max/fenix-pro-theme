XAUUSD เป็น Symbol ที่ใช้แสดงราคาทองคำเทียบกับดอลลาร์สหรัฐบนแพลตฟอร์มของโบรกเกอร์จำนวนมาก ความผันผวนและโอกาสที่ราคาเคลื่อนเร็วทำให้ทองเป็นสินทรัพย์ที่นิยมใช้กับ EA แต่ชื่อ XAUUSD ไม่ได้แปลว่าสเปกเหมือนกันทุกแห่ง Contract Size, Tick Value, Spread, Stops Level, Leverage และเวลาซื้อขายอาจต่างกัน จึงไม่ควรนำค่า Lot หรือ Preset จากบัญชีหนึ่งไปใช้กับอีกบัญชีโดยไม่ตรวจสอบ

บทความนี้เน้นสิ่งที่ต้องเช็กก่อนเปิด EA บนกราฟทอง ไม่ให้ความหมายว่า XAUUSD เหมาะกับผู้ใช้ทุกคน และไม่กำหนด Lot หรือทุนตายตัว เพราะระดับที่เหมาะสมขึ้นอยู่กับสเปกบัญชี ระบบ และความเสี่ยงที่แต่ละคนยอมรับได้

XAUUSD ใน MT5 คืออะไร

XAU เป็นรหัสที่ใช้แทนทองคำ และ USD คือดอลลาร์สหรัฐ ในบัญชี Retail Forex หรือ CFD ผู้ใช้ไม่ได้ควรสรุปโดยอัตโนมัติว่ากำลังซื้อทองคำแท่งหรือ Gold Futures จริง รูปแบบผลิตภัณฑ์ คู่สัญญา การคำนวณ Margin และสิทธิของผู้ถือขึ้นอยู่กับโบรกเกอร์และเอกสารบัญชี

ชื่อ Symbol อาจมีส่วนต่อท้าย เช่น XAUUSDm, GOLD หรือ XAUUSD.pro และ EA บางตัวตรวจชื่อ Symbol แบบตรงตัว หากผู้พัฒนาไม่ได้รองรับ Suffix ระบบอาจอ่านข้อมูลผิดหรือไม่ทำงาน จึงควรตรวจคู่มือและทดสอบบน Demo ก่อน

Contract Specification ที่ต้องตรวจทุกบัญชี

ใน MT5 เปิด Market Watch คลิกขวาที่ Symbol แล้วเลือก Specification ข้อมูลสำคัญมีดังนี้

รายการ มีผลต่อ EA อย่างไร
Contract Size กำหนดมูลค่าของหนึ่ง Lot และเป็นฐานของการคำนวณ Margin หรือผลกำไรขาดทุน
Tick Size / Tick Value ใช้คำนวณมูลค่าการเปลี่ยนราคาต่อ Tick และขนาดความเสี่ยง
Digits / Point มีผลต่อการแปลงระยะ Stop Loss, Take Profit และ Grid จากจุดเป็นราคา
Minimal Volume / Volume Step กำหนด Lot ต่ำสุดและขั้นการเพิ่ม Lot ที่ Server ยอมรับ
Stops Level กำหนดระยะขั้นต่ำที่วาง Stop Loss, Take Profit หรือ Pending Order ได้
Spread / Commission เป็นต้นทุนที่กระทบจุดคุ้มทุนและผลของระบบระยะสั้น
Swap มีผลเมื่อ EA ถือสถานะข้ามคืนหรือหลายวัน
Trading Sessions กำหนดช่วงที่ส่งคำสั่งได้และช่วงหยุดพักของ Symbol

อย่าจำค่าจากบทความหรือ Screenshot เพราะโบรกเกอร์สามารถใช้สเปกต่างกันและปรับเงื่อนไขได้ การอ่านค่าจาก Specification ของบัญชีที่จะใช้จริงเป็นแหล่งข้อมูลที่ตรงที่สุด

ความผันผวน ข่าว และต้นทุนของทอง

ราคาทองตอบสนองต่อหลายปัจจัย เช่น ดอลลาร์ อัตราดอกเบี้ยจริง ความคาดหวังนโยบายการเงิน ความเสี่ยงทางภูมิรัฐศาสตร์ และสภาพคล่องในตลาด เหตุการณ์อย่างประกาศเงินเฟ้อ การประชุมธนาคารกลาง หรือข้อมูลแรงงานอาจทำให้ราคาและ Spread เปลี่ยนรวดเร็ว

News Filter ช่วยกำหนดว่า EA จะงดเปิดออเดอร์รอบเหตุการณ์ที่ตั้งไว้ แต่ไม่สามารถรับประกันว่าจะไม่มี Gap, Slippage หรือ Spread ถ่าง เพราะออเดอร์เดิมยังได้รับผลจากตลาด และเหตุการณ์ที่ไม่อยู่ในปฏิทินก็เกิดได้ หากระบบถือสถานะอยู่ก่อนข่าว ต้องรู้ว่ามีกฎลดความเสี่ยง ปิดบางส่วน หรือปล่อยตาม Stop อย่างไร

ระบบ Scalping บนทองยิ่งไวต่อต้นทุน ส่วน Grid หรือ Martingale จะไวต่อแนวโน้มยาวและการสะสม Exposure เปรียบเทียบกลยุทธ์ได้ที่ ประเภทของ EA

กำหนด Lot ของ XAUUSD อย่างไร

ไม่ควรเลือก Lot จากทุนเพียงตัวเลขเดียว วิธีที่ตรวจสอบได้มากกว่าคือเริ่มจากจำนวนเงินสูงสุดที่ยอมเสียต่อออเดอร์หรือชุดออเดอร์ แล้วคำนวณร่วมกับระยะ Stop Loss และ Tick Value ของ Symbol

หลักคิดทั่วไปคือ:

Lot ที่รับได้ = เงินที่ยอมเสี่ยง ÷ มูลค่าขาดทุนต่อหนึ่ง Lot ตามระยะ Stop

แต่สูตรจริงต้องใช้ Tick Size, Tick Value, สกุลเงินบัญชี และวิธีคำนวณของ Symbol หากเป็นระบบหลายออเดอร์ ต้องรวม Lot และ Stop ของทั้ง Basket ไม่ใช่คำนวณเฉพาะไม้แรก MT5 มีฟังก์ชัน OrderCalcProfit และ OrderCalcMargin ให้โปรแกรมประเมินผลตามสเปกบัญชี แต่ผู้ใช้ยังควรตรวจผลกับเครื่องคำนวณและ Demo

อ่านแนวทางทีละขั้นที่ วิธีคำนวณ Lot Size และกำหนดกรอบด้วย ความเสี่ยงต่อออเดอร์

วิธีทดสอบ EA บน XAUUSD ก่อนใช้จริง

  1. ใช้ข้อมูลจากโบรกเกอร์หรือ Server ที่เกี่ยวข้อง เพราะราคา Tick และ Spread อาจต่างกัน
  2. ตรวจชื่อ Symbol และ Suffix ให้ตรงกับค่าที่ EA รองรับ
  3. ใส่ Commission และ Swap ตามประเภทบัญชีที่จะใช้จริง
  4. ทดสอบหลายระดับ Spread รวมช่วงที่ต้นทุนสูงกว่าปกติ
  5. ครอบคลุมข่าวและช่วงผันผวน ไม่ตัดช่วงเสียหายออกเพียงเพื่อให้กราฟสวย
  6. ตรวจทั้ง Balance และ Equity โดยเฉพาะระบบที่เปิดหลายออเดอร์
  7. ทำ Forward Test บน Demo เพื่อดูการส่งคำสั่งและข้อผิดพลาดใน Journal
  8. เริ่ม Lot ต่ำกว่าค่าที่รับได้สูงสุด เพื่อเผื่อ Slippage, Gap และความคลาดเคลื่อนจากแบบทดสอบ

เช็กลิสต์ก่อนเปิด EA เทรดทอง

  • EA รองรับชื่อ Symbol และสเปกของบัญชีนี้หรือไม่
  • รู้ Contract Size, Tick Size, Tick Value และ Volume Step แล้วหรือยัง
  • ระบบใช้ Fixed Lot, Auto Lot, Grid หรือ Martingale
  • ขาดทุนสูงสุดต่อออเดอร์และต่อวันถูกจำกัดอย่างไร
  • มี Stop Loss, Equity Stop หรือเงื่อนไขปิด Basket หรือไม่
  • ทำงานช่วงข่าวหรือ Rollover หรือไม่
  • VPS และ MT5 ใช้ Server Time ใด
  • ผลทดสอบรวม Spread, Commission, Swap และ Slippage หรือยัง
  • เงินที่ใช้เป็นเงินเย็นและยอมรับการขาดทุนได้หรือไม่

หากคำตอบบางข้อยังไม่ชัด ควรหยุดที่ Demo และสอบถามผู้พัฒนาก่อน การตั้งค่าให้เหมาะกับบัญชีสำคัญกว่าการนำ Preset ของผู้อื่นมาใช้โดยไม่ตรวจสเปก

คำเตือนความเสี่ยง: ทองคำและผลิตภัณฑ์ที่อ้างอิงทองมีความผันผวนสูง การใช้ EA และ Leverage อาจขยายทั้งกำไรและขาดทุน Stop Loss อาจถูกดำเนินการต่างจากราคาที่ตั้งไว้ในช่วง Gap หรือสภาพคล่องต่ำ ผลในอดีตไม่รับประกันผลในอนาคต
