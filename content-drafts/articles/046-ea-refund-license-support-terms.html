ก่อนซื้อ EA ควรอ่านอย่างน้อยสามเอกสาร: หน้ารายละเอียดสินค้า หน้าราคา/แพ็กเกจ และ Terms/Refund/Privacy ที่มีผล ณ วันที่ซื้อ ข้อความโฆษณาบอกสิ่งที่ผู้ขายต้องการนำเสนอ แต่สิทธิ์ใช้ การคืนเงิน การย้ายเครื่อง และขอบเขต Support มักอยู่ในรายละเอียดที่คนข้าม

บทความนี้เป็น Checklist เชิงปฏิบัติ ไม่ใช่คำแนะนำทางกฎหมาย สิทธิ์ผู้บริโภคอาจต่างตามประเทศ ช่องทางซื้อ ประเภทสินค้าดิจิทัล และข้อเท็จจริง หากมีข้อพิพาทควรเก็บหลักฐานและปรึกษาหน่วยงาน/ผู้เชี่ยวชาญที่เกี่ยวข้อง

สารบัญ

  • สิ่งที่ซื้อและการส่งมอบ
  • เงื่อนไข Refund
  • License และ Activation
  • Support และ Update
  • ค่าใช้จ่ายและบริการภายนอก
  • หลักฐานที่ต้องเก็บ

ระบุสิ่งที่จะได้รับให้ครบ

หัวข้อ สิ่งที่ควรระบุ
ไฟล์ EX5/Installer, Version, Preset, Indicator/Library ที่จำเป็น
Platform MT5 Build, Windows/VPS และ Account Type ที่รองรับ
License จำนวนบัญชี เครื่อง Activation และวันหมดอายุ
คู่มือ ติดตั้ง ตั้งค่า Update Backup และ Troubleshooting
Support ช่องทาง เวลา ขอบเขต ภาษา และระยะตอบโดยประมาณ
Update Bug Fix, Compatibility และ Major Version รวมถึงเมื่อใด

คำว่า “พร้อมใช้งาน” ไม่ได้บอกว่า Includes Installation Service, VPS หรือ Broker Account หรือไม่ ถามให้ชัดว่าผู้ขายช่วยติดตั้งหรือส่งเฉพาะไฟล์ และผู้ซื้อยังต้องเตรียมอะไร

อ่าน Refund ก่อน Activate หรือดาวน์โหลด

สินค้าดิจิทัลอาจมีเงื่อนไขต่างจากสินค้าทั่วไป บางช่องทางถือว่าการ Activate/Download เป็นการเริ่มใช้สิทธิ์และจำกัดการคืนเงิน ต้องอ่าน:

  • มี Refund หรือไม่ และระยะเวลานับจากจุดใด
  • กรณีใดเข้าเกณฑ์ เช่น ไฟล์ใช้ไม่ได้ตาม Specification หรือส่งมอบไม่ครบ
  • กรณีใดไม่เข้าเกณฑ์ เช่น ผลการเทรดไม่ตรงความคาดหวังหรือเปลี่ยนใจ
  • ต้องแจ้งผ่านช่องทางใด ส่ง Log/หลักฐานอะไร
  • ผู้ขายมีเวลาตรวจ/แก้ปัญหาก่อนอนุมัติคืนเงินหรือไม่
  • ค่าธรรมเนียม Payment, FX และ Subscription ถูกคืนหรือไม่
  • เมื่อ Refund แล้ว License/ไฟล์/ข้อมูลต้องจัดการอย่างไร

อย่าตีความคำว่า “รับประกันความพอใจ” เอง หากไม่มีขั้นตอนและข้อยกเว้น ควรถามเป็นข้อความก่อนชำระและเก็บคำตอบไว้

License เป็นข้อจำกัดที่กระทบ Operations

อ่าน Terms เรื่อง:

  1. สิทธิ์เป็น Personal, Commercial หรือใช้กับเงินบุคคลอื่นได้หรือไม่
  2. ผูก Account, Broker, Device, Hardware ID หรือ MQL5 Account
  3. Activation ถูกใช้เมื่อดาวน์โหลด ติดตั้ง เปิดโปรแกรม หรือเปลี่ยนเครื่อง
  4. ย้าย VPS/Format Windows/เปลี่ยนบัญชีมีค่าธรรมเนียมหรือ Limit
  5. ห้าม Copy, Resell, Reverse Engineer หรือ Share อย่างไร
  6. License Expire แล้ว EA หยุดเปิดใหม่หรือหยุดทุกฟังก์ชัน

ดูรายละเอียดคำถามที่ License EA ผูกบัญชีหรือเครื่อง และอย่าคิดว่าการมีไฟล์ EX5 เท่ากับมีสิทธิ์ใช้ไม่จำกัด

Support ไม่เท่ากับบริการบริหารบัญชี

Support ของซอฟต์แวร์อาจครอบคลุมการติดตั้ง Error และ Function ตามคู่มือ แต่ไม่รวมการเลือก Lot การรับประกันกำไร การเฝ้าบัญชี หรือการแก้ปัญหา Broker/VPS ทุกอย่าง ตรวจ:

  • เวลาให้บริการและวันหยุด
  • ช่องทางหลัก เช่น Ticket, Email, LINE และช่องทางฉุกเฉิน
  • ข้อมูลที่ต้องส่ง: Screenshot, Log, Version, Server โดยไม่ส่ง Password
  • รองรับ Remote Assistance หรือไม่ และมาตรการความปลอดภัย
  • Support หมดอายุเมื่อใด ต่ออายุเท่าไร
  • แก้ Critical Bug และ MT5 Compatibility ตามนโยบายใด

ถ้าต้อง Remote ให้ผู้ใช้เฝ้าหน้าจอ ใช้เครื่องมือที่ยืนยันได้ จำกัดสิทธิ์/เวลา และเปลี่ยน Credential ที่จำเป็นหลังจบ ไม่ให้ Broker Main Password แก่ผู้ขายเพียงเพื่อ “ตั้งค่าให้”

Update และการเปลี่ยน Strategy

ถามว่า Update อาจเปลี่ยน Entry/Exit/Risk Logic หรือไม่ มี Changelog, Version Pin และ Rollback หรือไม่ ไม่ควร Auto-update Production EA โดยไม่ทดสอบ เพราะผลลัพธ์/Parameter Compatibility อาจเปลี่ยน

แยก:

  • Critical Fix: แก้ Crash/Order Error/Security
  • Compatibility: รองรับ MT5/Broker/OS เปลี่ยน
  • Strategy Update: เปลี่ยน Logic ซึ่งต้อง Backtest/Forward ใหม่
  • Feature Update: เพิ่ม Dashboard/Filter/Parameter

Terms ควรบอกว่าสิทธิ์ Update ครอบคลุมแบบใดและ Version เดิมยังดาวน์โหลดได้หรือไม่

ต้นทุนภายนอกที่มักไม่รวม

  • VPS รายเดือนและ Backup/Monitoring
  • Broker Spread, Commission, Swap และ Deposit/Withdrawal Fee
  • Data/News/API/License Service
  • Payment Gateway, FX Conversion และภาษีที่เกี่ยวข้อง
  • ค่าต่อ Subscription/Support/Activation
  • เวลาและต้นทุนการย้าย/ทดสอบระบบ

ต้นทุนเหล่านี้ลด Net Result และอาจทำให้ระบบที่กำไรบางใน Backtest ใช้งานจริงไม่คุ้ม CFTC แนะนำให้พิจารณาค่าธรรมเนียม Spread และ Subscription ร่วมกับคำกล่าวอ้างผลตอบแทน

เก็บหลักฐานชุดเดียวให้ค้นได้

  1. Invoice/Receipt และ Transaction ID
  2. Screenshot/PDF หน้าสินค้า ราคา Terms และ Refund วันที่ซื้อ
  3. ข้อความตอบคำถามก่อนซื้อ
  4. License ID, Activation Count และวันหมดอายุ
  5. ไฟล์ Original, Version, Checksum และ Download Source
  6. Ticket/Log เมื่อพบปัญหาและผลการแก้ไข

อย่าเก็บ Password/OTP ร่วมใน Folder นี้ และไม่เผยแพร่ไฟล์ที่มีลิขสิทธิ์เพื่อขอความช่วยเหลือสาธารณะ

คำถามปิดท้ายก่อนกดซื้อ

  • หาก EA ไม่ทำงานตาม Specification กระบวนการแก้/คืนเงินคืออะไร
  • หากย้าย VPS พรุ่งนี้ ใช้ License ต่อได้อย่างไร
  • หากผู้ขายหยุดบริการ Position ที่เปิดอยู่จะถูกจัดการอย่างไร
  • Support ช่วยถึงขั้นใดและไม่ช่วยอะไร
  • ค่าใช้จ่ายรวมปีแรกและปีถัดไปเท่าไร

อ่าน คำถามก่อนซื้อ EA, วิธีตรวจผู้ขาย และเงื่อนไขของเว็บที่ ข้อกำหนดการใช้งาน ก่อนชำระ

สรุป: Terms ที่ดีควรทำให้รู้ว่าได้อะไร ใช้ได้แค่ไหน ขอคืนเงินอย่างไร ใครช่วยเมื่อมีปัญหา และเกิดอะไรเมื่อ License/Support หมดอายุ หากคำตอบสำคัญยังไม่ชัด ให้ขอเป็นลายลักษณ์อักษรก่อน Activate

คำเตือนความเสี่ยง: Refund/License ไม่รับประกันผลการเทรด และผลขาดทุนจากตลาดอาจไม่อยู่ในขอบเขตการคืนเงินของซอฟต์แวร์ โปรดอ่านเงื่อนไขจริงและประเมินความเหมาะสมก่อนซื้อ EA มีความเสี่ยงและไม่รับประกันกำไร อ่าน คำเตือนความเสี่ยงฉบับเต็ม
