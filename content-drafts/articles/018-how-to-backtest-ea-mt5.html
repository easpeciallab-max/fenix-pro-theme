Backtest EA บน MT5 คือการนำ EA ที่มีค่ากำหนดแน่นอนไปรันกับข้อมูลราคาในอดีต เพื่อดูว่าตรรกะทำงานอย่างไรภายใต้เงื่อนไขที่ตั้งไว้ Backtest ช่วยค้นหา Bug, ตรวจพฤติกรรม และประเมินความเสี่ยงเบื้องต้น แต่ไม่ใช่คำทำนายและไม่รับประกันผลในอนาคต

ผลทดสอบมีความหมายก็ต่อเมื่อระบุได้ว่าใช้ไฟล์ EA Version ใด Preset อะไร ข้อมูลจาก Server ไหน ค่า Spread/Commission เท่าไร และช่วงเวลาใด หากเปลี่ยนเงื่อนไขเพียงจุดเดียว ผลลัพธ์อาจเปลี่ยนมาก โดยเฉพาะระบบ Scalping, Grid หรือระบบที่ไวต่อเวลา

สารบัญ

  • ข้อมูลที่ต้องเตรียม
  • ตั้ง Strategy Tester
  • จำลองต้นทุนและ Execution
  • เริ่มทดสอบและตรวจ Log
  • อ่านผลที่สำคัญ
  • บันทึกให้ทดสอบซ้ำได้

ก่อนเปิด Strategy Tester ต้องเตรียมอะไร

  • ไฟล์ EX5 ที่ทราบชื่อและ Version
  • Preset/SET ที่จะทดสอบ
  • Symbol และ Timeframe ตามกลยุทธ์
  • ประเภทบัญชี สกุลเงิน เงินเริ่มต้น และ Leverage
  • ข้อมูล Contract Specification ของโบรกเกอร์เป้าหมาย
  • ช่วงวันที่ที่ครอบคลุมตลาดหลายลักษณะ
  • เกณฑ์ผ่าน/ไม่ผ่านที่กำหนดก่อนเห็นผล

ควรกำหนดคำถามก่อน เช่น “ระบบรับ Spread สูงขึ้นได้แค่ไหน” หรือ “Drawdown เปลี่ยนอย่างไรเมื่อ Risk ลดลง” ไม่ควรเริ่มด้วยการลองค่าจำนวนมากแล้วเลือกเส้น Equity ที่สวยที่สุด เพราะเสี่ยงต่อ Data Mining และ Overfitting

อ่านพื้นฐานการตีความได้ที่ วิธีอ่านผล Backtest EA และเปรียบเทียบกับการใช้งานจริงที่ Forward Test EA คืออะไร

ขั้นตอนตั้ง Strategy Tester บน MT5

  1. เปิด MT5 แล้วกด Ctrl+R เพื่อเปิด Strategy Tester
  2. เลือกงาน Test Expert หรือ Single Test ไม่เลือก Optimization หากยังต้องการตรวจ Preset เดียว
  3. เลือก EA ให้ตรงชื่อและ Version
  4. เลือก Symbol ของ Server ที่จะทดสอบ
  5. เลือก Timeframe ตามคู่มือ แม้ EA Multi-timeframe อาจเรียกข้อมูลช่วงอื่นเพิ่ม
  6. เลือก Modeling Mode ให้เหมาะกับตรรกะ EA
  7. กำหนดช่วงวันที่ Start/End
  8. กำหนด Initial Deposit, Currency และ Leverage
  9. โหลด SET ในแท็บ Inputs และตรวจค่าทุกช่อง
  10. ตั้ง Execution Delay/Commission/Specification ตามโจทย์ทดสอบ
  11. เปิด Visual Mode รอบสั้นเพื่อตรวจตรรกะก่อนรันช่วงยาว
  12. กด Start และรอให้ข้อมูล History/Tick ดาวน์โหลดครบ

เอกสาร MT5 ระบุว่าวันเริ่มต้นรวมอยู่ในการทดสอบ แต่วิธีนับวันสิ้นสุดจะจบที่ Tick สุดท้ายของวันก่อนหน้าวัน End จึงต้องตรวจช่วงจริงใน Report ไม่สมมติจากช่องวันที่อย่างเดียว

เลือก Modeling Mode อย่างไร

โหมด เหมาะกับ ข้อจำกัด
Every tick based on real ticks ตรวจละเอียดเมื่อ Server มีข้อมูล Tick จริง ช้าและข้อมูลมีขนาดใหญ่; ยังไม่จำลองทุกสภาพ Execution
Every tick ทดสอบตรรกะที่ทำงานระหว่างแท่งด้วย Tick ที่สร้างจาก M1 เส้นทาง Tick เป็นการจำลองเมื่อไม่มี Real Tick
1 minute OHLC ประเมินระบบที่ไม่ไวต่อทุก Tick เรียก OnTick จำกัดที่ OHLC ของ M1
Open prices only คัดกรองเร็วสำหรับ EA ที่ตัดสินใจเฉพาะเปิดแท่ง ไม่เหมาะกับ Intrabar, Trailing หรือเงื่อนไขย่อย

อย่าเลือกโหมดเร็วเพียงเพราะผลสวยกว่า ต้องอธิบายได้ว่าตรรกะของ EA ใช้ข้อมูลระดับใด หากไม่ทราบให้ใช้โหมดละเอียดและเปรียบเทียบหลายโหมดเพื่อดูความไว

ทำต้นทุนให้ใกล้บัญชีจริง

กำไรของ EA คือผลหลังต้นทุน หาก Tester ไม่รวมเงื่อนไขที่บัญชีจริงต้องจ่าย ผลจะสูงเกินจริงได้ ตรวจอย่างน้อย:

  • Spread แบบคงที่หรือเปลี่ยนตาม Tick
  • Commission ต่อ Lot/Side/Round Turn ตามนิยามของโบรกเกอร์
  • Swap และวันคิด Swap เพิ่ม
  • Execution Delay และ Slippage Scenario
  • Minimum/Maximum Volume และ Volume Step
  • Stops Level, Freeze Level และ Trading Session
  • Margin Calculation และ Leverage

MT5 มี Advanced Testing Settings และ Custom Symbol Specification สำหรับจำลองเงื่อนไข แต่ผู้ทดสอบต้องป้อนข้อมูลถูกหน่วย อย่าคัดเลข Commission จากหน้าโฆษณาโดยไม่ดูว่าเป็นต่อ Side หรือ Round Turn และสกุลใด

ระหว่างทดสอบต้องดูอะไร

เปิดแท็บ Journal ของ Strategy Tester ตรวจ Error, ข้อมูลไม่ครบ, Symbol ไม่พร้อม หรือการส่งคำสั่งถูกปฏิเสธ การมี Report ออกมาไม่ได้แปลว่ารันสมบูรณ์ หากมี Pass “tested with error” หรือ EA หยุดกลางช่วง ผลรวมไม่ควรนำไปเปรียบเทียบกับรอบปกติ

Visual Mode ช่วยตรวจ:

  • จุด Entry/Exit ตรงกับแนวคิด
  • Stop Loss/Take Profit อยู่ฝั่งถูกต้อง
  • Lot เปลี่ยนตาม Risk ที่ตั้ง
  • News/Time Filter หยุดในช่วงที่กำหนด
  • EA จัดการหลาย Position และ Pending Order ถูกชุด
  • ไม่มี Look-ahead จาก Indicator หรือข้อมูลอนาคต

หลังรอบสั้นผ่านจึงรันช่วงยาวโดยปิด Visualization เพื่อประหยัดเวลา

อ่าน Report โดยไม่ดูแค่ Net Profit

  • History Quality/Ticks: ข้อมูลมี Gap หรือจำนวน Tick สมเหตุผลหรือไม่
  • Total Trades: Sample เพียงพอให้ตีความหรือยัง
  • Equity Drawdown: เห็น Floating Risk ที่ Balance อาจซ่อน
  • Profit Factor: Gross Profit เทียบ Gross Loss
  • Recovery Factor: Profit เทียบ Maximum Drawdown
  • Expected Payoff: ค่าเฉลี่ยต่อ Trade ก่อนสรุปต้องดู Distribution
  • Consecutive Losses: ใช้วางแผนความทนทานและพฤติกรรมผู้ใช้
  • Equity Curve: มีช่วงนิ่ง ขาดทุนยาว หรือกำไรจากช่วงเดียวหรือไม่

ทดสอบ Sensitivity เพิ่มโดยเปลี่ยน Spread, Delay, Start Date และ Risk หากผลพังเมื่อเงื่อนไขขยับเล็กน้อย ระบบอาจไม่มี Margin of Safety เพียงพอ แม้รอบหลักดูดี

บันทึก Backtest ให้ผู้อื่นทำซ้ำได้

สร้าง Test ID ต่อหนึ่งรอบและเก็บ:

  • EA Filename/Version และ Hash หากมี
  • ไฟล์ SET
  • Server/Symbol/Specification
  • Date Range, Modeling Mode และ Execution Delay
  • Deposit/Currency/Leverage/Commission
  • MT5 Build และวันที่ดาวน์โหลดข้อมูล
  • Report HTML/XML และ Screenshot Settings
  • ข้อสรุปตามเกณฑ์ที่กำหนดไว้ก่อนทดสอบ

จากนั้นทำ Out-of-Sample, Forward Test และ Demo เพื่อดูว่าพฤติกรรมออกนอกข้อมูลที่ใช้เลือกค่าหรือไม่ หน้า ผล Backtest FENIX PRO ควรอ่านร่วมกับเงื่อนไขการทดสอบและ ผล Forward Test ไม่ใช้ภาพผลลัพธ์จุดเดียวแทนหลักฐานทั้งหมด

คำเตือนความเสี่ยง: Backtest อาศัยข้อมูลและสมมติฐานในอดีต ไม่สามารถจำลอง Liquidity, Slippage, Outage และพฤติกรรมตลาดอนาคตได้ครบ ผลในอดีตไม่รับประกันผลในอนาคต
