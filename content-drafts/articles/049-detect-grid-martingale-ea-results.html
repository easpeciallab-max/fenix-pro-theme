การดูว่า EA ใช้ Grid หรือ Martingale ต้องตรวจลำดับออเดอร์ ไม่ใช่ดูชื่อผลิตภัณฑ์หรือ Win Rate อย่างเดียว Grid คือรูปแบบวาง Position หลายระดับราคา ส่วน Martingale โดยทั่วไปคือการเพิ่มขนาดความเสี่ยงหลังขาดทุนหรือเมื่อสถานการณ์สวนทาง ระบบหนึ่งอาจใช้ Grid โดย Lot เท่ากัน, Martingale โดยไม่ใช้ Grid หรือผสมทั้งสองแบบ

ผู้ขายอาจใช้คำอื่น เช่น Recovery, Averaging, Basket หรือ Smart Money Management คำเรียกไม่สำคัญเท่า Logic จริง: เปิดเพิ่มเมื่อใด Lot เปลี่ยนอย่างไร และมีจุดหยุดตรงไหน

สารบัญ

  • แยก Grid กับ Martingale
  • อ่าน Trade List ทีละคอลัมน์
  • ดู Balance และ Equity
  • รูปแบบที่พบบ่อย
  • ข้อมูลที่ต้องขอเพิ่ม
  • วิธี Stress Test

Grid และ Martingale ไม่ใช่คำเดียวกัน

ระบบ สิ่งที่สังเกต ความเสี่ยงหลัก
Grid Fixed Lot เปิดหลายระดับด้วย Lot ใกล้เคียงกัน จำนวน Position/Exposure สะสม
Grid Progressive Lot เปิดหลายระดับและ Lot เพิ่มตามชั้น Exposure โตเร็วกว่าจำนวนออเดอร์
Martingale by Loss Lot รอบถัดไปเพิ่มหลัง Trade แพ้ Loss Streak ทำให้ Risk โต
Basket Recovery เพิ่ม/เฉลี่ยแล้วปิดหลายออเดอร์พร้อมกัน Floating Drawdown และ Margin Tail

อ่านพื้นฐานแยกที่ Grid EA เสี่ยงอย่างไร และ Martingale EA เสี่ยงอย่างไร

คอลัมน์ที่ต้องเรียงตามเวลา

Open Time และ Price

หากออเดอร์ทิศเดียวกันเปิดเมื่อราคาห่างเป็นช่วงใกล้เคียงกัน อาจเป็น Grid Step ตรวจว่าระยะคงที่หรือขยายตาม ATR/Volatility และมีออเดอร์สูงสุดหรือไม่

Volume/Lot

คำนวณอัตราส่วน Lot ระหว่างชั้น ไม่ดูเลขด้วยตาอย่างเดียว Lot อาจเพิ่มแบบคูณ บวกคงที่ หรือปรับตาม Equity หาก Lot เพิ่มหลัง Loss/Basket ลึก ต้องหาขีดจำกัดและ Worst-case Sequence

Direction และ Symbol

Grid อาจเปิดฝั่งเดียว เฮดจ์สองฝั่ง หรือกระจายหลาย Symbol การเปิด Buy/Sell พร้อมกันไม่ได้ลบ Gross Exposure/ต้นทุน และอาจเป็นคนละ Basket

Close Time/Price

หากหลาย Ticket ปิดเวลาเดียวกันหรือราคาใกล้กัน แสดงว่าใช้ Basket Exit ตรวจว่าปิดจากกำไรรวม, Average Price + Target, Equity หรือ Emergency Stop

Comment/Magic

ใช้แบ่ง Strategy/Basket แต่ Comment อาจเปลี่ยนโดย Broker และผู้ขายอาจไม่แสดง Magic ใน Report ต้องขอ Export/Log หากจำเป็น

Balance สวย แต่ Equity อาจบอกอีกเรื่อง

Grid/Martingale ที่ปิดกำไรเล็กบ่อยอาจทำให้ Balance Curve ไต่ขึ้นต่อเนื่อง ขณะที่ Equity ลดลึกระหว่างถือ Basket เมื่อราคากลับ ระบบปิดทั้งหมดแล้ว Balance กระโดดขึ้น ภาพ Balance อย่างเดียวจึงซ่อนระยะเวลาและขนาด Floating Loss

ตรวจ:

  • ช่องว่างสูงสุดระหว่าง Balance กับ Equity
  • Equity Drawdown และ Drawdown Duration
  • Maximum Deposit Load/Margin Level
  • Open Positions ณ จุดจบ Backtest
  • Worst Basket Loss เทียบ Average Basket Profit
  • จำนวนชั้นและ Lot รวม ณ จุด Equity ต่ำสุด

ใช้ วิธีอ่าน Equity Curve และ วิธีอ่านผล Backtest เพื่อไม่ตัดสินจาก Total Net Profit

Pattern ที่ชี้ว่าต้องตรวจลึก

  • Win Rate สูงมาก แต่ Largest Loss ใหญ่กว่า Average Win หลายเท่า
  • Trade ปิดกำไรจำนวนมาก แต่มี Basket ถือยาว/Swap สูง
  • Lot เพิ่มเป็น 0.01, 0.02, 0.04 หรือ Pattern ที่โตตามชั้น
  • ระยะเวลาเปิดออเดอร์ใหม่ถี่ขึ้นเมื่อราคา Trend สวนทาง
  • Trade หลายใบปิดพร้อมกันที่กำไรรวมเล็ก
  • Maximum Consecutive Loss ต่ำ แต่ Equity Drawdown สูง
  • Backtest จบก่อนช่วง Trend/Crash สำคัญหรือมี Position ค้าง

Pattern เหล่านี้ไม่พิสูจน์ว่าเป็นระบบไม่ดีหรือหลอกลวง แต่บอกว่า Average Metric ไม่พอ ต้องขอ Logic Limit และ Stress Test Tail Event

ขีดจำกัดที่ต้องรู้

  1. Grid Step คงที่หรือ Dynamic และ Minimum Distance เท่าไร
  2. Maximum Layers/Positions ต่อ Basket, Symbol และบัญชี
  3. Lot Progression Formula และ Maximum Lot
  4. Basket Stop, Equity Stop และ Margin Guard อยู่ที่ใด
  5. ระบบทำอย่างไรเมื่อ Spread ขยาย, Gap หรือปิดออเดอร์ไม่ครบ
  6. Restart/License ขาดแล้วกู้ Basket State อย่างไร
  7. ผู้ใช้ปิดบาง Ticket เอง ระบบเปิดทดแทนหรือคำนวณ Average ใหม่อย่างไร

หากไม่มี Maximum Layers/Lot/Stop ให้ถือว่า Maximum Exposure ยังไม่ถูกนิยาม ไม่ควรประมาณจากจำนวนชั้นสูงสุดที่บังเอิญเกิดใน Backtest

Stress Test ให้เห็น Tail Risk

  • เลือกช่วง Trend ยาวและ Mean Reversion ไม่เกิดตามระยะปกติ
  • เพิ่ม Spread/Slippage/Swap และจำลอง Gap
  • เริ่ม Backtest หลายวันเพื่อไม่ให้ Initial Timing ช่วยระบบ
  • ทดสอบทุน/Leverage ต่ำลงและ Specification หลาย Broker
  • ขยายจำนวนชั้นตาม Logic จนถึง Hard Limit
  • ทำ Monte Carlo/Trade Sequence เมื่อ Martingale อิง Loss Streak
  • ตรวจ Stop Out/Margin Level ก่อน Exit ของระบบ

งานวิจัย/การจำลองที่กล่าวถึง Grid/Martingale ชี้ให้เห็นว่าผลตอบแทนที่เรียบในสภาวะหนึ่งอาจแลกกับ Drawdown Tail เมื่อราคาเคลื่อนทิศเดียวเป็นเวลานาน จึงต้องรายงาน Worst Scenario ไม่ใช้ Win Rate เป็น Risk Metric

ขั้นตอนตรวจภายใน 15 นาที

  1. Export Trade List และ Sort ตาม Symbol/Open Time
  2. Group ออเดอร์ที่เปิดใกล้เวลา/ทิศเดียวกันเป็น Basket
  3. คำนวณ Price Step และ Lot Ratio
  4. จับเวลา Basket Start-to-Close และ Floating Drawdown
  5. ดู Maximum Layer, Gross Lot และ Margin ที่จุดแย่สุด
  6. เทียบกับ Limit ที่ผู้ขายอธิบาย

สรุป: Grid ตรวจจากการเพิ่มตำแหน่งตามระดับราคา Martingale ตรวจจากการเพิ่มขนาดหลัง Loss/Adverse Move และระบบผสมต้องวัดทั้งจำนวนชั้นกับ Lot Progression สิ่งสำคัญที่สุดคือ Hard Limit และ Equity Tail ไม่ใช่ชื่อ Strategy

คำเตือนความเสี่ยง: Grid และ Martingale สามารถสะสม Exposure, Floating Loss และ Margin Usage อย่างรวดเร็ว ผลกำไรสม่ำเสมอในอดีตไม่รับประกันว่าจะทน Trend, Gap หรือ Loss Streak ในอนาคตได้ โปรดทดสอบและใช้ทุนที่พร้อมรับความเสี่ยง อ่าน คำเตือนความเสี่ยงฉบับเต็ม
