Scalping EA คือระบบที่เข้าและออกออเดอร์ในระยะค่อนข้างสั้น โดยมักคาดหวังกำไรต่อครั้งไม่มากเมื่อเทียบกับระบบที่ถือสถานะหลายชั่วโมงหรือหลายวัน จุดเด่นคือมีโอกาสเกิดธุรกรรมจำนวนมาก แต่ข้อแลกเปลี่ยนคือผลลัพธ์ไวต่อ Spread, Commission, Slippage, Latency และวิธีประมวลผลคำสั่งของโบรกเกอร์

EA ที่ทำกำไรก่อนต้นทุนเพียงเล็กน้อยอาจเปลี่ยนเป็นขาดทุนเมื่อใช้เงื่อนไขบัญชีจริง ดังนั้นการดูเพียง Equity Curve จาก Backtest ยังไม่พอ ต้องตรวจคุณภาพข้อมูล Tick สเปก Symbol เวลาซื้อขาย และผลต่างระหว่างราคาที่ร้องขอกับราคาที่ได้รับจริง

  • Scalping EA ทำงานแบบไหน

Scalping EA ทำงานแบบไหน

ไม่มีระยะเวลามาตรฐานเพียงค่าเดียวที่ทำให้ระบบกลายเป็น Scalping แต่โดยพฤติกรรมมักมีลักษณะร่วมกันดังนี้

  • ถือออเดอร์สั้นและตั้งเป้ากำไรต่อครั้งค่อนข้างแคบ
  • ใช้ข้อมูล Tick หรือการเปลี่ยนแปลงราคาภายในแท่งอย่างละเอียด
  • มีจำนวนธุรกรรมมากกว่าระบบ Swing หรือ Trend Following
  • ใช้เงื่อนไข Spread, ช่วงเวลา หรือความผันผวนเพื่อหลีกเลี่ยงตลาดที่ต้นทุนสูง
  • อาจส่งคำสั่งหลายครั้งภายในเวลาสั้น จึงต้องจัดการ Retcode และสถานะการประมวลผลอย่างรัดกุม

ระบบ Scalping ไม่จำเป็นต้องเป็น High-frequency Trading ในความหมายระดับสถาบัน แต่อาจใช้คำสั่งแบบ asynchronous ใน MQL5 เพื่อไม่ให้โปรแกรมหยุดรอ Server อย่างไรก็ตาม เอกสาร MQL5 ระบุชัดว่าการส่งคำขอสำเร็จไม่ได้รับประกันว่าคำสั่งถึง Server และถูกยอมรับแล้ว โปรแกรมยังต้องติดตาม Trade Transaction และผลตอบกลับจริง

Spread, Commission และ Slippage กระทบอย่างไร

Spread

Spread คือส่วนต่างระหว่างราคา Bid และ Ask เมื่อเปิด Buy จะเข้าที่ Ask และเมื่อปิดจะอ้างอิง Bid ส่วน Sell ทำในทิศทางกลับกัน ระบบที่ตั้ง Take Profit แคบจึงใช้สัดส่วนกำไรจำนวนมากไปกับ Spread หาก Spread ถ่างในช่วงข่าว เปิดตลาด หรือสภาพคล่องต่ำ ผลที่ได้อาจต่างจากช่วงปกติชัดเจน

Commission

บัญชีที่โฆษณา Spread ต่ำอาจคิด Commission แยกตาม Lot หรือรอบการเปิดปิด ต้องรวมต้นทุนนี้ทุกครั้งในการทดสอบ โดยเฉพาะระบบที่เปิดออเดอร์บ่อย การเปรียบเทียบบัญชีควรดู “ต้นทุนต่อรอบ” ไม่ใช่ดู Spread เพียงตัวเดียว

Slippage

Slippage คือผลต่างระหว่างราคาที่ระบบคาดหรือร้องขอกับราคาที่คำสั่งถูกดำเนินการจริง เกิดได้ทั้งทางบวกและลบ ขึ้นอยู่กับความเร็วตลาด สภาพคล่อง รูปแบบ Execution และตำแหน่งของราคาเมื่อคำสั่งถึง Server การตั้งค่า Deviation ไม่ได้ทำให้ Slippage หายไปในทุก Execution Mode

Swap และค่าถือข้ามคืน

Scalping ส่วนใหญ่ตั้งใจปิดภายในวัน แต่หากระบบค้างออเดอร์เมื่อผิดทางหรือมี Recovery Logic อาจถูกคิด Swap จึงต้องตรวจประวัติว่ามีสถานะข้ามคืนจริงหรือไม่ ไม่สรุปจากคำว่า Scalping ในชื่อระบบ

Latency คืออะไร และ VPS ช่วยอะไรได้บ้าง

Latency คือเวลาที่ข้อมูลหรือคำสั่งเดินทางระหว่าง MT5 กับ Trade Server หากเครื่องอยู่ห่าง Server มากหรือเส้นทางเครือข่ายไม่เสถียร คำสั่งอาจใช้เวลานานขึ้น VPS ที่ตั้งอยู่ใกล้ Server โบรกเกอร์และมีเครือข่ายเสถียรสามารถลดส่วนของความหน่วงจากเครื่องผู้ใช้และอินเทอร์เน็ตภายในบ้านได้

แต่ VPS ไม่สามารถควบคุมทุกส่วนของการส่งคำสั่ง เช่น Queue ภายใน Server, Liquidity, Execution Policy หรือการเปลี่ยนแปลงราคาระหว่างประมวลผล จึงไม่ควรใช้คำว่า “Ping ต่ำ” เป็นหลักฐานว่าผลจริงจะตรง Backtest หรือไม่มี Slippage

ควรวัด Ping จาก MT5 ไปยัง Server บัญชีจริงในช่วงเวลาต่าง ๆ และติดตาม Journal ว่ามี Requote, Off Quotes, Invalid Price หรือ Retcode อื่นหรือไม่ อ่านพื้นฐานการเลือกเครื่องได้ที่ VPS สำหรับรัน EA

วิธี Backtest Scalping EA ให้ใกล้เงื่อนไขจริงขึ้น

  1. ใช้ Real Ticks เมื่อมีข้อมูลเหมาะสม MetaTrader ระบุว่า Real Ticks สะท้อนการเปลี่ยน Spread ภายในนาทีได้ใกล้เงื่อนไขจริงกว่า Tick ที่สร้างจากข้อมูลหนึ่งนาที
  2. ใส่ Commission ตามประเภทบัญชี ตรวจว่ารายงานรวมค่าใช้จ่ายทั้งขาเปิดและปิดแล้ว
  3. ทดสอบ Spread หลายระดับ ไม่ใช้เฉพาะค่าต่ำสุดจากโฆษณาของบัญชี
  4. ทำ Slippage Stress Test เพิ่มผลกระทบราคาทั้งด้านเข้าและออกเพื่อดูว่าความได้เปรียบยังเหลือหรือไม่
  5. แยกช่วงเวลา ตรวจ Session ที่ระบบเทรดจริง รวมช่วง Rollover และข่าวสำคัญ
  6. ทำ Out-of-Sample และ Forward Test ไม่ปรับพารามิเตอร์จากข้อมูลทั้งหมดแล้วใช้ข้อมูลเดิมตัดสิน
  7. ดู Distribution ต่อ Trade หากกำไรเฉลี่ยต่อครั้งใกล้กับต้นทุนมาก ระบบจะเปราะบางต่อความคลาดเคลื่อนเล็กน้อย

อ่านวิธีประเมินค่าต่าง ๆ เพิ่มเติมได้ใน คู่มือ Profit Factor, Drawdown และ Win Rate และ คู่มืออ่านผล Backtest EA

สิ่งที่ต้องตรวจจากโบรกเกอร์และ Symbol

ชื่อ Symbol เดียวกันไม่ได้แปลว่าสเปกเหมือนกันทุกโบรกเกอร์ ใน MT5 ให้เปิด Market Watch คลิกขวาที่ Symbol แล้วเลือก Specification เพื่อตรวจข้อมูลต่อไปนี้

  • Spread แบบคงที่หรือลอยตัว
  • Digits, Point, Tick Size และ Tick Value
  • Contract Size และวิธีคำนวณ Margin
  • Stops Level และ Freeze Level
  • Execution Mode และ Filling Policy
  • Volume ขั้นต่ำ ขั้นสูง และ Volume Step
  • Trading Sessions และเวลาที่ Symbol เปิดให้ส่งคำสั่ง
  • Commission และ Swap ที่ใช้กับประเภทบัญชี

ก่อนเลือกบัญชีควรดูความน่าเชื่อถือและเงื่อนไขโดยรวม ไม่เลือกจาก Spread ต่ำเพียงอย่างเดียว ดูแนวทางได้ที่ วิธีเลือกโบรกเกอร์ที่รองรับ MT5

เช็กลิสต์ก่อนใช้ Scalping EA ด้วยเงินจริง

  • ผล Backtest ใช้ Tick และต้นทุนจากแหล่งใด
  • กำไรเฉลี่ยต่อ Trade มากกว่าต้นทุนรวมเพียงใด
  • ระบบมี Maximum Spread Filter และทำอะไรเมื่อ Spread เกินค่า
  • มีการจัดการคำสั่งที่ถูก Reject หรือ Fill บางส่วนอย่างไร
  • ถือออเดอร์ข้ามคืนหรือช่วงข่าวหรือไม่
  • ผล Forward Test ใช้โบรกเกอร์และประเภทบัญชีเดียวกับที่จะใช้จริงหรือไม่
  • Journal มีข้อผิดพลาดหรือความหน่วงผิดปกติหรือไม่
  • เมื่อเชื่อมต่อหลุด ระบบตรวจสถานะออเดอร์เดิมก่อนส่งคำสั่งใหม่หรือไม่

เริ่มจาก Demo หรือ Lot ต่ำและเก็บข้อมูล Execution จริงก่อนเพิ่มความเสี่ยง การตัดสินใจควรอิงผลหลังต้นทุนและ Drawdown ไม่ใช่จำนวนออเดอร์ชนะเพียงอย่างเดียว

คำเตือนความเสี่ยง: Scalping EA อาจได้รับผลกระทบจาก Spread, Commission, Slippage, Latency และเงื่อนไขของโบรกเกอร์ ผลทดสอบบนข้อมูลหรือบัญชีหนึ่งอาจไม่เกิดซ้ำบนอีกบัญชี การเทรดด้วย Leverage มีโอกาสขาดทุนสูงและไม่มีระบบใดรับประกันผลกำไร
