ใช้ได้ หน้าดาวน์โหลดทางการของ metatrader5.com ที่เปิดดูวันที่ 18 พฤศจิกายน 2026 มีลิงก์ For macOS อยู่ข้างปุ่มดาวน์โหลดสำหรับ Windows และลิงก์ For Linux ลิงก์ของ macOS ให้ไฟล์ติดตั้งที่ชื่อ MetaTrader5.pkg.zip ส่วนคู่มือของผู้พัฒนามีหน้าแยกชื่อ Installation on Mac OS อธิบายขั้นตอนไว้ครบ จึงเป็นทางที่ผู้พัฒนารองรับเอง ไม่ใช่วิธีลัดที่ผู้ใช้คิดกันขึ้นมา

แต่มีรายละเอียดที่ต้องรู้ก่อนโหลด เพราะตัวติดตั้งนี้ไม่ได้เป็นโปรแกรมที่เขียนขึ้นใหม่สำหรับ macOS โดยเฉพาะ และข้อนี้มีผลกับประสิทธิภาพและความเสถียรเวลารันระบบอัตโนมัติ บทความนี้ไล่ทั้งสิ่งที่คู่มือเขียนไว้ เงื่อนไขของเครื่อง และทางเลือกอื่นอีกสี่ทางที่มีอยู่จริง ถ้าเทียบกับขั้นตอนฝั่งวินโดวส์ อ่านได้ที่ วิธีติดตั้ง MT5 บนคอมพิวเตอร์ทีละขั้นตอน

หน้าดาวน์โหลดทางการมีอะไรให้บ้าง

สิ่งที่อยู่บนหน้าดาวน์โหลดตอนที่ตรวจมีห้ากลุ่ม กลุ่มแรกคือปุ่มดาวน์โหลดสำหรับ Windows กลุ่มที่สองคือลิงก์ For macOS กลุ่มที่สามคือลิงก์ For Linux กลุ่มที่สี่คือปุ่มเปิดเวอร์ชันที่ใช้ผ่านเบราว์เซอร์ และกลุ่มที่ห้าคือคิวอาร์โค้ดสี่ชุดสำหรับติดตั้งแอปมือถือ คือจาก App Store จาก Google Play จาก Huawei AppGallery และสำหรับดึงไฟล์ APK ของ Android โดยตรง

ลิงก์ของ macOS ชี้ไปที่ไฟล์ชื่อ MetaTrader5.pkg.zip ซึ่งเป็นชุดติดตั้งก้อนใหญ่ ไม่ใช่ตัวติดตั้งแบบเว็บขนาดเล็กเหมือนฝั่งวินโดวส์ที่คู่มือระบุว่าจะดึงส่วนประกอบเพิ่มระหว่างติดตั้ง จุดนี้มีผลในทางปฏิบัติคือการโหลดใช้เวลาและกินปริมาณข้อมูลอินเทอร์เน็ตมากกว่า ควรโหลดบนเครือข่ายที่ไม่จำกัดปริมาณ

คู่มือหน้า Installation on Mac OS ระบุช่องทางไว้สองทาง คือโหลดผ่านลิงก์บนหน้านั้น หรือเรียกจากเมนู Help ในแพลตฟอร์มที่ติดตั้งอยู่แล้ว ทางที่สองมีประโยชน์เวลาอยากอัปเดตตัวติดตั้งโดยไม่ต้องไปหาลิงก์ใหม่

สิ่งที่หน้าดาวน์โหลดไม่มีคือลิงก์แยกสำหรับชิปแต่ละรุ่น มีไฟล์ macOS ไฟล์เดียว ซึ่งตรงกับที่คู่มือเขียนไว้ว่ารองรับหน่วยประมวลผลของ Apple ทุกรุ่น

ตัวติดตั้งทำงานยังไง และคำว่าชั้นความเข้ากันได้คืออะไร

คู่มือเขียนไว้ตรงไปตรงมาว่าผู้พัฒนาจัดตัวติดตั้งเฉพาะสำหรับ macOS ไว้ให้ เป็นตัวช่วยติดตั้งแบบเต็มรูปที่ลงโปรแกรมให้เหมือนแอปทั่วไป และระบุขั้นตอนที่ตัวติดตั้งทำแทนให้ทั้งหมดไว้สี่ขั้น คือระบุระบบของเครื่อง ดาวน์โหลดและติดตั้ง Wine เวอร์ชันล่าสุด ตั้งค่า Wine ให้ แล้วจึงติดตั้ง MetaTrader ลงไปข้างใน คู่มือบอกว่าทุกขั้นทำแบบอัตโนมัติ และใช้งานได้ทันทีหลังติดตั้งเสร็จ

คำว่า Wine ที่ปรากฏในขั้นตอนนั้นคือหัวใจของเรื่อง บทความของผู้พัฒนาที่ว่าด้วยการติดตั้งบน Linux นิยามไว้ว่า Wine เป็นชั้นความเข้ากันได้แบบฟรี ที่ทำให้ซอฟต์แวร์ซึ่งเขียนขึ้นสำหรับ Microsoft Windows ทำงานบนระบบปฏิบัติการตระกูลยูนิกซ์ได้ แปลว่าโปรแกรมที่รันอยู่บนแมคของคุณคือตัวเดียวกับเวอร์ชันวินโดวส์ ไม่ใช่โปรแกรมที่เขียนใหม่สำหรับ macOS

ข้อนี้ไม่ใช่เรื่องเสียหาย แต่มีผลสองอย่างที่ควรรู้ อย่างแรกคือมีชั้นแปลคำสั่งเพิ่มเข้ามาระหว่างโปรแกรมกับระบบปฏิบัติการ อย่างที่สองคือตัวชั้นแปลนั้นเป็นอีกองค์ประกอบที่มีเวอร์ชันของตัวเองและต้องดูแล ซึ่งคู่มือพูดถึงเรื่องนี้ไว้ชัด

คู่มือระบุว่าถ้าใช้แพลตฟอร์มบน macOS อยู่แล้ว ให้ตรวจเวอร์ชันของ Wine ที่ใช้อยู่ ซึ่งแสดงอยู่ในบันทึกเหตุการณ์ของแพลตฟอร์มตอนเปิดโปรแกรม และระบุว่าถ้าเวอร์ชันต่ำกว่า 8.0.1 ผู้พัฒนาแนะนำอย่างยิ่งให้ถอนแพลตฟอร์มเก่าออกพร้อมกับ Wine prefix ที่มันติดตั้งอยู่ โดยสำรองไฟล์ที่จำเป็นไว้ก่อน ทั้งเทมเพลต โปรแกรมอัตโนมัติที่โหลดมา และอินดิเคเตอร์ ขั้นตอนถอนคือย้ายโปรแกรมจากโฟลเดอร์ Applications ไปถังขยะตามปกติ แล้วลบโฟลเดอร์ของ Wine ผ่าน Finder ด้วยเมนูไปยังโฟลเดอร์

ขั้นสำรองไฟล์ก่อนลงใหม่คือขั้นที่คนข้ามบ่อยและเสียหายจริง ไฟล์ตั้งค่าของระบบอัตโนมัติ เทมเพลตกราฟ และตัวไฟล์โปรแกรมที่โหลดมา อยู่ในโฟลเดอร์ข้อมูลของแพลตฟอร์มซึ่งถูกลบไปพร้อม Wine prefix ถ้าลบก่อนสำรอง จะต้องตั้งค่าใหม่หมดและต้องไปขอไฟล์จากคนขายอีกรอบ

เครื่องต้องเป็นแบบไหน และไฟล์ไปอยู่ที่ไหน

คู่มือระบุเงื่อนไขขั้นต่ำไว้สองข้อ ข้อแรกคือเวอร์ชัน macOS ต่ำสุดที่ติดตั้งได้คือ Catalina รุ่น 10.15.7 ข้อที่สองคือรองรับหน่วยประมวลผลของ Apple ทุกรุ่น ตั้งแต่ M1 ไปจนถึงรุ่นล่าสุดที่ออกมา และคู่มือระบุว่าแพลตฟอร์มทำงานได้บน macOS ทุกเวอร์ชันสมัยใหม่

ระหว่างติดตั้ง คู่มือบอกว่าให้เปิดไฟล์ที่โหลดมาแล้วทำตามคำแนะนำเหมือนลงแอปทั่วไป และจะมีหน้าต่างขอให้ติดตั้งแพ็กเกจเพิ่มของ Wine สองตัว คือ Mono และ Gecko คู่มือบอกให้ตอบตกลง เพราะสองตัวนี้จำเป็นต่อการทำงานของแพลตฟอร์ม คนที่กดปฏิเสธเพราะไม่รู้ว่ามันคืออะไร มักกลับมาเจอว่าบางหน้าต่างของโปรแกรมเปิดไม่ขึ้น

เรื่องตำแหน่งไฟล์ต่างจากฝั่งวินโดวส์พอสมควร คู่มือระบุว่า Wine จะสร้างไดรฟ์เสมือนแยกขึ้นมาให้แพลตฟอร์มพร้อมสภาพแวดล้อมที่จำเป็น และโฟลเดอร์ข้อมูลของแพลตฟอร์มตามค่าเริ่มต้นอยู่ลึกเข้าไปในโฟลเดอร์ Application Support ของผู้ใช้ ใต้ชื่อที่ขึ้นต้นด้วย net.metaquotes.wine ตามด้วยไดรฟ์เสมือนและโฟลเดอร์โปรแกรม ใครที่ต้องเอาไฟล์ระบบอัตโนมัติไปวางในโฟลเดอร์ Experts ต้องเดินเข้าไปตามเส้นทางนี้ ไม่ใช่ที่เดียวกับฝั่งวินโดวส์

อีกข้อที่คู่มือเขียนไว้และแก้ยากถ้ารู้ช้าคือเรื่องภาษาหน้าจอ คู่มือระบุว่าตอนติดตั้ง Wine จะเพิ่มการรองรับภาษาที่ macOS ตั้งอยู่ ณ ตอนนั้นให้โดยอัตโนมัติ ซึ่งคู่มือบอกว่าเพียงพอในกรณีส่วนใหญ่ แต่ถ้าต้องการใช้ภาษาอื่นกับแพลตฟอร์ม ให้สลับภาษาของ macOS ไปเป็นภาษานั้นก่อนติดตั้ง รีสตาร์ทเครื่อง แล้วจึงติดตั้ง หลังเสร็จจะสลับภาษาของ macOS กลับได้

ทางอื่นที่มีอยู่จริง

ทางที่สองคือแอปเวอร์ชันมือถือ คู่มือ MetaTrader 5 ฝั่ง iPhone ระบุไว้ในหน้าเริ่มต้นใช้งานว่าแอปนี้ทำงานบน iPhone, iPad และ iPod ที่เป็น iOS 9.0 ขึ้นไป และทำงานบนเครื่องตั้งโต๊ะที่ใช้ชิป M1 และ macOS Big Sur ขึ้นไปได้ด้วย ข้อดีคือติดตั้งง่ายที่สุดในทุกทาง ข้อจำกัดคือมันยังเป็นแอปเวอร์ชันมือถือ ซึ่งสารบัญคู่มือไม่มีหมวดการเทรดอัตโนมัติและไม่มีหมวดตัวทดสอบกลยุทธ์ รายละเอียดของข้อจำกัดนี้อยู่ที่ รันบอทเทรดบนมือถือได้ไหม ข้อจำกัดคืออะไร

ทางที่สามคือเวอร์ชันที่ใช้ผ่านเบราว์เซอร์ หน้าดาวน์โหลดอธิบายไว้ว่าใช้ได้โดยไม่ต้องดาวน์โหลดหรือติดตั้งโปรแกรมอะไรเลย และเทรดได้จากเบราว์เซอร์และระบบปฏิบัติการใดก็ได้ ขอแค่มีอินเทอร์เน็ต เหมาะกับการเข้าไปดูพอร์ตหรือปิดไม้เร็ว ๆ จากเครื่องที่ลงโปรแกรมไม่ได้ ข้อจำกัดคือไม่ได้มีส่วนของโปรแกรมอัตโนมัติและตัวทดสอบ

ทางที่สี่คือรันวินโดวส์เป็นเครื่องเสมือนอยู่บนแมค แล้วติดตั้งแพลตฟอร์มเวอร์ชันวินโดวส์ลงไปข้างใน ข้อที่ต้องรู้คือคู่มือหมวดการติดตั้งของผู้พัฒนามีสามหน้า คือการติดตั้งทั่วไป การติดตั้งบน Mac OS และการติดตั้งบน Linux ไม่มีหน้าที่ว่าด้วยการรันผ่านเครื่องเสมือน แปลว่าทางนี้ไม่มีคู่มือทางการมารองรับ และสิ่งที่ต้องตรวจเองคือซอฟต์แวร์สร้างเครื่องเสมือนที่เลือกรองรับชิปของเครื่องคุณหรือไม่ และวินโดวส์ที่จะลงในนั้นเป็นรุ่นที่แพลตฟอร์มรองรับหรือไม่ บวกค่าไลเซนส์วินโดวส์และทรัพยากรเครื่องที่ต้องแบ่งไปให้

ทางที่ห้าคือไม่ใช้แมครันเลย แต่ไปเช่าเครื่องหรือแพลตฟอร์มเสมือนให้รันแทน หน้าบริการแพลตฟอร์มเสมือนของผู้พัฒนาเขียนหัวเรื่องไว้ว่าให้รันโปรแกรมอัตโนมัติและการติดตามสัญญาณได้ตลอดยี่สิบสี่ชั่วโมงเจ็ดวัน ระบุว่าบริการทำงานต่อแม้คอมพิวเตอร์ของผู้ใช้จะปิดอยู่ บอกว่าเช่าได้จากในแพลตฟอร์มโดยตรง และระบุว่ากระบวนการจะย้ายโปรแกรมอัตโนมัติ อินดิเคเตอร์ สคริปต์ และการติดตามสัญญาณ ไปอยู่บนเซิร์ฟเวอร์นั้น

เทียบห้าทาง แล้วเลือกอย่างไร

ทางเลือก รันระบบอัตโนมัติได้ไหม ข้อจำกัดหลัก
ตัวติดตั้งสำหรับ macOS จากหน้าดาวน์โหลดทางการ ได้ เพราะเป็นแพลตฟอร์มเวอร์ชันคอมพิวเตอร์เต็ม ทำงานผ่านชั้นความเข้ากันได้ ต้อง macOS 10.15.7 ขึ้นไป และเครื่องต้องเปิดค้างตลอดช่วงที่ตลาดเปิด
แอป MT5 เวอร์ชัน iPhone บนเครื่องชิป Apple ไม่ได้ เป็นแอปมือถือ ไม่มีหมวดการเทรดอัตโนมัติ ต้องเป็นชิป M1 และ macOS Big Sur ขึ้นไป
เวอร์ชันที่ใช้ผ่านเบราว์เซอร์ ไม่ได้ ไม่ต้องติดตั้งอะไร แต่ไม่มีส่วนของโปรแกรมอัตโนมัติและตัวทดสอบ
วินโดวส์เสมือนบนแมค ได้ ถ้าวินโดวส์ในนั้นตรงเงื่อนไขของแพลตฟอร์ม ไม่มีคู่มือทางการรองรับ ต้องมีไลเซนส์วินโดวส์ ต้องแบ่งทรัพยากรเครื่อง และต้องตรวจความเข้ากันได้กับชิปเอง
เช่าแพลตฟอร์มเสมือนหรือเครื่องเช่า ได้ และทำงานต่อแม้ปิดแมค มีค่าเช่า และต้องรีโมทเข้าไปจัดการเมื่อต้องเปลี่ยนค่า

วิธีเลือกให้ตัดจากเป้าหมายก่อน ถ้าเป้าหมายคือดูกราฟ วิเคราะห์ และส่งคำสั่งด้วยมือ ตัวติดตั้ง macOS ทางการพอแล้ว ถ้าเป้าหมายคือดูพอร์ตระหว่างวันโดยไม่อยากลงอะไร เวอร์ชันเบราว์เซอร์หรือแอปเวอร์ชันมือถือเร็วกว่า

แต่ถ้าเป้าหมายคือรันระบบอัตโนมัติแบบต่อเนื่อง ข้อที่ตัดสินไม่ใช่เรื่องว่าแมครันได้หรือไม่ ข้อที่ตัดสินคือเครื่องเปิดค้างได้หรือไม่ แมคที่ปิดฝาแล้วหลับหรือถูกยกไปไหนมาไหนด้วยทุกวัน ไม่เหมาะเป็นเครื่องรันระบบตั้งแต่ต้น ไม่ว่าจะติดตั้งสำเร็จแค่ไหน เกณฑ์เลือกและค่าใช้จ่ายของทางเช่าอยู่ที่ VPS สำหรับรัน EA คืออะไร จำเป็นไหม เลือกยังไง และคำถามที่คนถามบ่อยที่สุดเรื่องการรีโมทอยู่ที่ ปิด Remote Desktop แล้ว EA ยังรันอยู่ไหม

ข้อควรระวังที่คนใช้แมคเจอบ่อย

ข้อแรกคือเส้นทางโฟลเดอร์ไม่เหมือนที่คู่มือทั่วไปหรือคลิปสอนฝั่งวินโดวส์บอก เวลาต้องเอาไฟล์ระบบอัตโนมัติไปวาง ต้องเข้าไปที่โฟลเดอร์ข้อมูลใต้ Application Support ตามที่คู่มือ macOS ระบุ ไม่ใช่ที่ Program Files ตรง ๆ คนที่วางผิดที่แล้วไม่เห็นชื่อโปรแกรมในหน้าต่าง Navigator มักคิดว่าไฟล์เสีย

ข้อที่สองคือเวอร์ชันของชั้นความเข้ากันได้ ถ้าเคยติดตั้งไว้นานแล้วและเวอร์ชันต่ำกว่าที่คู่มือแนะนำ อาการที่เจอมักเป็นหน้าต่างบางอันเปิดไม่ขึ้นหรือโปรแกรมปิดตัวเอง วิธีตรวจคือดูบันทึกเหตุการณ์ตอนเปิดโปรแกรมตามที่คู่มือบอก แล้วถ้าต่ำกว่าเกณฑ์ก็ลงใหม่ตามขั้นที่คู่มือเขียนไว้ หลังสำรองไฟล์เรียบร้อย

ข้อที่สามคือการตั้งค่าเครื่องให้ไม่หลับ ระบบอัตโนมัติต้องรออ่านราคาที่ไหลเข้ามา เครื่องที่เข้าโหมดประหยัดพลังงานหรือหลับเมื่อปิดฝา จะทำให้โปรแกรมหยุดรับราคาไปเงียบ ๆ โดยไม่มีข้อความเตือน

ข้อที่สี่คืออย่าสรุปว่าอาการที่เจอเป็นเพราะใช้แมค อาการหลายอย่างที่คนโทษเรื่องระบบปฏิบัติการ จริง ๆ เป็นเรื่องสิทธิ์การเทรดอัตโนมัติ ชื่อสินค้าในบัญชีไม่ตรง หรือไฟล์วางผิดโฟลเดอร์ ซึ่งเกิดบนวินโดวส์เหมือนกัน รายการสาเหตุที่เจอบ่อยอยู่ที่ EA ไม่ทำงานบน MT5 แก้ยังไง รวมสาเหตุที่เจอบ่อย ส่วนไฟล์และขั้นตอนเริ่มใช้งานของทางเราอยู่ที่ หน้าเริ่มใช้งานและดาวน์โหลด

สรุป

สรุป: ใช้ MT5 บนแมคได้ และเป็นทางที่ผู้พัฒนารองรับเอง หน้าดาวน์โหลดทางการที่ตรวจเมื่อวันที่ 18 พฤศจิกายน 2026 มีลิงก์ For macOS อยู่ข้างปุ่มสำหรับ Windows และลิงก์ For Linux พร้อมปุ่มเปิดเวอร์ชันเบราว์เซอร์และคิวอาร์โค้ดสำหรับ App Store, Google Play, Huawei AppGallery และไฟล์ APK ลิงก์ของ macOS ให้ไฟล์ชื่อ MetaTrader5.pkg.zip และคู่มือมีหน้าแยกชื่อ Installation on Mac OS กลไกที่คู่มืออธิบายคือตัวติดตั้งจะระบุระบบของเครื่อง ดาวน์โหลดและติดตั้ง Wine เวอร์ชันล่าสุด ตั้งค่าให้ แล้วติดตั้ง MetaTrader ลงไปข้างใน โดย Wine คือชั้นความเข้ากันได้ที่ทำให้โปรแกรมของวินโดวส์ทำงานบนระบบตระกูลยูนิกซ์ได้ เงื่อนไขเครื่องคือ macOS ขั้นต่ำ Catalina รุ่น 10.15.7 และรองรับหน่วยประมวลผลของ Apple ทุกรุ่นตั้งแต่ M1 ขึ้นไป ระหว่างติดตั้งจะถูกถามให้ลงแพ็กเกจ Mono และ Gecko ซึ่งคู่มือบอกให้ตอบตกลง โฟลเดอร์ข้อมูลอยู่ใต้ Application Support ของผู้ใช้ ไม่ใช่ที่เดียวกับฝั่งวินโดวส์ และคู่มือเตือนว่าถ้า Wine ที่ใช้อยู่ต่ำกว่าเวอร์ชัน 8.0.1 ให้ถอนแพลตฟอร์มเก่าพร้อม Wine prefix ออกหลังสำรองไฟล์แล้ว ทางเลือกอื่นมีอีกสี่ทาง คือแอปเวอร์ชัน iPhone ที่คู่มือระบุว่าใช้บนเครื่องชิป M1 กับ macOS Big Sur ขึ้นไปได้แต่ไม่มีหมวดการเทรดอัตโนมัติ เวอร์ชันเบราว์เซอร์ที่ไม่ต้องติดตั้งแต่ก็ไม่มีส่วนของโปรแกรมอัตโนมัติ วินโดวส์เสมือนที่ไม่มีคู่มือทางการรองรับ และการเช่าแพลตฟอร์มเสมือนซึ่งผู้พัฒนาระบุว่าทำงานต่อแม้คอมพิวเตอร์ของผู้ใช้ปิดอยู่ ถ้าเป้าหมายคือรันระบบต่อเนื่อง ข้อที่ตัดสินไม่ใช่เรื่องระบบปฏิบัติการ แต่เป็นเรื่องว่าเครื่องเปิดค้างได้หรือไม่

คำเตือนความเสี่ยง: การเทรดด้วยมาร์จิ้นมีความเสี่ยงสูงและอาจทำให้สูญเงินลงทุนทั้งจำนวน การติดตั้งแพลตฟอร์มได้สำเร็จบนเครื่องใดก็ตามไม่ได้ทำให้ผลการเทรดดีขึ้น และการรันผ่านชั้นความเข้ากันได้หรือผ่านเครื่องเสมือนเพิ่มจุดที่อาจเกิดปัญหาทางเทคนิคได้ ทั้งเรื่องความเสถียรและเรื่องเวลาในการส่งคำสั่ง ซึ่งอาจทำให้ผลต่างจากที่ทดสอบไว้ ระบบที่หยุดทำงานกลางทางอาจทิ้งสถานะที่เปิดอยู่ไว้โดยไม่มีการจัดการ บทความนี้เป็นข้อมูลทั่วไปเกี่ยวกับการใช้งานโปรแกรม ไม่ใช่คำแนะนำการลงทุน ใช้เฉพาะเงินที่พร้อมรับความเสียหายและไม่มีกำหนดต้องใช้ อ่าน คำเตือนความเสี่ยงฉบับเต็ม
