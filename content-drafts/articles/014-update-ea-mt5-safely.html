การอัปเดต EA บน MT5 ไม่ควรเริ่มด้วยการลากไฟล์ EX5 ใหม่ทับของเดิมทันที เพราะ EA อาจเปลี่ยน Input, วิธีอ่าน Position, License หรือไฟล์ประกอบ หากมี Position ค้างอยู่ การ Restart หรือถอด EA อาจทำให้ฟังก์ชันที่ทำงานใน Terminal เช่น Trailing Stop, Break Even หรือ Basket Exit หยุดชั่วคราว

ขั้นตอนที่ดีต้องตอบได้สามคำถาม: ถ้าไฟล์ใหม่มีปัญหาจะย้อนกลับอย่างไร, Preset เดิมเข้ากันได้หรือไม่ และ Position ที่เปิดอยู่จะถูก Version ใหม่รับช่วงอย่างไร หากตอบไม่ได้ควรทดสอบในสภาพแวดล้อมแยกก่อน

สารบัญ

  • สิ่งที่ต้องเช็กก่อนอัปเดต
  • รายการ Backup
  • ขั้นตอนอัปเดตทีละขั้น
  • กรณีมี Position ค้าง
  • ตรวจหลังอัปเดต
  • วิธี Rollback

ก่อนอัปเดตต้องอ่านอะไร

  • Release Notes: มีการแก้ Bug, เปลี่ยนกลยุทธ์ หรือเพิ่ม Parameter ใด
  • Minimum MT5 Build: ไฟล์ใหม่ต้องใช้แพลตฟอร์มรุ่นใด
  • Preset Compatibility: SET รุ่นเก่าโหลดต่อได้หรือจำเป็นต้องสร้างใหม่
  • Position Migration: EA ใหม่รับ Position ของ Version เดิมจาก Magic/Comment อย่างไร
  • License: ต้อง Activate ใหม่หรือผูกเครื่อง/บัญชีเดิมได้
  • Dependencies: มี Indicator, Library หรือ URL เพิ่มหรือไม่

หาก Release Notes ไม่ชัดและมี Position จริงค้าง ให้ติดต่อผู้พัฒนาก่อน การรอจังหวะที่ไม่มี Position อาจง่ายและเสี่ยงน้อยกว่าการอัปเดตกลางรอบ แต่ต้องใช้วิธีหยุด Entry ที่ผู้พัฒนารองรับ ไม่ใช่ปิด Terminal แบบกะทันหัน

ต้องสำรองอะไรบ้าง

  1. ไฟล์ EX5 Version เดิมและไฟล์ประกอบ
  2. ไฟล์ SET ที่ใช้งานจริงทุกกราฟ
  3. Screenshot หน้า Inputs และ Common
  4. รายชื่อกราฟ Symbol, Timeframe และ Magic Number
  5. รายการ Position/Pending Order ที่ค้าง
  6. Experts/Journal ช่วงก่อนอัปเดต
  7. โฟลเดอร์ Profile หรือ Template หากใช้กู้ Workspace
  8. หมายเลข MT5 Build, EA Version และเวลาที่สำรอง

เก็บ Backup นอก VPS อย่างน้อยหนึ่งชุด เพราะหาก Disk หรือ Windows มีปัญหา ไฟล์ที่วางอยู่เครื่องเดียวกันไม่ถือว่าเป็นสำเนาสำรองที่ใช้งานได้

เรียนรู้การจัดไฟล์ Input จาก วิธีบันทึกและโหลดไฟล์ SET และตำแหน่งโปรแกรมจาก ไฟล์ EX5 กับ MQ5 ต่างกันอย่างไร

ขั้นตอนอัปเดต EA บน MT5

1. ทดสอบไฟล์ใหม่ใน Terminal สำรอง

ติดตั้ง MT5 แยก Directory หรือใช้เครื่องทดสอบ เปิด Demo ที่มีสเปกใกล้บัญชีจริง ติดตั้งไฟล์ใหม่และโหลด Preset สำเนา ตรวจว่าค่า Mapping ครบและไม่มี Error

2. หยุดการเปิดออเดอร์ใหม่

ใช้ Switch หรือ Schedule ที่ EA รองรับ หากไม่มีให้สอบถามผู้พัฒนา อย่าปิด Algo Trading โดยไม่เข้าใจผลต่อการจัดการ Position เพราะอาจหยุดทั้ง Entry และ Exit ที่ทำงานจาก EA

3. บันทึกสถานะปัจจุบัน

ทำ Backup ตามรายการ จดจำนวน Position, Equity, Margin และ Magic เพื่อเทียบหลังอัปเดต ไม่ใช้ความจำจากหน้าจออย่างเดียว

4. ปิด MT5 แล้วเปลี่ยนไฟล์

เปิด Data Folder ให้ถูก Terminal ปิดโปรแกรมเพื่อให้แน่ใจว่าไฟล์ไม่ถูกใช้งาน จากนั้นย้ายไฟล์เดิมไปโฟลเดอร์ Backup และคัดลอกไฟล์ใหม่พร้อม Dependencies ตามโครงเดิม

5. เปิด MT5 และโหลดค่าที่ตรวจแล้ว

ตรวจชื่อ/Version ของ EA เปิด Properties และโหลด Preset ที่ตรงรุ่น เปรียบเทียบค่าหลักกับ Screenshot ก่อนหน้า หาก Schema เปลี่ยนให้ใช้ Preset รุ่นใหม่ ไม่บังคับ SET เก่าทับ

6. ตรวจ Log ก่อนเปิด Entry

ดู Experts/Journal ว่า Initialize, License, Connection และการตรวจ Position ผ่าน ตรวจว่า EA เห็น Position เดิมจำนวนถูกต้อง แล้วจึงเปิดรับสัญญาณใหม่ตามขั้นตอน

ถ้ามี Position ค้างควรทำอย่างไร

มีสามแนวทาง แต่ต้องเลือกตามการออกแบบของ EA:

  • รอให้รอบจบ: เหมาะเมื่อหยุด Entry ใหม่ได้และ Position เดิมยังถูกจัดการตามแผน
  • ให้ Version ใหม่รับช่วง: ใช้ได้เมื่อผู้พัฒนายืนยัน Compatibility ของ Magic/State และมีขั้นตอนชัดเจน
  • จัดการ Position ด้วยมือ: เป็นการเปลี่ยนแผนเทรด ต้องประเมินความเสี่ยงและไม่ควรทำเพียงเพื่อให้อัปเดตเร็วขึ้น

Stop Loss/Take Profit ที่วางบน Server อาจยังทำงานเมื่อ EA ถูกปิด แต่ Trailing, Break Even, Time Exit, Basket Stop หรือ Equity Stop ที่คำนวณใน Terminal จะไม่ทำงานระหว่างที่ EA หยุด จึงต้องรู้ว่าแต่ละระบบใช้ส่วนใด

เช็กลิสต์หลังอัปเดต

  • ชื่อ EA และ Version ตรง Release Notes
  • Preset/Inputs ตรงกับค่าที่อนุมัติ
  • Magic Number ไม่เปลี่ยนโดยไม่ตั้งใจ
  • EA เห็น Position เดิมครบและไม่สร้างรายการซ้ำ
  • Algo Trading และ Permission อยู่ในสถานะถูกต้อง
  • Experts/Journal ไม่มี Error หรือ Warning ที่ไม่เข้าใจ
  • Symbol, Timeframe, Server Time และ Trading Session ถูกต้อง
  • Dashboard/สถานะบนกราฟแสดงค่าตรงบัญชี
  • ทดสอบ Restart หนึ่งครั้งใน Demo ก่อน Production

ควรเฝ้าดูอย่างน้อยหนึ่งรอบการทำงานจริงและเปรียบเทียบ Order Comment, Lot, Stop, Filter กับ Version เดิม หากพฤติกรรมต่าง ให้หยุดเพิ่มความเสี่ยงและตรวจ Release Notes/Log ก่อน

วางแผน Rollback อย่างไร

  1. หยุด Entry ใหม่โดยไม่ทำให้ Position ถูกทิ้ง
  2. เก็บ Log ของ Version ใหม่ก่อนปิด
  3. ปิด Terminal และย้ายไฟล์ใหม่ออก
  4. คืน EX5, Dependencies และ Preset รุ่นเดิมจาก Backup
  5. เปิด Terminal ตรวจ Version และ Position Mapping
  6. ดู Experts/Journal ว่าระบบเดิมเริ่มทำงานครบ
  7. บันทึกสาเหตุและเงื่อนไขที่ทำให้ Rollback

Rollback ไม่ควรหมายถึง “หาไฟล์เก่าจากแชต” เพราะอาจได้คนละรุ่น ต้องเก็บ Artifact ที่ระบุ Version และ Hash/วันที่ไว้ตั้งแต่ก่อนอัปเดต

สำหรับข่าว Version ของ FENIX PRO ให้ติดตามเฉพาะประกาศจริงที่ อัปเดต FENIX PRO EA และอย่าติดตั้งไฟล์จากลิงก์ส่งต่อที่ไม่สามารถยืนยันแหล่งได้

คำเตือนความเสี่ยง: การอัปเดตกลางรอบอาจทำให้ฟังก์ชันจัดการ Position เปลี่ยนหรือหยุดชั่วคราว ทดสอบไฟล์และแผนย้อนกลับก่อนดำเนินการกับบัญชีเงินจริง
