คำว่า “EA” บอกเพียงว่าเป็น Expert Advisor ที่ทำงานบนแพลตฟอร์ม MetaTrader แต่ไม่ได้บอกว่าระบบเข้าออเดอร์อย่างไร จัดการออเดอร์แบบไหน หรือรับความเสี่ยงมากเพียงใด EA สองตัวอาจใช้บน MT5 เหมือนกัน แต่มีพฤติกรรมของพอร์ตต่างกันอย่างสิ้นเชิง เพราะกลยุทธ์ การกำหนดขนาด Lot และกฎปิดสถานะไม่เหมือนกัน

บทความนี้จะแยก EA ที่พบได้บ่อยออกเป็น 4 กลุ่ม ได้แก่ Trend Following, Grid, Martingale และ Scalping เพื่อให้มองระบบได้ลึกกว่าคำว่า “อัตโนมัติ” และรู้ว่าควรถามอะไรจากผู้พัฒนาหรือผู้ขายก่อนนำไปทดสอบ ทั้งนี้ EA หนึ่งตัวอาจผสมหลายแนวคิดเข้าด้วยกัน จึงไม่ควรตัดสินประเภทจากชื่อทางการตลาดเพียงอย่างเดียว

ควรแบ่งประเภท EA จากอะไร

การแบ่งประเภทที่มีประโยชน์ควรดูอย่างน้อย 3 ชั้นพร้อมกัน ไม่ใช่ดูเฉพาะจังหวะเข้าออเดอร์

  1. ตรรกะการหาโอกาสเทรด เช่น ตามแนวโน้ม สวนแนวโน้ม ทะลุกรอบ หรือเก็บการแกว่งตัวระยะสั้น
  2. วิธีจัดการสถานะ เช่น เปิดครั้งละหนึ่งออเดอร์ วางออเดอร์หลายระดับ เพิ่มสถานะเมื่อราคาผิดทาง หรือทยอยปิดกำไร
  3. วิธีกำหนดความเสี่ยง เช่น Fixed Lot, คำนวณ Lot ตามเปอร์เซ็นต์, เพิ่ม Lot หลังขาดทุน หรือจำกัดผลขาดทุนรวมของพอร์ต

MetaTrader อธิบายว่า Expert Advisor เป็นโปรแกรมที่สามารถวิเคราะห์ข้อมูลและส่งคำสั่งซื้อขายตามตรรกะที่เขียนไว้ แต่ตัวแพลตฟอร์มไม่ได้รับรองว่าตรรกะนั้นเหมาะกับผู้ใช้ทุกคน ดังนั้นก่อนแยกประเภท ควรเข้าใจ พื้นฐานว่า EA คืออะไร และ กลไกการทำงานของ EA ก่อน

1. Trend Following EA: เทรดตามแนวโน้ม

Trend Following EA พยายามเข้าเทรดไปในทิศทางเดียวกับแนวโน้มที่ระบบตรวจพบ อาจใช้เส้นค่าเฉลี่ย การทะลุกรอบ ราคา High/Low หรือชุดเงื่อนไขหลายตัวประกอบกัน แนวคิดหลักคือยอมให้มีออเดอร์ที่ขาดทุนขนาดเล็กหรือสัญญาณหลอก แลกกับโอกาสถือสถานะเมื่อเกิดแนวโน้มที่ชัดเจน

จุดแข็งที่มักพบ

  • กติกาเข้าและออกสามารถอธิบายและทดสอบย้อนหลังได้ค่อนข้างชัด
  • หากมี Stop Loss ทุกออเดอร์ จะเห็นขอบเขตความเสียหายต่อครั้งได้ง่ายกว่าแนวทางที่สะสมสถานะ
  • เหมาะกับการวิเคราะห์แยกตามสภาวะตลาด เพราะจะเห็นชัดว่าระบบได้เปรียบเมื่อเกิดแนวโน้มและเสียเปรียบเมื่อราคาแกว่งกลับไปมา

ข้อจำกัดที่ต้องเข้าใจ คือช่วง Sideway อาจเกิดสัญญาณหลอกต่อเนื่อง และผลลัพธ์อาจมีช่วงขาดทุนหลายครั้งติดกัน ผู้ใช้จึงไม่ควรดูเพียง Win Rate แต่ต้องอ่าน Profit Factor, Average Win/Loss, Drawdown และระยะเวลาฟื้นตัวร่วมกัน ดูแนวทางต่อได้ใน คู่มืออ่านผล Backtest EA

2. Grid EA: วางออเดอร์หลายระดับราคา

Grid EA ใช้แนวคิดแบ่งระดับราคาเป็นช่วง ๆ แล้วเปิดหรือวางออเดอร์เมื่อราคาเคลื่อนผ่านแต่ละระดับ ระบบบางตัววางทั้ง Buy และ Sell ขณะที่บางตัวเพิ่มสถานะเพียงด้านเดียว เป้าหมายอาจเป็นการเก็บกำไรจากการแกว่งตัว หรือคำนวณราคาเฉลี่ยของสถานะรวม

คำว่า Grid ไม่ได้แปลว่า Martingale เสมอไป เพราะ Grid บอกโครงสร้างการวางออเดอร์ ส่วน Martingale บอกวิธีเพิ่มขนาดความเสี่ยงหลังผลลัพธ์ที่ไม่เป็นไปตามแผน Grid ที่ใช้ Lot เท่ากันทุกระดับก็มี แต่ถึงไม่เพิ่ม Lot ความเสี่ยงรวมยังเพิ่มขึ้นได้เมื่อจำนวนออเดอร์สะสมมากขึ้น

จุดที่ต้องตรวจให้ชัดคือจำนวนชั้นสูงสุด ระยะห่างระหว่างชั้น Lot รวมสูงสุด จุดหยุดสะสมออเดอร์ และเงื่อนไขปิดขาดทุนทั้งชุด หากผู้ขายแสดงเฉพาะ Balance แต่ไม่แสดง Equity อาจทำให้มองไม่เห็น Floating Loss ที่ยังไม่ถูกปิด จึงต้องอ่านรายงานโดยดู Balance และ Equity ควบคู่กัน

3. Martingale EA: เพิ่มขนาดสถานะหลังขาดทุน

Martingale EA เพิ่มขนาด Lot หลังออเดอร์หรือชุดออเดอร์ขาดทุน โดยหวังว่าเมื่อเกิดออเดอร์ที่ชนะ กำไรจะชดเชยผลขาดทุนก่อนหน้าได้ วิธีเพิ่มอาจเป็นสองเท่า หรือใช้ตัวคูณที่ต่ำกว่านั้น ระบบจึงอาจแสดง Win Rate สูงและ Equity Curve ที่ดูนิ่งเป็นเวลานาน ก่อนจะเกิด Drawdown ใหญ่เมื่อเจอลำดับการเคลื่อนไหวที่ยาวกว่าที่ระบบรองรับ

ความเสี่ยงสำคัญไม่ได้อยู่ที่ออเดอร์แรก แต่อยู่ที่การเติบโตของ Exposure เมื่อเพิ่ม Lot หลายครั้งติดต่อกัน ข้อจำกัดของเงินทุน Margin และจำนวนระดับที่ระบบเปิดได้จริง ทำให้คำอธิบายว่า “รอให้ราคากลับก็จบ” ไม่เพียงพอสำหรับการประเมินความเสี่ยง

ก่อนใช้ควรขอดู Lot ของทุกออเดอร์ ไม่ใช่ดูเฉพาะกำไรรวม ตรวจว่าใช้ Stop Loss หรือ Equity Stop หรือไม่ และจำลองกรณีที่ราคาเคลื่อนทางเดียวต่อเนื่อง พร้อมศึกษา วิธีอ่าน Drawdown เพื่อดูความเสียหายจาก Equity ไม่ใช่ดูเฉพาะออเดอร์ที่ปิดแล้ว

4. Scalping EA: เข้าออกระยะสั้นและไวต่อสภาพการส่งคำสั่ง

Scalping EA มักถือออเดอร์ช่วงสั้นและคาดหวังกำไรต่อครั้งไม่มาก ระบบประเภทนี้จึงไวต่อ Spread, Commission, Slippage, Latency และข้อกำหนดของโบรกเกอร์มากกว่าระบบที่ถือสถานะยาว หากต้นทุนจริงสูงขึ้นเล็กน้อย อัตราส่วนกำไรต่อขาดทุนอาจเปลี่ยนอย่างมีนัยสำคัญ

ผล Backtest ของ Scalping EA ควรใช้ข้อมูล Tick ที่เหมาะสม ใส่ต้นทุนใกล้เคียงบัญชีจริง และทดสอบหลายระดับ Spread การใช้ VPS สำหรับรัน EA ใกล้ Server โบรกเกอร์อาจช่วยลดความหน่วงของเครือข่าย แต่ไม่สามารถลบ Slippage หรือรับประกันราคาที่ได้รับจริงได้

ตารางเปรียบเทียบ EA 4 ประเภท

ประเภท แนวคิดหลัก จุดที่ต้องตรวจเป็นพิเศษ
Trend Following ตามทิศทางแนวโน้มและปล่อยกำไรเมื่อราคาไปต่อ สัญญาณหลอก ช่วง Sideway และจำนวนครั้งขาดทุนติดกัน
Grid แบ่งราคาเป็นหลายระดับและสะสมหรือกระจายสถานะ จำนวนชั้น Lot รวม Floating Loss และ Margin
Martingale เพิ่มขนาดสถานะหลังขาดทุนเพื่อหวังชดเชยรอบก่อน ตัวคูณ Lot จำนวนระดับสูงสุด Equity Stop และ Risk of Ruin
Scalping เข้าออกระยะสั้นเพื่อเก็บการเคลื่อนไหวขนาดเล็ก Spread, Commission, Slippage, Latency และคุณภาพ Tick

ตารางนี้เป็นเพียงกรอบเริ่มต้น ระบบจริงอาจเป็น Trend Following ที่ใช้ Grid จัดการสถานะ หรือ Scalping ที่เพิ่ม Lot แบบ Martingale ได้ จึงต้องตรวจทั้งตรรกะเข้าออเดอร์และ Money Management แยกกัน

เช็กลิสต์ก่อนเลือกใช้ EA

  1. ถามว่าระบบเข้าออเดอร์เพราะอะไร คำตอบควรอธิบายหลักการได้ ไม่จำเป็นต้องเปิดเผย Source Code แต่ไม่ควรมีเพียงคำว่า AI หรือระบบอัจฉริยะ
  2. ดูประวัติ Lot ทุกออเดอร์ เพื่อตรวจการเพิ่ม Lot และการสะสม Exposure
  3. ดูทั้ง Balance และ Equity เพราะ Balance อาจยังไม่สะท้อนผลขาดทุนลอยตัว
  4. ตรวจ Stop Loss และกฎหยุดระบบ รวมถึง Daily Loss Limit หรือ Equity Stop หากมี
  5. ทดสอบหลายสภาวะตลาด ไม่เลือกดูเฉพาะช่วงที่กราฟสวย
  6. เปรียบเทียบผล Backtest กับ Forward Test พร้อมตรวจต้นทุนและเงื่อนไขบัญชี
  7. เริ่มด้วยความเสี่ยงที่รับได้ และใช้เงินที่การขาดทุนไม่กระทบค่าใช้จ่ายจำเป็น

หากต้องการมองภาพรวมทั้งข้อดีและข้อจำกัดก่อนตัดสินใจ อ่านต่อที่ ข้อดีและข้อจำกัดของ EA หรือดูแนวทางระบบของ FENIX PRO EA โดยควรประเมินให้ตรงกับทุน ความเสี่ยง และประสบการณ์ของตนเอง

คำเตือนความเสี่ยง: การเทรด Forex ทองคำ และสินทรัพย์ที่มี Leverage มีความเสี่ยงสูง EA เป็นเครื่องมือทำตามกฎ ไม่สามารถรับประกันผลกำไรหรือป้องกันการขาดทุนได้ ผลทดสอบย้อนหลังไม่ใช่ผลลัพธ์ที่จะเกิดขึ้นแน่นอนในอนาคต
