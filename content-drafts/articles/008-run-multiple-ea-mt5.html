MT5 สามารถเปิดหลายกราฟและรัน EA หลายตัวพร้อมกันได้ แต่คำว่า “เปิดได้” ไม่ได้แปลว่า “ควรเปิดโดยไม่จำกัด” ปัญหาหลักไม่ได้มีเพียง CPU หรือ RAM สิ่งที่สำคัญกว่าคือ EA แต่ละตัวแยกออเดอร์ของตนเองถูกต้องหรือไม่ และเมื่อรวมทุกระบบแล้ว Portfolio Exposure, Margin และความเสี่ยงต่อวันยังอยู่ในกรอบที่ยอมรับได้หรือไม่

เอกสาร MetaTrader ระบุว่าในหนึ่งกราฟสามารถรัน Expert Advisor ได้หนึ่งตัว หากนำ EA อีกตัวมาวางบนกราฟเดิม ตัวก่อนหน้าจะถูกแทนที่ ดังนั้นการใช้หลายระบบต้องแยกกราฟหรือแยก Terminal และต้องวางแผน Magic Number, Symbol และบัญชีให้ชัดเจน

สารบัญ

  • โครงสร้างที่ใช้ได้
  • Magic Number สำคัญอย่างไร
  • วิธีคิดความเสี่ยงรวม
  • CPU, RAM และ VPS
  • ปัญหาที่พบบ่อย
  • เช็กลิสต์ตั้งค่า

เปิดหลาย EA ได้ในรูปแบบใดบ้าง

หลายกราฟใน MT5 Terminal เดียว

เหมาะเมื่อใช้บัญชีเดียวและ EA ออกแบบให้แยกออเดอร์ด้วย Symbol/Magic Number ได้ เปิดกราฟตาม Symbol และ Timeframe ที่คู่มือกำหนด แล้ววาง EA หนึ่งตัวต่อหนึ่งกราฟ ข้อดีคือดูแลง่ายและใช้ทรัพยากรน้อยกว่าหลาย Terminal

หลาย MT5 Terminal บนเครื่องเดียว

ใช้เมื่อต้องแยกบัญชี โบรกเกอร์ หรือชุดระบบให้เป็นอิสระ ต้องติดตั้งแต่ละ Terminal คนละโฟลเดอร์และตรวจ Data Folder ให้ถูกต้อง การคัดลอกไฟล์ EA หรือ Preset ผิด Terminal เป็นสาเหตุที่พบบ่อยเมื่อระบบไม่ทำงาน

หลาย VPS หรือแยกตามบัญชี

เหมาะเมื่อจำเป็นต้องแยกความเสี่ยง การบำรุงรักษา หรือสถานที่ Server แต่มีต้นทุนและภาระดูแลมากขึ้น ไม่จำเป็นต้องแยก VPS ทุกระบบหากเครื่องเดียวมีทรัพยากรเพียงพอและโครงสร้างบัญชีชัดเจน

อ่านขั้นตอนพื้นฐานได้ที่ วิธีลง EA บน MT5 และ การเลือก VPS สำหรับ EA

Magic Number คืออะไรและสำคัญอย่างไร

Magic Number คือหมายเลขที่ EA ใส่ไว้กับคำสั่งหรือ Position เพื่อระบุว่าออเดอร์นั้นมาจากระบบใด ใน MQL5 มีข้อมูล Magic สำหรับอ่าน ID ของ EA ที่เปิด Position หากสองกราฟใช้ Magic เดียวกันและโค้ดเลือกออเดอร์จาก Magic เพียงอย่างเดียว ระบบหนึ่งอาจแก้ไขหรือปิดออเดอร์ของอีกระบบโดยไม่ตั้งใจ

หลักการตั้งค่าที่ควรใช้:

  • ให้แต่ละกลยุทธ์มี Magic Number ไม่ซ้ำกัน
  • หาก EA เดียวกันเปิดหลาย Symbol ตรวจว่าคู่มือให้ใช้ Magic เดียวหรือแยกต่อ Symbol
  • บันทึกตารางว่า Magic ใดอยู่กราฟ บัญชี และ Preset ใด
  • อย่าเปลี่ยน Magic ขณะที่มีออเดอร์ค้าง หากยังไม่ทราบว่า EA จะจัดการออเดอร์เดิมอย่างไร
  • ตรวจ Comment เพิ่มเติม แต่ไม่ใช้ Comment เป็นตัวระบุเพียงอย่างเดียวหากโบรกเกอร์อาจแก้ไขข้อความ

หากคู่มือไม่ได้ระบุ Magic Number หรือวิธีแยกออเดอร์ ควรถามผู้พัฒนาก่อนเปิดหลายกราฟ เพราะการเดาค่าเองอาจทำให้ระบบไม่ติดตาม Position เดิมหรือจัดการออเดอร์ผิดชุด

วิธีคิดความเสี่ยงรวมเมื่อเปิดหลายระบบ

ข้อผิดพลาดที่พบบ่อยคือกำหนด Risk per Trade ให้แต่ละ EA แยกกัน แล้วสมมติว่าพอร์ตรวมยังเสี่ยงเท่าเดิม หากหลายระบบเปิดพร้อมกัน ความเสี่ยงรวมอาจเป็นผลบวกของทุกสถานะ และถ้า Symbol มีความสัมพันธ์กัน ความเสียหายอาจเกิดพร้อมกัน

ควรติดตามอย่างน้อย 5 ค่า:

  1. Open Risk รวม จำนวนเงินที่อาจเสียหากทุก Stop Loss ถูกเรียกตามระดับที่ตั้งไว้
  2. Lot และ Notional Exposure รวม แยกตาม Symbol และทิศทาง
  3. Margin Used และ Margin Level หลังรวม Pending Order และ Position
  4. Daily Loss รวม ไม่ให้แต่ละ EA เริ่มรอบใหม่จนเกินเพดานของพอร์ต
  5. Correlation เช่น EA หลายตัวอาจเปิดความเสี่ยงต่อ USD หรือทองในทิศทางเดียวกัน

หาก EA ไม่มี Stop Loss รายออเดอร์ ต้องประเมินจาก Basket Stop หรือ Equity Stop และจำลองสถานการณ์ที่หลายระบบขาดทุนพร้อมกัน ไม่ใช้ผลเฉลี่ยของแต่ละตัวแยกกัน อ่านพื้นฐานเพิ่มที่ Money Management และ การอ่าน Drawdown

CPU, RAM, Disk และ Network ต้องพอแค่ไหน

การใช้ทรัพยากรขึ้นอยู่กับจำนวนกราฟ Indicator, Tick, Log, History และความซับซ้อนของ EA ไม่สามารถสรุปจากจำนวน EA อย่างเดียว ควรเริ่มจากสเปกที่มีพื้นที่เผื่อและวัดการใช้งานจริง

  • CPU สำคัญเมื่อ EA คำนวณถี่หรือเปิดหลายกราฟพร้อมกัน
  • RAM เพิ่มตามจำนวน Terminal, กราฟ และข้อมูลที่โหลด
  • Disk ใช้เก็บ History, Tick, Log และไฟล์ของแต่ละ Terminal ควรเหลือพื้นที่สำหรับ Update
  • Network ต้องเสถียรและเชื่อมต่อ Trade Server ต่อเนื่อง ไม่ดูเพียงความเร็วดาวน์โหลดสูงสุด

ใน Windows ให้ดู Task Manager และ Resource Monitor ช่วงตลาดเคลื่อนไหวจริง หาก CPU หรือ RAM แตะระดับสูงต่อเนื่อง ควรลดภาระหรือเพิ่มทรัพยากรก่อนเพิ่มระบบใหม่

ปัญหาที่พบบ่อยเมื่อเปิดหลาย EA

อาการ สาเหตุที่ควรตรวจ
EA ตัวหนึ่งปิดออเดอร์ของอีกตัว Magic Number ซ้ำ หรือโค้ดเลือก Position จาก Symbol โดยไม่แยก Magic
วาง EA ใหม่แล้วตัวเดิมหาย วางสอง EA บนกราฟเดียวกัน
MT5 ค้างหรือส่งคำสั่งช้า CPU/RAM ไม่พอ Log มาก หรืออินเทอร์เน็ตไม่เสถียร
ไฟล์ Preset ไม่ตรง โหลด SET ผิดกราฟ ผิด Symbol หรือผิดเวอร์ชัน
Margin ลดเร็ว หลายระบบเปิดทิศทางเดียวกันหรือสะสมออเดอร์พร้อมกัน
Restart แล้วบาง EA ไม่กลับมาทำงาน Profile, AutoTrading, Login หรือ Startup ของ Terminal ไม่ครบ

เช็กลิสต์ก่อนเปิดหลาย EA

  • แยกกราฟให้แต่ละ EA และตรวจชื่อ Symbol/Timeframe
  • กำหนด Magic Number ไม่ซ้ำตามคู่มือ
  • บันทึก Preset และ Version ของทุกกราฟ
  • คำนวณ Risk, Lot, Margin และ Daily Loss รวมทั้งพอร์ต
  • ทดสอบหลายระบบพร้อมกันบน Demo ไม่ทดสอบแยกอย่างเดียว
  • ดู CPU, RAM, Disk และ Network ในช่วงตลาดเคลื่อนไหว
  • ตรวจ Experts/Journal ว่าไม่มี Error หรือออเดอร์ถูกปฏิเสธ
  • วางแผน Restart, Update และ Backup โดยไม่ทำให้ทุกระบบหยุดพร้อมกัน
  • เพิ่มระบบใหม่ทีละตัวและเฝ้าดูพฤติกรรมก่อนเพิ่มความเสี่ยง

การเปิดหลาย EA ช่วยกระจาย “กลยุทธ์” ได้ก็ต่อเมื่อระบบไม่ได้เสี่ยงต่อปัจจัยเดียวกันทั้งหมด การมีหลายชื่อหรือหลายกราฟไม่ใช่การกระจายความเสี่ยงโดยอัตโนมัติ

คำเตือนความเสี่ยง: การใช้หลาย EA สามารถเพิ่ม Exposure, Margin Used และขาดทุนพร้อมกันได้ ต้องประเมินความเสี่ยงระดับพอร์ต ไม่ใช่ดูแต่ละระบบแยกกัน ผล Backtest ของแต่ละ EA ไม่ได้จำลองปฏิสัมพันธ์ของทั้งพอร์ตเสมอไป
