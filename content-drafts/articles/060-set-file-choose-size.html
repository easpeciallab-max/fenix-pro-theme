ไฟล์ set ea คือไฟล์เล็ก ๆ ที่เก็บค่าในส่วน input parameters ของ ea ไว้ทั้งชุด เพื่อโหลดกลับมาใช้ซ้ำได้โดยไม่ต้องพิมพ์ใหม่ทีละช่อง ตัวไฟล์ไม่มีตรรกะการเทรดอยู่ข้างใน และไม่รู้ว่าบัญชีที่กำลังจะนำไปใช้มีทุนเท่าไร ชุดค่าที่โหลดมาจึงไม่ปรับตัวตามขนาดพอร์ตให้เอง

บทความนี้ไล่สองเรื่องควบกัน เรื่องแรกคือไฟล์ .set เก็บอะไรและใช้งานตรงไหนใน MT5 เรื่องที่สองคือวิธีเลือกชุดค่าให้สัมพันธ์กับทุนที่มีจริง ส่วนการตั้งชื่อไฟล์และคุมเวอร์ชันอ่านต่อได้ที่ วิธีบันทึกและโหลดไฟล์ preset set ของ ea บน MT5 ภาพรวมของการใช้ ea กับสินทรัพย์ที่แกว่งแรงอยู่ที่ คู่มือใช้ ea เทรดบิตคอยน์บน MT5

ไฟล์ .set เก็บอะไร และต่างจากตัว ea อย่างไร

คู่มือ MetaTrader 5 เรียกค่าที่ผู้ใช้ปรับได้ว่า input parameters ไฟล์ .set คือสำเนาของค่าชุดนั้น เก็บเป็นคู่ของชื่อพารามิเตอร์กับค่า และเปิดอ่านด้วยโปรแกรมแก้ข้อความได้ ขอบเขตของไฟล์จึงจบลงที่ช่องที่ผู้พัฒนาเปิดให้ปรับ ถ้า ea ไม่มีช่องกำหนดเวลาเทรด ไฟล์ .set ก็เก็บเวลาเทรดไม่ได้

คู่มือระบุว่าชุดค่าที่บันทึกไว้ถูกเก็บในโฟลเดอร์ Presets ของแพลตฟอร์ม และหน้าเอกสารเรื่องไฟล์กับโฟลเดอร์อธิบายเพิ่มว่าในโฟลเดอร์ Profiles ยังมีโฟลเดอร์ Tester ซึ่งเก็บไฟล์ .set ชุดล่าสุดของ ea ทุกตัวที่เคยถูกทดสอบ สองที่นี้แยกกัน

ต่างจากไฟล์ .ex5 ที่เป็นตัว ea อย่างไร

.ex5 คือโปรแกรมที่คอมไพล์แล้ว ข้างในมีเงื่อนไขเข้าออเดอร์ วิธีคิดขนาดไม้ และวิธีจัดการไม้ที่เปิดอยู่ ส่วน .set คือค่าที่ป้อนให้โปรแกรมนั้นใช้ตัดสินใจ ลบ .set ทิ้ง ea ยังทำงานด้วยค่าเริ่มต้นของมัน แต่ถ้าไม่มี .ex5 ไฟล์ .set ก็เป็นเพียงข้อความที่ไม่มีใครอ่าน

ผลตามมาคือชื่อพารามิเตอร์ต้องตรงกันทั้งสองฝั่ง ถ้าผู้พัฒนาเปลี่ยนชื่อช่องหรือเพิ่มช่องใหม่ในเวอร์ชันถัดไป ค่าบางช่องจากไฟล์เก่าจะไม่ถูกโหลดและกลับไปใช้ค่าเริ่มต้นอย่างเงียบ ๆ โดยไม่มีข้อความเตือน แท็บ common บอกชื่อและเวอร์ชันของโปรแกรมให้ แต่ข้อมูลนั้นไม่ติดมากับไฟล์ จึงควรจดเวอร์ชันของ ea ไว้คู่กับชื่อไฟล์เอง

โหลดและบันทึกไฟล์ .set ใน MT5 ตรงไหน

คู่มือระบุว่าหน้าต่างคุณสมบัติจะเปิดขึ้นก่อนที่โปรแกรมจะเริ่มทำงานบนกราฟ และเปิดหน้าต่างนี้ระหว่างที่โปรแกรมกำลังทำงานรอบหนึ่งอยู่ไม่ได้ ในทางปฏิบัติคือกด F7 บนกราฟที่มี ea อยู่ หรือลาก ea จาก navigator ลงกราฟ

  1. ไปที่ส่วนรายการค่าพารามิเตอร์ แก้ค่าทีละช่องด้วยการดับเบิลคลิกที่ค่านั้น
  2. กด load เพื่อเรียกชุดค่าที่บันทึกไว้กลับมา ไฟล์ที่บันทึกไว้อยู่ในโฟลเดอร์ presets แต่เลือกจากที่อื่นได้
  3. กด save เพื่อบันทึกชุดค่าที่เห็นอยู่เป็นไฟล์ หรือ reset เพื่อกลับไปใช้ค่าเริ่มต้นของ ea ทั้งชุด
  4. กด ok คู่มือระบุว่า ea จะถูกเริ่มต้นใหม่ด้วยค่าชุดใหม่หลังกดปุ่มนี้

ฝั่ง strategy tester มีแท็บ inputs ของตัวเอง คู่มืออธิบายว่าปุ่ม save ในแท็บนี้บันทึกค่าเป็น set-file ลงเครื่อง ซึ่งย้ายไปเครื่องอื่นหรือส่งให้คนอื่นได้ และมี save version ที่เก็บชุดค่าไว้ในแพลตฟอร์มเดิมแล้วเรียกคืนจากเมนูย่อย load version ชุดค่าที่ใช้ทดสอบแยกจากชุดค่าที่ ea ใช้บนกราฟจริง หลายคนจึงทดสอบค่าหนึ่งแต่รันจริงอีกค่าโดยไม่รู้ตัว

กด load แล้วเห็นค่าเปลี่ยนครบ ยังไม่ใช่หลักฐานว่าชุดค่านี้เหมาะกับบัญชีที่กำลังเปิดอยู่ ไฟล์ .set ไม่รู้ยอดเงินในพอร์ต ไม่รู้ว่าบัญชีคิดยอดเป็นหน่วยใด และไม่รู้ว่าโบรกตั้งชื่อสัญลักษณ์ว่าอะไร สามอย่างนี้ต้องตรวจด้วยตา

ทำไมชุดค่าเดียวใช้กับทุนต่างกันไม่ได้

เพราะค่าที่สำคัญที่สุดในไฟล์ .set ผูกกับจำนวนเงิน ไม่ใช่ผูกกับสัดส่วนของพอร์ต ขนาดไม้แรก จำนวนขั้นที่เปิดเพิ่มได้ ระยะห่างของแต่ละขั้น และเงินประกันที่ต้องกันไว้ ทั้งสี่อย่างเดินไปด้วยกันและเทียบกับทุนเสมอ

หน้าสเปกสัญญาใน market watch ของ MT5 เปิดได้จากการคลิกขวาที่สัญลักษณ์แล้วเลือก specification คู่มือนิยาม contract size ว่าจำนวนหน่วยของสินทรัพย์ใน 1 lot, minimal volume คือปริมาณต่ำสุดที่เทรดได้, volume step คือขั้นการเปลี่ยนปริมาณ และ tick value คือต้นทุนของการที่ราคาเปลี่ยนไปหนึ่งจุด ค่าที่ขาดไม่ได้อีกตัวคือ initial margin ซึ่งเอกสารฝั่ง mql5 อธิบายว่าเป็นเงินในสกุลของมาร์จิ้นที่ต้องใช้เพื่อเปิดสถานะขนาด 1 lot และโบรกใช้ค่านี้ตรวจเงินของลูกค้าตอนส่งคำสั่ง

ค่าทั้งห้าตัวนี้เป็นของสัญลักษณ์และของโบรก ไม่ขยับตามทุนของเรา เมื่อ lot ไม้แรกถูกตั้งเป็นเลขคงที่ในไฟล์ ความเสียหายจากการที่ราคาวิ่งสวนหนึ่งช่วงจะเท่ากันทุกบัญชี แต่สัดส่วนต่อทุนต่างกันตามขนาดพอร์ต สมมติเหตุการณ์เดียวกันทำให้ติดลบ 40 ดอลลาร์ พอร์ต 2,000 ดอลลาร์เสีย 2 เปอร์เซ็นต์ แต่พอร์ต 500 ดอลลาร์เสีย 8 เปอร์เซ็นต์

ปริมาณรวมโตเร็วกว่าที่ชื่อไฟล์บอก

ระบบที่เปิดได้หลายไม้ทำให้ช่องว่างนี้กว้างขึ้นอีก เพราะปริมาณที่ค้างอยู่ในพอร์ตคือผลรวมของทุกไม้ ไม่ใช่ขนาดของไม้แรก สมมติไม้แรก 0.01 lot เปิดเพิ่มได้อีก 5 ขั้น ขนาดเท่ากันทุกขั้น ปริมาณรวมตอนครบขั้นคือ 0.06 lot แต่ถ้าตั้งให้แต่ละขั้นใหญ่ขึ้นหนึ่งเท่าครึ่ง ปริมาณรวมจะอยู่ราว 0.11 lot จากการแก้ค่าเพียงช่องเดียว ตัวเลขชุดนี้สมมติไว้ให้เห็นลำดับการคิด และต้องปรับให้ลงตัวกับ volume step ก่อนใช้จริง

เงินประกันที่ถูกกันไว้เดินตามปริมาณรวม ไม่ใช่ตามไม้แรก ชุดค่าที่ทุนก้อนใหญ่รับไหวสบาย ๆ จึงอาจทำให้ทุนก้อนเล็กถูกปิดสถานะอัตโนมัติก่อนราคาจะกลับมาที่เดิม

ไล่ลำดับเลือกชุดค่าให้ตรงกับทุน

ลำดับที่ใช้ได้จริงคือเริ่มจากทุน แล้วค่อยเดินมาที่ lot เป็นค่าสุดท้าย ไม่ใช่เลือก lot ที่คุ้นตาก่อนแล้วหวังว่าทุนจะพอ

  1. เริ่มจากทุนที่ตั้งใจให้ระบบใช้จริง คือเงินก้อนที่ยอมให้เสียได้ทั้งก้อนโดยไม่กระทบชีวิตประจำวัน ไม่ใช่ยอดรวมในบัญชีธนาคาร
  2. กำหนดเพดานความเสียหายที่ยอมรับได้ เป็นเปอร์เซ็นต์ของทุนก้อนนั้น ว่ายอมให้พอร์ตติดลบลึกสุดเท่าไรก่อนจะปิดระบบมาทบทวน ตัวเลขนี้ต้องตั้งก่อนเริ่ม
  3. ดูจำนวนไม้สูงสุดที่ชุดค่ายอมให้เปิด พร้อมระยะห่างของแต่ละขั้น สองค่านี้บอกว่าราคาต้องวิ่งสวนไปไกลเท่าไรกว่าจะครบทุกขั้น และตอนนั้นปริมาณรวมจะเป็นเท่าไร
  4. ค่อยคำนวณ lot ไม้แรก ให้กรณีที่แย่ที่สุดที่ชุดค่านี้ยอมให้เกิด ยังอยู่ใต้เพดานในข้อสอง ไม่ใช่คิดจากไม้แรกไม้เดียว
  5. ปรับให้ลงล็อกกับข้อจำกัดของสัญลักษณ์ ค่าที่ได้ต้องไม่ต่ำกว่า minimal volume และเป็นจำนวนเท่าของ volume step มิฉะนั้นคำสั่งจะถูกปฏิเสธหรือถูกปัดเป็นค่าอื่น

ถ้าคำนวณออกมาแล้วได้ค่าต่ำกว่า minimal volume ของสัญลักษณ์ นั่นไม่ใช่เรื่องของการปัดเศษ แต่เป็นสัญญาณว่าทุนก้อนนี้ยังไม่พอกับชุดค่าที่เลือก ทางออกคือลดจำนวนขั้นที่อนุญาต เปลี่ยนไปใช้ชุดที่ออกแบบมาสำหรับทุนเล็กกว่า หรือรอให้ทุนถึงระดับที่ชุดนั้นต้องการ วิธีคิดขนาดไม้จากเปอร์เซ็นต์ความเสี่ยงอ่านต่อที่ วิธีคำนวณ lot size ให้เหมาะกับทุน

อีกจุดที่ต้องแยกให้ออกคือ ea บางตัวคิด lot จากทุนให้เอง ค่าที่เห็นในช่องจึงเป็นพารามิเตอร์ของสูตร เช่นเปอร์เซ็นต์ความเสี่ยงต่อไม้ ไม่ใช่ขนาดไม้สุดท้าย แต่เพดานจำนวนไม้และระยะมักเป็นเลขคงที่ที่สูตรไม่แตะ จึงยังต้องตรวจเอง

สำหรับชุดค่าของ FENIX เราเตรียมไว้พร้อมเงื่อนไขที่ชุดนั้นถูกทำมา ดูได้ที่ คู่มือเลือกชุดค่าของ FENIX DUAL และดาวน์โหลดไฟล์ได้ที่ หน้าดาวน์โหลดและเริ่มใช้งาน

ตรวจอะไรทุกครั้งหลังโหลดไฟล์ .set

รายการข้างล่างใช้เวลาไม่กี่นาที แต่เป็นด่านที่กันความผิดพลาดที่แก้ย้อนหลังไม่ได้ ตรวจก่อนกด ok ไม่ใช่หลัง ea เปิดไม้แล้ว

ค่า ต้องตรวจอะไร ถ้าผิดจะเกิดอะไร
สัญลักษณ์ที่ใช้ ชื่อสัญลักษณ์บนกราฟตรงกับที่ชุดค่าถูกทำมา รวมคำต่อท้ายที่โบรกเติม สเปกสัญญาคนละชุด ระยะและขนาดไม้เพี้ยนทั้งระบบ
ช่วงเวลาของกราฟ timeframe เดียวกับที่ทดสอบ และกราฟมีข้อมูลย้อนหลังพอ สัญญาณเข้าออกเกิดต่างจังหวะจากผลทดสอบที่เคยดู
ชนิดและสกุลของบัญชี บัญชีคิดยอดเป็นเซนต์หรือเป็นหน่วยเต็ม และสกุลเงินของบัญชี ไม้ที่ดูเล็กในบัญชีหนึ่งกลายเป็นไม้ใหญ่เกินตัวในอีกบัญชี
lot ไม้แรกและโหมดคิด lot เป็น lot คงที่หรือคิดจากทุน และค่าลงล็อกกับ volume step ขนาดไม้ไม่สัมพันธ์กับทุน หรือคำสั่งถูกปฏิเสธเพราะปริมาณไม่ถูกต้อง
จำนวนไม้สูงสุดและระยะขั้น เพดานจำนวนไม้ ระยะห่างแต่ละขั้น และตัวคูณถ้ามี ปริมาณรวมและเงินประกันที่ต้องกันไว้เกินทุนที่มี
magic number ไม่ซ้ำกับ ea ตัวอื่นหรือกราฟอื่นในเทอร์มินัลเดียวกัน ea สองตัวเข้าไปแก้หรือปิดไม้ของกันและกัน
เพดานหยุดระบบ ค่าที่สั่งหยุดเทรดเมื่อพอร์ตเสียหายถึงระดับที่ตั้งไว้ ไม่มีอะไรหยุดระบบเมื่อขาดทุนเลยแผนที่วางไว้

magic number มักถูกมองข้ามเวลาโหลดไฟล์เดียวกันลงหลายกราฟ เพราะทุกกราฟจะได้เลขเดียวกัน วิธีแยกเลขอ่านได้ที่ magic number บน MT5 คืออะไร หลังกด ok ควรดูแท็บ experts ว่า ea เริ่มต้นสำเร็จ

กับดักที่พบบ่อย

เอาชุดค่าของบัญชีเซนต์ไปใส่บัญชี usd

บัญชีเซนต์แสดงยอดเป็นหน่วยย่อย ยอดที่เห็นเป็นเลขหลักหมื่นอาจเป็นเงินจริงหลักร้อย ชุดค่าที่จูนมาให้เหมาะกับเลขที่เห็นบนหน้าจอ เมื่อย้ายไปบัญชีที่คิดยอดเป็นหน่วยเต็มจะกลายเป็นไม้ที่ใหญ่กว่าเจตนาเดิมหลายเท่า ตัวที่เชื่อถือได้ไม่ใช่ชื่อบัญชี แต่เป็นหน้าสเปกสัญญาในบัญชีนั้น

เอาชุดค่าของทองไปใส่บิตคอยน์

สองสัญลักษณ์นี้มีมูลค่าต่อหน่วยสูงทั้งคู่ จึงดูเหมือนแทนกันได้ แต่ contract size, volume step, tick value และ initial margin ไม่เหมือนกัน ระยะที่ตั้งเป็นจุดจึงให้ความหมายต่างกัน ที่หนักกว่าคือช่วงแกว่งต่อวันต่างกัน ระยะขั้นที่ห่างพอสำหรับสัญลักษณ์หนึ่งอาจถูกราคาของอีกตัววิ่งผ่านจนครบทุกขั้นในรอบเดียว

ไฟล์ .set จากคนอื่นที่ไม่รู้ที่มา

ไฟล์ที่ส่งต่อกันในกลุ่มแชตมักมาเดี่ยว ๆ ไม่มีข้อมูลว่าถูกทำมาสำหรับทุนเท่าไร บัญชีแบบไหน สัญลักษณ์ชื่ออะไร และ ea เวอร์ชันใด ชื่อไฟล์ที่เขียนว่าเสี่ยงต่ำเป็นคำเรียก ไม่ใช่สเปกที่ตรวจสอบได้ บริบทที่ขาดไปคือส่วนที่ตัดสินว่าค่านั้นเหมาะกับพอร์ตของเราหรือไม่ ทางที่เสี่ยงน้อยกว่าคือขอชุดค่าจากผู้พัฒนาพร้อมเงื่อนไขที่ชุดนั้นถูกทำมา

ทดสอบชุดค่าก่อนใช้เงินจริง

ขั้นแรกคือทดสอบย้อนหลังด้วย strategy tester โดยตั้ง initial deposit ให้เท่ากับทุนที่จะใช้จริง คู่มือระบุว่าช่องนี้คือเงินฝากเริ่มต้นที่ใช้ในการทดสอบและการหาค่าที่เหมาะสม จุดนี้สำคัญ เพราะชุดค่าที่ผ่านได้ที่ทุนก้อนหนึ่งอาจเงินประกันไม่พอที่ทุนอีกก้อน แล้วถูกปิดสถานะกลางทางทั้งที่ตรรกะของระบบไม่เปลี่ยน

คู่มือยังอธิบายว่า forward testing ในตัวโปรแกรมคือการรัน ea ซ้ำบนช่วงเวลาที่ต่างออกไป โดยช่วงท้ายของกรอบเวลาทั้งหมดถูกใช้เป็นช่วง forward ส่วนช่วงก่อนหน้าใช้ปรับค่า ทำให้เห็นว่าชุดค่าที่เลือกยังทำงานได้บนข้อมูลที่ไม่ได้ใช้จูนหรือไม่

ขั้นที่สองคือบัญชีเดโม่ที่โบรกและเซิร์ฟเวอร์เดียวกับที่จะใช้จริง เพราะเดโม่คือที่เดียวที่ตรวจได้ว่าชื่อสัญลักษณ์ตรงกัน และเงินประกันที่ถูกกันไว้ตรงกับที่คำนวณหรือไม่ ควรรันให้ผ่านรอบที่ระบบเปิดไม้ครบจำนวนขั้นอย่างน้อยหนึ่งครั้ง ไม่ใช่ดูแค่สัปดาห์ที่ตลาดสงบ เพราะช่วงนั้นชุดค่าที่ใหญ่เกินทุนก็ดูเรียบร้อยได้

เมื่อผ่านทั้งสองขั้น ให้กด save เก็บไฟล์พร้อมชื่อที่บอกสัญลักษณ์ ทุนที่ใช้ทดสอบ และเวอร์ชันของ ea เพื่อย้อนกลับมาเทียบได้เมื่อผลจริงเริ่มต่างจากที่ทดสอบ

สรุป

สรุป: ไฟล์ .set เก็บแค่ชื่อพารามิเตอร์กับค่าในส่วน input ของ ea ไม่ใช่ตัวโปรแกรมและไม่ได้เก็บยอดเงินในบัญชี โหลดและบันทึกได้จากหน้าต่างคุณสมบัติด้วยปุ่ม load กับ save ชุดค่าเดียวกันใช้กับทุนต่างกันไม่ได้ เพราะ lot ไม้แรก จำนวนขั้น ระยะ และเงินประกันผูกกับจำนวนเงิน ลำดับที่ถูกคือไล่จากทุนที่ยอมเสียได้ ไปหาเพดานความเสียหาย ไปหาจำนวนไม้สูงสุด แล้วจึงคำนวณ lot ไม้แรก ก่อนใช้จริงให้ตรวจสัญลักษณ์ ช่วงเวลา ชนิดบัญชี ค่า lot และ magic number ทุกครั้ง

คำเตือนความเสี่ยง: การเลือกชุดค่าให้ตรงกับทุนช่วยลดโอกาสที่พอร์ตจะเสียหายเร็วเกินแผน แต่ไม่ได้ทำให้ระบบเทรดมีกำไร และไม่มีชุดค่าใดที่ปลอดความเสี่ยง การเทรดด้วย ea บนสินทรัพย์ที่ผันผวนสูงอาจทำให้สูญเงินลงทุนทั้งจำนวน สเปกสัญญา เงินประกัน และเงื่อนไขของโบรกเปลี่ยนแปลงได้ตลอดเวลา ผลทดสอบย้อนหลังไม่รับประกันผลในอนาคต ใช้เฉพาะเงินที่พร้อมรับความเสียหาย อ่าน คำเตือนความเสี่ยงฉบับเต็ม
