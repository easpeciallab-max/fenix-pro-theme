ATR คือค่าเฉลี่ยเคลื่อนที่ของ True Range ซึ่งก็คือระยะที่ราคาวิ่งจริงในแต่ละแท่ง คู่มือ MetaTrader 5 เรียกมันตรง ๆ ว่าอินดิเคเตอร์ที่แสดงความผันผวนของตลาด ค่าที่ได้เป็นตัวเลขในหน่วยราคา ไม่ใช่เปอร์เซ็นต์ และไม่ใช่สัญญาณซื้อขาย EA จึงเอาค่านี้ไปคูณเป็นระยะกริดหรือระยะ TP/SL เพื่อให้ระยะขยายเองตอนตลาดเหวี่ยงและแคบลงตอนตลาดสงบ แทนการล็อกตัวเลขคงที่ที่พอดีกับตลาดช่วงเดียว

บทความนี้ลงที่กลไกและค่าตั้งที่ต้องตัดสินใจจริง คือ True Range ประกอบจากอะไร ทำไมค่าเฉลี่ยตอบช้า คาบกับกรอบเวลาเปลี่ยนตัวเลขได้แค่ไหน ควรตั้งเพดานอย่างไร และจะยืนยันยังไงว่าตัวเลขที่ EA ใช้คือตัวเลขที่ตั้งใจ ภาพรวมการรัน EA บนบิตคอยน์อยู่ใน คู่มือใช้ EA เทรดบิตคอยน์บน MT5

สารบัญ

  • True Range และ ATR คำนวณจากอะไร
  • ATR บอกอะไร ไม่บอกอะไร
  • ทำไม EA ไม่ใช้ระยะคงที่
  • คาบและกรอบเวลาที่อ่านค่า
  • ปัญหาที่เจอจริง
  • เพดานบนและพื้นล่างของระยะ
  • ตรวจค่าที่ EA ใช้จริง

True Range และ ATR คำนวณจากอะไร

ตัวตั้งต้นไม่ใช่ ATR แต่เป็น True Range ของแต่ละแท่ง คู่มือ MetaTrader 5 ระบุว่า True Range คือค่าที่มากที่สุดในสามค่า

  • ราคาสูงสุดลบราคาต่ำสุดของแท่งปัจจุบัน คือระยะที่เห็นด้วยตาว่าแท่งนั้นยาวแค่ไหน
  • ราคาปิดแท่งก่อนหน้าเทียบกับราคาสูงสุดปัจจุบัน จับกรณีที่ราคาเปิดกระโดดขึ้น
  • ราคาปิดแท่งก่อนหน้าเทียบกับราคาต่ำสุดปัจจุบัน จับกรณีที่ราคาเปิดกระโดดลง

สองค่าหลังมีไว้จับช่องว่างระหว่างแท่ง ถ้าวัดแค่สูงสุดลบต่ำสุด แท่งที่เปิดห่างจากราคาปิดก่อนหน้าไปไกลแล้วนิ่งอยู่แคบ ๆ จะถูกนับว่าเป็นแท่งสั้น ทั้งที่ระยะที่ราคาเดินทางจริงกว้างมาก การเทียบกับราคาปิดแท่งก่อนจึงทำให้ True Range ไม่น้อยกว่าความยาวของแท่งเสมอ แต่นี่คือการนับช่องว่างที่ เกิดแล้ว ไม่ใช่การเตือนว่าจะมีช่องว่างข้างหน้า

จากนั้น ATR ทำอีกขั้นเดียวคือเฉลี่ย True Range รายแท่ง คู่มือ MetaTrader 5 เขียนว่า ATR เป็นค่าเฉลี่ยเคลื่อนที่ของค่า True Range โดยไม่ได้ระบุชนิดของค่าเฉลี่ย รายละเอียดนี้สำคัญ เพราะสูตรเฉลี่ยที่ต่างกันให้ตัวเลขต่างกันบนข้อมูลชุดเดียวกัน ถ้า EA คำนวณ ATR ด้วยโค้ดของตัวเอง อย่าแปลกใจถ้าเลขไม่ตรงกับเส้นบนกราฟเป๊ะ

ATR บอกอะไร และไม่บอกอะไร

ประโยคเดียวที่ใช้ได้เสมอคือ ATR บอกว่าช่วงที่ผ่านมาราคากินระยะเฉลี่ยกว้างเท่าไรในหน่วยราคาของสัญลักษณ์นั้น ส่วนที่คนมักอ่านเกินมีสองข้อ

ไม่บอกทิศทาง

ค่าสูงแปลแค่ว่าระยะที่อาจวิ่งในรอบถัดไปกว้างกว่าปกติ ไม่ว่าทางไหน คู่มือ MetaTrader 5 ยังชี้ว่า ATR มักขึ้นไปสูงบริเวณจุดต่ำของตลาดหลังราคาร่วงจากการเทขายแบบตื่นตระหนก ขณะที่ค่าต่ำเป็นลักษณะของช่วงที่ตลาดเคลื่อนไหวออกข้างเป็นเวลานาน ค่าสูงสุดจึงมักอยู่ตรงจุดที่คนกลัวที่สุด

ไม่บอกว่าจะแกว่งต่อหรือเปล่า

ATR เป็นค่าเฉลี่ยของสิ่งที่ปิดไปแล้ว ไม่มีส่วนใดในสูตรที่พยากรณ์แท่งถัดไป คู่มือ MetaTrader 5 มีข้อสังเกตว่ายิ่งค่าสูง โอกาสที่แนวโน้มจะเปลี่ยนก็ยิ่งสูงขึ้น ซึ่งเป็นข้อสังเกตเชิงพฤติกรรม ไม่ใช่ความน่าจะเป็นที่คำนวณได้ และยังมีสิ่งที่ ATR มองไม่เห็นเลย คือสเปรดที่ขยาย คอมมิชชัน slippage และระยะขั้นต่ำของโบรกเกอร์

ทำไม EA ไม่ใช้ระยะคงที่ แล้วเอา ATR มาคูณแทน

ระยะกริดที่เป็นตัวเลขคงที่มีปัญหาข้อเดียว คือถูกตั้งจากตลาดช่วงหนึ่งแล้วใช้ต่อในตลาดทุกช่วง ระยะที่พอดีในเดือนที่ราคาแกว่งแคบจะถี่เกินไปในเดือนที่ราคาวิ่งแรง ไม้เต็มเพดานจบในการเคลื่อนไหวครั้งเดียว ขณะที่ระยะซึ่งเผื่อไว้สำหรับตลาดเหวี่ยงจะกว้างจนไม่มีไม้ไหนถูกเปิดเลยในตลาดเงียบ

การคูณ ATR เปลี่ยนหน่วยของค่าตั้ง จากเดิมตั้งเป็น "กี่จุด" กลายเป็น "กี่เท่าของระยะแกว่งปัจจุบัน" ค่าตั้งจึงผูกกับสเกลของสินทรัพย์เอง สมมติให้เห็นภาพ ถ้า ATR บนกรอบเวลาหนึ่งอ่านได้ 300 จุด และบนกรอบที่ใหญ่กว่าอ่านได้ 2,400 จุด ตัวคูณเดียวกันจะให้ระยะต่างกันแปดเท่าโดยไม่ต้องแก้ค่าตั้ง กลไกและความเสี่ยงของระบบกริดอ่านเพิ่มที่ ความเสี่ยงของ Grid EA

แต่วิธีนี้ไม่ได้ลบการตัดสินใจทิ้ง มันย้ายไปที่อื่น เดิมเลือกตัวเลขตัวเดียวคือระยะเป็นจุด ตอนนี้ต้องเลือกคาบของ ATR กรอบเวลาที่อ่านค่า ตัวคูณ และเพดานบนล่าง ถ้าเลือกผิดจะแย่กว่าใช้ตัวเลขคงที่ เพราะพฤติกรรมเปลี่ยนตามตลาดโดยที่คุณอ่านไม่ออกว่าตอนนั้นใช้ระยะเท่าไร และชุดค่าตั้งเดียวยังใช้ข้ามสินทรัพย์ไม่ได้อยู่ดี ความต่างในมุมนี้อยู่ใน การเทียบความผันผวนของบิตคอยน์กับทอง

คาบและกรอบเวลาที่อ่านค่า เปลี่ยนตัวเลขได้มากกว่าที่คิด

ใน MQL5 ฟังก์ชันที่สร้าง ATR ขึ้นมาใช้คือ iATR ซึ่งคู่มือ MQL5 ระบุว่ารับค่าสามตัว คือสัญลักษณ์ กรอบเวลา และ ma_period ที่เป็นคาบของการเฉลี่ย โครงสร้างนี้บอกอะไรที่ใช้งานได้จริงสามข้อ

กรอบเวลาเป็นพารามิเตอร์แยก ไม่ใช่กรอบเวลาของกราฟเสมอไป

คู่มือ MQL5 ระบุว่าค่ากรอบเวลาที่ส่งเข้าไปถ้าเป็นศูนย์หมายถึงกรอบเวลาของกราฟปัจจุบัน EA ที่อ่านค่าแบบนั้นจะเปลี่ยนพฤติกรรมทันทีเมื่อย้ายไปแปะบนกราฟคนละกรอบเวลา ส่วนตัวที่ล็อกกรอบเวลาไว้ในค่าตั้งจะให้ระยะเดิมไม่ว่าแปะบนกราฟไหน ก่อนสรุปว่าค่าตั้งของคุณทำงานถูก ต้องรู้ก่อนว่า EA ที่ใช้อยู่เป็นแบบไหน

คาบกำหนดว่าค่าจะไหวเร็วหรือนิ่ง

คาบสั้นทำให้ค่าขยับตามแท่งล่าสุดได้ไว แต่ก็กระโดดตามแท่งเดียวที่ผิดปกติได้ไวเหมือนกัน ระยะกริดจึงเปลี่ยนบ่อย สองไม้ที่เปิดห่างกันไม่กี่ชั่วโมงอาจใช้ระยะต่างกันมาก คาบยาวให้ค่านิ่งกว่า แต่ตอบสนองช้าลงเมื่อตลาดเปลี่ยนระดับความผันผวนจริง ไม่มีคาบที่ถูกสำหรับทุกคน ต้องทดสอบกับสินทรัพย์และทุนของตัวเองเท่านั้น

ช่วงที่ค่ายังไม่พร้อม

คู่มือ MQL5 อธิบายว่า iATR คืนค่าเป็น handle ของอินดิเคเตอร์ที่มีบัฟเฟอร์เดียว EA จึงอ่านค่าด้วย CopyBuffer ที่บัฟเฟอร์หมายเลขศูนย์ และตัวอย่างในคู่มือใช้ BarsCalculated ตรวจก่อนว่าคำนวณพอแล้วหรือยัง ตอนเพิ่งแปะ EA หรือเริ่มทดสอบย้อนหลังที่ข้อมูลยังไม่พอ ค่าอาจยังอ่านไม่ได้ ต้องรู้ว่า EA หยุดรอ ใช้ค่าสำรอง หรือเดินต่อด้วยค่าศูนย์ซึ่งจะทำให้ระยะกลายเป็นศูนย์

จุดที่พลาดบ่อยที่สุดไม่ใช่การตั้งตัวคูณผิด แต่คือเปลี่ยนกรอบเวลาของกราฟที่ EA เกาะอยู่ แล้วคิดว่าค่าตั้งเดิมยังให้ผลเดิม ถ้า EA อ่าน ATR จากกรอบเวลาของกราฟ ระยะกริดทั้งชุดจะเปลี่ยนทันทีโดยไม่มีข้อความแจ้งเตือน ให้ยืนยันจากบันทึกการทำงานก่อนปล่อยให้รันต่อ

ปัญหาที่เจอจริงเมื่อผูกระยะกับ ATR

ตอบช้าหลังตลาดเปลี่ยนระดับ

เพราะเป็นค่าเฉลี่ย ATR จึงต้องสะสมแท่งใหม่หลายแท่งก่อนจะสะท้อนความผันผวนที่เปลี่ยนไปแล้ว ช่วงรอยต่อจึงเจ็บที่สุด ตลาดสงบมานานทำให้ค่าต่ำและระยะแคบที่สุด พอความผันผวนกลับมา ราคาวิ่งเต็มระยะหลายชั้นก่อนที่ค่าจะทันขยาย

ค่าพุ่งแล้วค้างสูง

ด้านกลับกันก็เป็นปัญหา หลังการเทขายรุนแรงหนึ่งครั้ง True Range ของแท่งนั้นใหญ่มาก และเพราะ ATR เฉลี่ยค่าย้อนหลัง แท่งเดียวนั้นยังดันค่าเฉลี่ยให้สูงอีกหลายแท่งแม้ตลาดกลับมานิ่งแล้ว ระยะที่คำนวณได้จึงกว้างเกินสภาพจริง

ระยะกว้างเกินจนไม่มีไม้เข้า

อาการนี้มักถูกตีความผิดว่า EA เสีย แต่หลายครั้งคือระยะที่คำนวณได้กว้างกว่าที่ราคาจะวิ่งไปถึงในกรอบเวลาที่คุณเฝ้าดู ที่ต้องระวังอีกชั้นคือระยะ TP ที่กว้างมากจนไม้ค้างข้ามรอบตลาด ซึ่งเปลี่ยนความเสี่ยงของพอร์ตทั้งก้อน

ระยะแคบเกินจนไม้ถี่

ปัญหานี้อันตรายกว่าเพราะดูเหมือนทำงานปกติ ไม้เข้าเรื่อย ๆ มีกำไรเล็ก ๆ เข้ามา จนราคาวิ่งทางเดียวแล้วไม้ทั้งชุดเปิดชิดกันในระยะสั้น ๆ มาร์จิ้นถูกใช้เร็วกว่าที่ประเมินไว้ และไม้ที่เหลือหมดลงตอนที่ยังต้องการมันที่สุด

คำนวณใหม่ตอนไหน

คำถามที่มักไม่มีใครถามคือ EA คำนวณระยะใหม่ทุกครั้งที่จะเปิดไม้ หรือล็อกค่าไว้ตั้งแต่ไม้แรกของตะกร้า ถ้าคำนวณใหม่ตลอด ระยะในตะกร้าเดียวกันจะไม่เท่ากัน ประเมินความเสียหายที่ไม้สุดท้ายล่วงหน้าไม่ได้ ถ้าล็อกไว้ ระยะสม่ำเสมอ แต่จะไม่รับรู้ว่าความผันผวนเพิ่มกลางทาง

ค่าที่ปรับ ผลเมื่อตั้งกว้างไป ผลเมื่อตั้งแคบไป
ตัวคูณ ATR ของระยะกริด ไม้ถัดไปแทบไม่ถูกเปิดในตลาดปกติ ระบบดูเหมือนหยุดทำงาน ไม้เปิดชิดกัน ชนเพดานจำนวนไม้ในการเคลื่อนไหวครั้งเดียว
ระยะ TP ไม้ค้างยาวข้ามรอบตลาด ความเสี่ยงกองรวมกันนานขึ้น ถูกชนบ่อย กำไรต่อไม้ไม่คุ้มสเปรดกับคอมมิชชัน
ระยะ SL ขาดทุนต่อไม้ลึกกว่าที่ทุนรับได้ก่อนจะถูกตัด ถูกปัดออกด้วยการแกว่งปกติ ไม่ใช่เพราะทิศทางผิดจริง
พื้นล่างของระยะ ระยะไม่เคยแคบลงตามตลาดที่สงบ เสียโอกาสในกรอบแคบ แทบไม่ทำหน้าที่ ค่าที่ต่ำผิดปกติหลุดต่ำกว่าระยะขั้นต่ำของโบรกเกอร์
เพดานบนของระยะ ค่าที่พุ่งครั้งเดียวดันระยะออกไปค้างไว้ได้นาน ตัดระยะทิ้งในตลาดที่เหวี่ยงจริง กลายเป็นระยะคงที่โดยไม่รู้ตัว

ตารางนี้บอกทิศทางของผล ไม่ใช่ค่าที่ก๊อปไปใส่ได้ ตัวเลขที่เหมาะขึ้นกับสินทรัพย์ โบรกเกอร์ ขนาดทุน และจำนวนไม้ที่ยอมให้ค้างพร้อมกัน

ตั้งเพดานบนและพื้นล่างของระยะ ไม่ให้ค่าที่คำนวณได้หลุดกรอบ

หลักคิดคือยอมให้ ATR ปรับระยะได้ แต่ไม่ให้ปรับออกไปไกลกว่าที่ระบบและโบรกเกอร์รับได้ กรอบนี้มีสองด้านและเหตุผลไม่เหมือนกัน

พื้นล่างมีข้อบังคับจากโบรกเกอร์อยู่แล้ว

คู่มือ MQL5 ส่วนคุณสมบัติของสัญลักษณ์ระบุว่า SYMBOL_TRADE_STOPS_LEVEL คือระยะห่างขั้นต่ำในหน่วยจุดจากราคาปิดปัจจุบันสำหรับการวาง Stop orders ส่วน SYMBOL_POINT คือมูลค่าของหนึ่งจุด ถ้าระยะที่คำนวณจาก ATR แคบกว่านั้น คำสั่งจะถูกปฏิเสธ EA บางตัวข้ามไม้นั้นไป บางตัวเปิดไม้โดยไม่มี SL ไปเลย พื้นล่างที่ตั้งเองจึงควรกว้างกว่าค่าขั้นต่ำของโบรกเกอร์ เผื่อช่วงที่สเปรดขยาย

เพดานบนกันค่าที่พุ่งครั้งเดียว

เพดานบนมีหน้าที่เดียวคือกันไม่ให้เหตุการณ์ผิดปกติครั้งเดียวดันระยะออกไปค้างไว้เป็นวัน ต้นทุนของมันคือในตลาดที่เหวี่ยงแรงและยืดเยื้อ ระยะจะถูกตัดกลับมาเท่าเพดาน พฤติกรรมของระบบตอนนั้นจึงกลายเป็นแบบระยะคงที่

รายละเอียดที่ทำให้ค่าเพี้ยนเงียบ ๆ

  • หน่วยที่ใช้ ATR ออกมาเป็นหน่วยราคา แต่ระยะขั้นต่ำของโบรกเกอร์เป็นจุด ต้องแปลงด้วยค่าจุดของสัญลักษณ์ก่อนเทียบ
  • การปัดเศษ ระยะต้องปัดให้ลงล็อกกับจำนวนทศนิยมและขั้นราคาของสัญลักษณ์ ไม่งั้นราคาที่ส่งไปอาจไม่ถูกรับ
  • ลำดับการตัด ตัดด้วยเพดานก่อนหรือหลังคูณตัวคูณ ให้ผลคนละแบบ ควรบันทึกค่าทั้งก่อนและหลังตัด

ตรวจว่าค่าที่ EA ใช้คือค่าที่ตั้งใจจริง

อ่านจากบันทึกการทำงาน

คู่มือ MQL5 ระบุว่าฟังก์ชัน Print บันทึกข้อความลงใน log ของ Expert Advisor ซึ่งแสดงในแท็บ Experts ให้ไล่ดูว่าแต่ละครั้งที่เปิดไม้มีตัวเลขเหล่านี้ครบไหม คือค่า ATR ที่อ่านได้ กรอบเวลาและคาบที่ใช้อ่าน ตัวคูณ ระยะก่อนตัดด้วยเพดาน ระยะที่ใช้จริงหลังตัด และระยะขั้นต่ำของสัญลักษณ์ในขณะนั้น ถ้าบันทึกไม่มีข้อมูลพวกนี้ คุณจะยืนยันอะไรไม่ได้นอกจากวัดระยะห่างของไม้ย้อนหลัง วิธีอ่านแท็บเหล่านี้อยู่ใน วิธีอ่านแท็บ Experts และ Journal บน MT5

ตรวจทานด้วยมือหนึ่งครั้ง

เลือกไม้หนึ่งไม้จากบันทึก ย้อนไปดูกราฟในกรอบเวลาเดียวกันที่เวลานั้น แล้วเทียบค่า ATR บนกราฟกับค่าที่บันทึกไว้ ถ้าต่างกันมากให้สืบสาเหตุก่อนรันต่อ ที่พบบ่อยคืออ่านจากกรอบเวลาคนละอัน ใช้คาบคนละค่า หรือสูตรเฉลี่ยคนละสูตรกับอินดิเคเตอร์บนกราฟ

ทดสอบย้อนหลังหลายช่วงตลาด

ค่าที่ผูกกับความผันผวนต้องเห็นตลาดหลายแบบจึงจะรู้ว่ามันทำตัวอย่างไร คู่มือ MetaTrader 5 ส่วน Strategy Testing อธิบายว่าช่องวันที่ให้เลือกช่วงทดสอบเองได้ และการทดสอบแบบ Forward จะใช้ส่วนที่สองซึ่งเป็นช่วงหลังสุดของทั้งช่วงเสมอ ให้ใช้ความสามารถนี้แยกทดสอบช่วงที่ตลาดนิ่งนาน ช่วงที่เหวี่ยงแรง และช่วงรอยต่อระหว่างสองสภาวะ ไม่ใช่ทดสอบช่วงยาวช่วงเดียวแล้วดูผลรวม เพราะผลรวมกลบพฤติกรรมในรอยต่อที่เป็นจุดอ่อนของวิธีนี้ หลักการเลือกช่วงอยู่ใน ควร Backtest EA กี่ปีและต้องผ่านสภาวะตลาดแบบไหน ส่วนช่วงเวลาและสินทรัพย์ที่เราทดสอบระบบไว้ ดูได้ที่หน้า ผลทดสอบย้อนหลัง จากนั้นรันบนบัญชีทดลองต่ออีกระยะ เพราะผลทดสอบย้อนหลังไม่เห็นสเปรดที่ขยายจริงและการปฏิเสธคำสั่งจริง

สรุป

สรุป: ATR คือค่าเฉลี่ยเคลื่อนที่ของ True Range ซึ่งเป็นค่าที่มากที่สุดในสามค่า คือช่วงสูงต่ำของแท่งปัจจุบัน และผลต่างของราคาปิดก่อนหน้ากับราคาสูงสุดและต่ำสุดปัจจุบัน สองค่าหลังทำให้ระยะกระโดดระหว่างแท่งถูกนับเข้าไปด้วย ค่าที่ได้บอกระยะแกว่งที่ผ่านมาในหน่วยราคา ไม่บอกทิศทาง และไม่บอกว่าจะแกว่งต่อ EA เอามาคูณเป็นระยะกริดหรือ TP/SL เพื่อให้ค่าตั้งผูกกับสเกลของสินทรัพย์ แต่ก็ย้ายการตัดสินใจไปที่คาบ กรอบเวลา ตัวคูณ และเพดาน บทความนี้ไม่เสนอค่าที่ควรตั้ง เพราะค่าที่เหมาะต้องมาจากการทดสอบกับสินทรัพย์และทุนของคุณเอง

คำเตือนความเสี่ยง: การปรับระยะตามความผันผวนเป็นเพียงวิธีจัดการค่าตั้ง ไม่ได้ลดความเสี่ยงลงเป็นศูนย์ และไม่ได้รับประกันผลกำไร ระบบที่ผูกระยะกับ ATR ยังเสียหายได้เมื่อตลาดเปลี่ยนระดับความผันผวนเร็วกว่าที่ค่าเฉลี่ยจะตามทัน หรือเมื่อคำสั่งถูกปฏิเสธด้วยเงื่อนไขของสัญลักษณ์ ผลการทดสอบในอดีตไม่ได้บอกผลในอนาคต โปรดใช้เฉพาะเงินที่พร้อมรับความเสี่ยงและติดตามระบบสม่ำเสมอ อ่าน คำเตือนความเสี่ยงฉบับเต็ม
