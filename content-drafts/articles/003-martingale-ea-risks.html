Martingale EA คือระบบที่เพิ่มขนาดสถานะหลังเกิดผลขาดทุนหรือเมื่อราคายังไม่กลับตามแผน เป้าหมายคือให้ออเดอร์ที่ชนะในภายหลังชดเชยผลขาดทุนก่อนหน้า วิธีนี้อาจทำให้ประวัติการเทรดมีออเดอร์ชนะจำนวนมากและกำไรเติบโตค่อนข้างสม่ำเสมอ แต่ความเสี่ยงจะถูกสะสมไว้ในรอบที่ตลาดเคลื่อนต่อเนื่องผิดทาง

ประเด็นสำคัญจึงไม่ใช่ว่า Martingale “ชนะบ่อยแค่ไหน” แต่คือพอร์ตสามารถรับลำดับขาดทุนได้กี่ขั้น Lot รวมเพิ่มเร็วเพียงใด และระบบยอมปิดขาดทุนเมื่อไร บทความนี้อธิบายกลไกโดยใช้หลัก Exposure และ Margin ไม่ใช้คำรับรองผลตอบแทน

  • วิธีตรวจประวัติออเดอร์

Martingale EA ทำงานอย่างไร

รูปแบบคลาสสิกคือเพิ่มขนาดหลังขาดทุน เช่น เริ่มด้วย Lot ตั้งต้นหนึ่งระดับ แล้วคูณ Lot เมื่อเปิดไม้ถัดไป ระบบจริงอาจไม่ได้เพิ่มเป็นสองเท่าเสมอไป บางตัวใช้ตัวคูณต่ำกว่า 2 บางตัวเพิ่มตามจำนวนจุดที่ราคาผิดทาง และบางตัวคำนวณ Lot เพื่อให้กำไรรวมของ Basket กลับมาเป็นบวกเมื่อราคาฟื้นเพียงระยะสั้น

ไม่ว่าตัวคูณจะเท่าใด ควรแยกคำถามออกเป็น 3 เรื่อง

  1. Trigger อะไรทำให้ระบบเพิ่มออเดอร์ เช่น ขาดทุนหนึ่งไม้ ราคาเคลื่อนครบระยะ หรือสัญญาณเดิมยังคงอยู่
  2. Sizing Lot ไม้ถัดไปคำนวณอย่างไร ใช้ตัวคูณคงที่หรือปรับตาม Equity
  3. Exit ระบบปิดทั้งชุดเมื่อไร มี Basket Take Profit, Stop Loss หรือ Equity Stop หรือไม่

หากคำอธิบายมีเพียง “เพิ่มไม้เพื่อแก้พอร์ต” แต่ไม่ระบุ Trigger, Sizing และ Exit ผู้ใช้ยังไม่สามารถประเมินความเสี่ยงได้ครบ

ทำไม Lot รวมและ Margin จึงเพิ่มเร็ว

ลองพิจารณาเชิงโครงสร้างโดยไม่กำหนดว่า Lot เริ่มต้นควรเป็นเท่าไร หากระบบใช้ตัวคูณ 2 ขนาดแต่ละขั้นจะเป็น 1, 2, 4, 8 และ 16 หน่วย ขณะที่ขนาดสะสมรวมหลังห้าขั้นเท่ากับ 31 หน่วย ไม่ใช่ 16 หน่วย เพราะทุกสถานะก่อนหน้ายังอยู่ในพอร์ต

แม้ใช้ตัวคูณต่ำกว่า 2 การสะสมหลายขั้นก็ยังทำให้ Exposure และ Margin Required เพิ่มขึ้น การคำนวณ Margin ของ Forex บน MT5 อาศัย Volume, Contract Size และ Leverage ตามเงื่อนไขของ Symbol และบัญชี แต่ละโบรกเกอร์อาจตั้ง Contract Specification ต่างกัน จึงห้ามนำ Lot จากบัญชีหนึ่งไปสรุปว่าเหมาะกับอีกบัญชีโดยไม่ตรวจสเปก

เมื่อ Equity ลดลงพร้อมกับ Margin Used เพิ่มขึ้น Free Margin และ Margin Level จะลดลงสองทาง หากต่ำถึงเกณฑ์ของโบรกเกอร์ อาจเกิด Margin Call หรือ Stop Out ก่อนที่ราคาจะกลับตามที่ระบบคาดไว้ อ่านพื้นฐานการควบคุมทุนได้ที่ Money Management สำหรับ EA

Martingale ต่างจาก Grid อย่างไร

Grid คือการวางออเดอร์หลายระดับราคา ส่วน Martingale คือการเพิ่มขนาดสถานะหลังผลลัพธ์ที่เสียเปรียบ ระบบจึงอาจใช้ Martingale โดยไม่ใช้ Grid เช่น เพิ่ม Lot ในสัญญาณใหม่หลังออเดอร์ก่อนหน้าปิดขาดทุน หรือใช้ Grid แบบ Fixed Lot โดยไม่เพิ่ม Lot ก็ได้

กรณีที่ต้องระวังมากคือ Grid + Martingale เพราะระบบเพิ่มทั้ง “จำนวนออเดอร์” และ “ขนาดออเดอร์” พร้อมกัน ความเสี่ยงจึงต้องดู Lot รวมของ Basket และระยะที่ราคาเคลื่อนต่อได้ ไม่ใช่ดูเพียง Lot ไม้แรก รายละเอียดโครงสร้างอ่านต่อได้ที่ Grid EA คืออะไร

ทำไม Win Rate และ Equity Curve อาจดูดีเป็นเวลานาน

Martingale มักปิดชุดออเดอร์เมื่อราคากลับเพียงบางส่วน ทำให้หลายรอบจบด้วยกำไรเล็กหรือไม่มีผลขาดทุนที่ปิดจริง Win Rate จึงอาจสูง แต่ค่าดังกล่าวไม่ได้บอกขนาดความเสียหายของรอบที่ระบบปิดไม่สำเร็จ

ตัวเลขที่ควรอ่านร่วมกัน ได้แก่

  • Maximum Equity Drawdown เพื่อเห็นผลขาดทุนลอยตัว ไม่ดูเฉพาะ Balance Drawdown
  • Largest Loss และ Average Loss เพื่อตรวจว่ารอบเสียหายมีขนาดต่างจากรอบปกติเท่าไร
  • Maximum Consecutive Losses เพื่อดูจำนวนครั้งขาดทุนต่อเนื่องที่เคยเกิดในข้อมูลทดสอบ
  • Recovery Time เพื่อดูว่าพอร์ตใช้เวลานานเท่าไรจึงกลับมาระดับเดิม
  • Lot Distribution เพื่อดูว่า Lot สูงสุดเกิดบ่อยหรือเกิดในช่วงตลาดแบบใด

ผลย้อนหลังที่ไม่เคยเจอเหตุการณ์รุนแรงไม่ได้แปลว่าเหตุการณ์นั้นจะเกิดไม่ได้ การทดสอบควรครอบคลุมหลายสภาวะตลาดและมีการทดสอบนอกช่วงที่ใช้ปรับค่า ดูวิธีอ่านเพิ่มเติมที่ อ่านผล Backtest EA อย่างไร และ เหตุผลที่ต้องดู Forward Test

วิธีตรวจว่า EA ใช้ Martingale หรือไม่

  1. เปิดประวัติออเดอร์และเรียงตามเวลา จับกลุ่มออเดอร์ของ Symbol และ Magic Number เดียวกัน
  2. เปรียบเทียบ Lot ต่อเนื่อง หาก Lot เพิ่มหลังราคาเคลื่อนผิดทางหรือหลังขาดทุน ให้คำนวณตัวคูณจริง
  3. ดูว่าออเดอร์เก่ายังเปิดอยู่หรือไม่ เพราะการเพิ่ม Lot ขณะสถานะเดิมยังค้างทำให้ Exposure รวมสูงขึ้น
  4. ตรวจจุดปิด Basket ดูว่าระบบปิดหลายออเดอร์พร้อมกันเมื่อกำไรรวมเป็นบวกเล็กน้อยหรือไม่
  5. เปรียบเทียบ Balance กับ Equity ช่วงที่สองเส้นห่างมากอาจเป็นรอบที่ระบบกำลังแบก Floating Loss
  6. ดู Lot สูงสุดเทียบกับ Lot แรก ไม่สรุปจากค่าเฉลี่ย เพราะความเสี่ยงกระจุกอยู่ที่ปลายลำดับ

หากมีเพียงภาพ Screenshot ของกำไร ควรขอ Statement หรือผลทดสอบที่เปิดดูรายละเอียดออเดอร์ได้ และตรวจหลักฐานตาม เช็กลิสต์ประเมิน EA

ขีดจำกัดที่ระบบ Martingale ควรอธิบายได้

ขีดจำกัด เหตุผลที่ต้องรู้
จำนวนขั้นสูงสุด ทำให้รู้ว่าระบบหยุดเพิ่มความเสี่ยงเมื่อใด
Lot รวมสูงสุด ใช้ประเมิน Margin และ Exposure ของสถานการณ์เลวร้าย
Basket Stop Loss หรือ Equity Stop กำหนดจุดที่ยอมรับความเสียหายแทนการรอไม่มีกำหนด
Daily Loss Limit ป้องกันการเริ่มรอบใหม่ซ้ำในวันที่ตลาดผิดปกติ
Spread และ News Filter ลดการเปิดเพิ่มในช่วงต้นทุนหรือความผันผวนสูง แต่ไม่ลบความเสี่ยงทั้งหมด
เงื่อนไขหยุดเมื่อ Margin ต่ำ ช่วยไม่ให้ระบบเปิดออเดอร์เพิ่มจนใกล้ Stop Out

ขีดจำกัดไม่ได้ทำให้ Martingale กลายเป็นระบบที่ปลอดภัย แต่ช่วยให้ความเสียหายมีกรอบที่ประเมินได้มากขึ้น ผู้ใช้ยังต้องเลือกระดับความเสี่ยงให้สัมพันธ์กับทุนและยอมรับได้ว่าการหยุดระบบอาจเกิดขึ้นพร้อมผลขาดทุนจริง

คำเตือนความเสี่ยง: Martingale มีความเสี่ยงจากการเพิ่มขนาดสถานะและการกระจุกตัวของความเสียหายในเหตุการณ์ที่เกิดไม่บ่อย ผลกำไรที่ดูสม่ำเสมอหรือ Win Rate สูงไม่ใช่หลักฐานว่าระบบมีความเสี่ยงต่ำ การเทรดด้วย Leverage อาจทำให้สูญเสียเงินทุนอย่างรวดเร็ว
