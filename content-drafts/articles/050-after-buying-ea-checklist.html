หลังซื้อ EA การได้รับลิงก์ดาวน์โหลดไม่ใช่จุดจบของการส่งมอบ ผู้ซื้อควรมีชุดไฟล์ License คู่มือ Preset, Version, Support และหลักฐานที่เพียงพอให้ติดตั้ง ทดสอบ อัปเดต และกู้ระบบได้โดยไม่ต้องเดาทุกครั้ง จากนั้นต้องผ่าน Demo/Acceptance Test ก่อนใช้เงินจริง

รายการที่ต้องได้รับขึ้นกับแพ็กเกจและ Terms ไม่ใช่ทุก EA ต้องให้ Source Code หรือ Preset ทุก Broker แต่สิ่งที่โฆษณา/ตกลงไว้ควรตรวจรับเป็นลายลักษณ์อักษรและจัดเก็บอย่างปลอดภัย

สารบัญ

  • ตรวจไฟล์และ License
  • คู่มือที่ควรมี
  • ติดตั้งและตรวจ Version
  • Acceptance Test ก่อนเงินจริง
  • เตรียมข้อมูลสำหรับ Support
  • จัดเก็บและสำรอง

Checklist การส่งมอบ

รายการ สิ่งที่ต้องตรวจ
ไฟล์ EA ชื่อไฟล์, .ex5/Installer, Version และแหล่งดาวน์โหลด
Dependencies Indicator, Library, DLL, Font, WebRequest Domain ที่จำเป็น
Preset Symbol/Timeframe/Broker/Risk Profile ที่รองรับ
License License ID, Account/Device Lock, Activation เหลือและวันหมดอายุ
Documentation ติดตั้ง ตั้งค่า Update Backup Error และ Risk
Proof of Purchase Invoice, Receipt, Package, Terms และช่องทาง Support

ตรวจขนาดไฟล์และ Hash/Checksum หากผู้ขายให้ไว้ อย่า Rename/แก้ไฟล์ Original ให้เก็บสำเนาต้นฉบับ Read-only และใช้ Working Copy สำหรับติดตั้ง ดาวน์โหลดผ่าน HTTPS/บัญชีทางการ ไม่รับไฟล์ใหม่จากบัญชี Social ที่ยืนยันไม่ได้

คู่มือควรตอบคำถามที่เกิดจริง

  • รองรับ MT5 Build, Windows, Account Type และ Broker/Symbol ใด
  • วางไฟล์ใน Data Folder ตำแหน่งใดและ Refresh/Restart อย่างไร
  • Attach กับ Symbol/Timeframe ใด และเปิด AutoTrading ที่ไหน
  • แต่ละ Input มีหน่วย Default และขอบเขตอะไร
  • Fixed/Auto Lot, Maximum Orders, Stop และ Equity Protection ทำงานอย่างไร
  • สถานะ Ready/Error ดูจาก Dashboard, Experts หรือ Journal ตรงไหน
  • Update/ย้าย VPS/เปลี่ยนบัญชีโดยไม่เสีย License อย่างไร
  • หยุดระบบและจัดการ Position ที่เปิดอย่างไร

เริ่มจาก วิธีติดตั้ง EA บน MT5 และใช้คู่มือเฉพาะ ติดตั้ง FENIX PRO EA สำหรับไฟล์ของระบบนี้

ติดตั้งโดยบันทึก Baseline

  1. ตรวจ Source/Checksum และ Scan ตามนโยบาย Security
  2. บันทึก EA Version, MT5 Build, Broker, Server, Account Type
  3. สำรอง Data/Preset ปัจจุบันก่อนเปลี่ยน
  4. คัดลอกไฟล์ไป Folder ตามคู่มือและ Restart/Refresh
  5. Activate License ด้วยข้อมูลที่จำเป็นเท่านั้น
  6. โหลด Preset ที่ตรง Environment แล้ว Review ทุก Input
  7. Attach บน Demo และตรวจ Init Message ใน Experts/Journal
  8. เก็บ Screenshot/Baseline ของ Setting ที่อนุมัติ

อย่าคัดลอก Lot จาก Screenshot หรือ Preset ของผู้ขายมาใช้จริงโดยไม่คำนวณจากทุน, Symbol Specification และ Risk Budget ของตน อ่าน Money Management ก่อนตั้งค่า

Acceptance Test ก่อน Production

Functional

  • EA Initialize ผ่านและสถานะ Ready
  • อ่านราคา/เวลา/Symbol ถูก
  • เปิด แก้ และปิดออเดอร์บน Demo ตาม Logic
  • Magic Number/Comment แยก Ownership ถูก
  • Stop, TP, Trailing, Break Even และ Filter ทำงานตามคู่มือ

Risk

  • Fixed/Auto Lot คำนวณตรงกับ Expected Risk
  • Maximum Order/Lot/Exposure ถูกบังคับจริง
  • Daily Limit/Equity Stop และ Resume Rule ผ่าน Test
  • Spread/News/Session Filter แสดงเหตุผลที่ไม่เปิด

Operations

  • Restart MT5/VPS แล้วโหลด State ถูก ไม่เปิดซ้ำ
  • Disconnect RDP แล้ว Heartbeat/Log ยังเดิน
  • Network ขาดแล้ว Reconnect โดยไม่ส่งคำสั่งซ้ำ
  • Alert, Log, Backup และ Restore ใช้งานได้

ใช้ Forward Test ระยะที่เหมาะกับความถี่ Trade ไม่เร่งเปิดเงินจริงเพราะ Demo มี Winner หนึ่งครั้ง เปรียบเทียบ Execution/Cost กับข้อมูลที่ผู้ขายให้และบันทึก Deviation

เมื่อจะเริ่มเงินจริง

  1. เริ่มด้วย Risk ต่ำกว่าระดับเป้าหมาย
  2. จำกัด Symbol/Session ก่อน แล้วเพิ่มตาม Checkpoint
  3. ตรวจ Broker Contract Specification และ Stop Out
  4. ตั้ง Monitoring และผู้รับ Alert
  5. กำหนดระดับ Watch, Reduce, Pause, Emergency
  6. ทบทวนหลังจำนวน Trade/ช่วงเวลาที่กำหนด ไม่ปรับตามอารมณ์รายวัน

VPS ช่วยความต่อเนื่องแต่ยังต้องดูแล อ่าน VPS สำหรับ EA และเลือกสเปก/แผนสำรองให้เหมาะกับจำนวน Terminal

ส่งข้อมูลให้ Support โดยไม่ส่ง Password

เตรียม Template Ticket:

  • วันเวลาและ Timezone ที่เกิด
  • EA Version, MT5 Build, Broker/Server, Account Type (ปกปิด Login)
  • Symbol, Timeframe, Preset Name และ Input ที่เกี่ยวข้อง
  • Expected Behavior กับ Actual Behavior
  • Experts/Journal Log ช่วงก่อน-หลัง Error
  • Screenshot ที่ปกปิด Balance/Login หากไม่จำเป็น
  • ขั้นตอนที่ลองแล้วและผล

ไม่ส่ง Main/Investor Password, OTP, Remote Credential หรือไฟล์ License สาธารณะ หากต้อง Remote ให้ยืนยันผู้ช่วย จำกัด Session และติดตามการเปลี่ยนแปลง

ตรวจเงื่อนไขหลังซื้อ

  • บันทึกวันหมดอายุ License/Support และ Reminder
  • ติดตาม Changelog ไม่อัปเดต Production ทันที
  • รู้จำนวน Activation และขั้นตอนย้ายเครื่องจาก คู่มือ License EA
  • เก็บ Terms/Refund ตาม Checklist เงื่อนไขซื้อ EA
  • ทบทวน Contact/Support Channel เมื่อข้อมูลเปลี่ยน

สรุป: การรับมอบที่ครบทำให้ผู้ซื้อรู้ว่ามีไฟล์อะไร ใช้สิทธิ์อย่างไร ติดตั้งจาก Baseline ไหน และกู้ระบบได้เมื่อ VPS/เครื่องเสีย อย่าข้าม Demo/Acceptance Test เพื่อรีบหากำไร เพราะข้อผิดพลาดด้าน Version, Preset และ License ป้องกันได้ก่อนเงินจริง

คำเตือนความเสี่ยง: การติดตั้งและทดสอบผ่านไม่รับประกันผลกำไร EA, VPS, License และ Broker อาจขัดข้อง ผลในอดีตไม่รับประกันอนาคต โปรดใช้เงินที่พร้อมรับความเสี่ยงและติดตามระบบอย่างสม่ำเสมอ อ่าน คำเตือนความเสี่ยงฉบับเต็ม
