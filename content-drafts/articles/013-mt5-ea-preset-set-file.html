ไฟล์ SET บน MT5 คือไฟล์สำหรับบันทึกชุดค่า Input Parameters ของ EA หรือ Strategy Tester ช่วยให้โหลดค่าหลายสิบช่องกลับมาได้โดยไม่ต้องกรอกใหม่ทีละรายการ แต่ SET ไม่ใช่ไฟล์ EA ไม่ได้เก็บ Login และไม่ได้รับประกันว่าค่านั้นเหมาะกับทุก Symbol, Timeframe หรือ Version

ความผิดพลาดที่พบบ่อยคือเห็นว่าโหลดไฟล์สำเร็จแล้วกด OK ทันที ทั้งที่ชื่อ Parameter เปลี่ยน ค่า Risk ไม่ตรงเงินทุน หรือ Preset ถูกสร้างสำหรับ Symbol อื่น ขั้นตอนสำคัญจึงไม่ใช่แค่ Load แต่ต้องตรวจค่าหลัง Load และเก็บหลักฐานว่าไฟล์ใดใช้กับระบบใด

สารบัญ

  • ไฟล์ SET เก็บอะไร
  • วิธีบันทึก Preset
  • วิธีโหลดอย่างปลอดภัย
  • ตั้งชื่อและจัดโฟลเดอร์
  • Preset กับ Version ของ EA
  • ปัญหาที่พบบ่อย

ไฟล์ SET เก็บและไม่เก็บอะไร

ไฟล์ SET เก็บชื่อ Parameter และค่าที่เลือกในแท็บ Inputs เช่น Lot, Risk, ช่วงเวลาเทรด, Stop Loss, Filter หรือ Magic Number ตามที่ EA เปิดให้ปรับ แต่สิ่งต่อไปนี้อาจไม่ได้อยู่ใน SET:

  • ตัวไฟล์ EX5 และ License
  • Symbol/Timeframe ของกราฟ เว้นแต่ EA มี Input กำหนดเอง
  • สีกราฟ Indicator และ Object บางชนิด
  • สถานะปุ่ม Algo Trading ของ Terminal
  • Permission ระดับ Common เช่น DLL/WebRequest บางส่วน
  • Position ที่เปิดอยู่และสถานะภายในที่ EA เก็บแยก

หากต้องการเก็บทั้งหน้าตากราฟ EA และ Indicator ให้ใช้ Template หรือ Profile เพิ่ม เอกสาร MT5 ระบุว่า Chart Template สามารถเก็บ EA และ Parameters ที่ผูกกับกราฟได้ แต่การนำ Template ไปใช้ต้องระวังไม่ให้แทน EA/การตั้งค่าบนกราฟปลายทางโดยไม่ตั้งใจ

วิธีบันทึกไฟล์ SET

  1. เปิดกราฟและ Properties ของ EA ด้วย F7 หรือคลิกขวา Expert List
  2. ไปแท็บ Inputs
  3. ตรวจค่าทุกช่อง โดยเฉพาะ Risk, Lot, Magic, Symbol และ Session
  4. กด Save
  5. ตั้งชื่อที่บอก EA, Version, Symbol, Timeframe และระดับความเสี่ยง
  6. บันทึกในโฟลเดอร์ที่ทีมสำรองได้ และเก็บสำเนานอก VPS
  7. จับ Screenshot หน้า Inputs หรือ Export รายการค่าเพื่อใช้ตรวจเทียบ

ตัวอย่างชื่อที่อ่านย้อนหลังได้:

fenix-pro-v1-3-xauusd-h1-low-20260724.set

อย่าใช้ชื่ออย่าง new.set, ล่าสุด.set หรือ ดีมาก.set เพราะเมื่อมีหลายไฟล์จะไม่รู้ว่า “ล่าสุด” ของ Version ใดและใช้กับบัญชีแบบไหน

วิธีโหลด Preset โดยไม่ใช้ค่าผิด

  1. ยืนยันชื่อและ Version ของ EA บนกราฟ
  2. ยืนยัน Symbol และ Timeframe ตามคู่มือ
  3. เปิด Properties > Inputs แล้วกด Load
  4. เลือกไฟล์ SET ที่ตรงกับ EA/Version
  5. ตรวจว่าค่าเปลี่ยนครบและไม่มี Parameter สำคัญหาย
  6. ตรวจ Lot/Risk ด้วยตนเอง ไม่เชื่อจากชื่อไฟล์อย่างเดียว
  7. ตรวจ Magic Number ไม่ซ้ำกับกราฟอื่น
  8. กด OK แล้วดู Experts Log ว่า Init สำเร็จ
  9. บันทึกชื่อ Preset ที่ใช้จริงลงตารางระบบ

หากกำลังติดตั้ง FENIX PRO EA ให้ใช้ Preset ที่ทีมส่งให้ตามคู่มือ การตั้งค่า FENIX PRO EA และตรวจขั้นตอนจาก คู่มือติดตั้งฉบับภาพ

ระบบตั้งชื่อและจัดเก็บที่แนะนำ

ส่วนของชื่อ เหตุผล
Product/EA ป้องกันโหลดข้ามระบบ
Version รู้ว่า Parameter Schema ตรงกันหรือไม่
Symbol/Timeframe ลดการใช้ค่าข้ามตลาด
Risk Profile แยก Low/Custom โดยต้องมีเอกสารนิยาม
Date ตรวจประวัติการเปลี่ยนแปลง

ในแต่ละไฟล์ควรมี Change Log แยก เช่นวันที่แก้ ค่าใดเปลี่ยน เหตุผล ผู้อนุมัติ และผลทดสอบที่เกี่ยวข้อง ไม่แก้ Preset เดิมแล้วบันทึกทับโดยไม่มี Version เพราะจะย้อนกลับไม่ได้เมื่อผลต่างจากเดิม

ทำไม Preset ต้องตรง Version ของ EA

เมื่อผู้พัฒนาเพิ่ม ลบ หรือเปลี่ยนชื่อ Input ไฟล์ SET รุ่นเก่าอาจโหลดได้เพียงบางค่า ค่าใหม่อาจใช้ Default หรือค่าบางช่องอาจแมปไม่ตรง การที่หน้าต่างไม่แสดง Error ไม่ได้ยืนยันว่าค่าทั้งหมดถูกต้อง

ก่อนอัปเดต EA:

  • Save Preset ของ Version ปัจจุบัน
  • บันทึก Screenshot และ Version
  • อ่าน Release Notes ว่า Parameter ใดเปลี่ยน
  • ทดสอบ SET เก่าบน Demo หรือ Terminal สำรอง
  • สร้าง SET ชุดใหม่หาก Schema เปลี่ยน
  • อย่าแทนไฟล์ EA ขณะมี Position หากไม่รู้กระบวนการ Migration

ค่าที่ควรตรวจเป็นพิเศษหลังอัปเดตคือ Risk Mode, Lot, Magic Number, Trading Session, News Filter, Max Spread, Equity Stop และค่าที่มีหน่วยเป็น Points/Pips เพราะชื่อใกล้กันแต่ความหมายอาจเปลี่ยนได้

ปัญหาที่พบบ่อย

กด Load แล้วค่าไม่เปลี่ยน

อาจเลือกไฟล์คนละ EA, SET เสีย หรือ Parameter Name ไม่ตรง Version เปิดด้วย Text Editor เพื่อดูโครงได้แต่ไม่ควรแก้สุ่ม ให้ขอไฟล์ที่ถูกต้องจากผู้พัฒนา

หาไฟล์ไม่เจอ

MT5 เปิด Dialog จากโฟลเดอร์ Presets/Tester ตามบริบท แต่ผู้ใช้สามารถเลือก Path อื่นได้ ควรเก็บ Master Copy ในโฟลเดอร์ที่สำรองและคัดลอกมาใช้ ไม่ฝากไฟล์เดียวไว้ใน VPS

โหลดแล้ว EA ไม่ทำงาน

ดู Experts/Journal ว่า Parameter Validation ผ่านหรือไม่ ตรวจ Permission และ Symbol/Timeframe การโหลด SET สำเร็จไม่ได้แปลว่าทุกเงื่อนไขพร้อม อ่าน วิธีอ่าน Experts และ Journal

ค่า Lot เปลี่ยนเอง

หาก EA ใช้ Auto Lot ค่าแสดงอาจเป็น Parameter ของสูตร ไม่ใช่ Lot สุดท้าย ต้องอ่านวิธีคำนวณและดู Volume ที่ส่งจริง ห้ามสรุปจากชื่อ Preset “Low” โดยไม่รู้ค่าความเสี่ยง

ไฟล์ SET ช่วยลด Human Error ได้เมื่อมีระบบ Version Control ที่ชัดเจน แต่หากตั้งชื่อไม่ดีและไม่มีขั้นตรวจกลับ มันกลับทำให้โหลดค่าผิดได้เร็วกว่าเดิม

คำเตือนความเสี่ยง: Preset เป็นชุดการตั้งค่า ไม่ใช่คำรับรองผลลัพธ์ ค่าที่เหมาะสมขึ้นกับเงินทุน Symbol, Contract Specification และระดับความเสี่ยงที่ผู้ใช้รับได้ ต้องตรวจทุกครั้งก่อนใช้เงินจริง
