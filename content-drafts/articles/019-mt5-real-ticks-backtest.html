Every tick based on real ticks คือโหมด Strategy Tester ที่ใช้ข้อมูล Tick จริงซึ่งโบรกเกอร์บันทึกไว้ แทนการสร้าง Tick ระหว่างแท่งจากข้อมูลหนึ่งนาที เมื่อข้อมูลครบ โหมดนี้สะท้อนลำดับ Bid/Ask และ Spread ที่เปลี่ยนในอดีตได้ละเอียดกว่า แต่ยังไม่ใช่การจำลองบัญชีจริงแบบสมบูรณ์

คำว่า “Real Ticks” บอกแหล่งข้อมูลราคา ไม่ได้หมายความว่า Tester รู้ Liquidity, Queue, Reject, VPS Outage หรือ Slippage ของคำสั่งคุณในอนาคต ผู้ทดสอบยังต้องกำหนด Commission, Delay, Specification และตรวจคุณภาพข้อมูลด้วย

สารบัญ

  • โหมด Tick แต่ละแบบ
  • Real Ticks ให้ข้อมูลอะไร
  • EA แบบไหนต้องใช้โหมดใด
  • Bid, Ask และ Spread
  • ตรวจคุณภาพข้อมูล
  • Workflow ทดสอบที่ประหยัดเวลา

เปรียบเทียบโหมดสร้างราคาใน MT5

โหมด ข้อมูลที่ใช้ การใช้งาน
Every tick based on real ticks Tick จริงจาก Server เมื่อมีข้อมูล ตรวจละเอียดและระบบไวต่อ Spread/Intrabar
Every tick Tick ที่สร้างจาก M1 พร้อมกฎการจำลอง ทดสอบ OnTick เมื่อต้องการช่วงข้อมูลกว้าง
1 minute OHLC Open, High, Low, Close ของทุก M1 ประเมินระบบที่ไม่ขึ้นกับเส้นทาง Tick ละเอียด
Open prices only ราคาเปิดของแท่ง Timeframe ทดสอบ คัดกรองเร็วสำหรับระบบทำงานเฉพาะเปิดแท่ง

โหมดเร็วมีประโยชน์สำหรับ Screening แต่ไม่ควรเป็น Report สุดท้ายหาก EA ใช้ Trailing, Stop/Pending Intrabar, Spread Filter, Scalping หรือเงื่อนไขที่ตรวจทุก Tick

Real Ticks ต่างจาก Tick ที่สร้างอย่างไร

ใน Real Ticks Tester เล่นลำดับ Tick ที่สะสมจาก Exchange/Liquidity Provider ผ่านโบรกเกอร์ Spread สามารถเปลี่ยนภายในนาทีได้ ส่วนโหมด Every Tick ที่สร้างจาก M1 จะใช้กฎสร้างจุดอ้างอิงระหว่าง Open, High, Low, Close และ Ask คำนวณจาก Bid + Spread ของ Bar ตามเอกสาร MT5

ความต่างนี้สำคัญเมื่อ:

  • EA เปิด/ปิดหลายครั้งภายใน M1
  • ใช้ Tick Count หรือ Microstructure
  • มี Stop/Pending ใกล้ราคา
  • กรอง Spread ก่อน Entry
  • ใช้ Trailing/Break Even ที่ขยับระหว่างแท่ง
  • เทรดรอบข่าวหรือช่วง Spread ขยาย

หากช่วงใดมี Minute Bar แต่ไม่มี Tick จริง Tester อาจสร้าง Tick เพื่อให้ทดสอบต่อได้ตามกฎของแพลตฟอร์ม จึงต้องอ่าน History Quality และจำนวน Tick ไม่สรุปว่าเลือกเมนู Real Ticks แล้วข้อมูลจริง 100% ทุกวินาที

เลือกโหมดตามตรรกะ EA

ระบบทำงานเฉพาะเปิดแท่ง

Open Prices Only ใช้ Screening ได้หากโค้ดอ่านสัญญาณเฉพาะ Bar ใหม่และไม่พึ่ง Stop/Trailing Intrabar แต่ควรยืนยันรอบสุดท้ายด้วยโหมดละเอียด เพราะการ Execution ของ Stop และ Pending อาจต่าง

ระบบอ่านค่า M1 OHLC

1 Minute OHLC เร็วกว่าทุก Tick และมีจุด OHLC ต่อ M1 แต่ลำดับ High/Low ที่จำลองอาจมีผลกับ Stop/Take Profit หากทั้งสองระดับอยู่ในแท่งเดียวกัน

Scalping/Grid/ข่าว

ควรทดสอบ Real Ticks เมื่อมีข้อมูล และทำ Stress Test Spread/Delay เพิ่ม เพราะระบบเหล่านี้ไวต่อเส้นทางราคาและต้นทุนมาก อ่านภาพรวมที่ Scalping EA บน MT5

Multi-symbol EA

ตรวจข้อมูล Tick ของทุก Symbol ที่ EA เรียก ไม่ใช่เฉพาะ Chart หลัก Strategy Tester จะโหลดข้อมูลที่จำเป็น แต่ Gap หรือ Time Alignment ของ Symbol รองยังมีผลได้

ทำไมต้องสนใจ Bid และ Ask

กราฟจำนวนมากแสดง Bid เป็นหลัก แต่คำสั่ง Buy เปิดที่ Ask และปิดที่ Bid ส่วน Sell เปิดที่ Bid และปิดที่ Ask ดังนั้น Spread อยู่ในเส้นทางกำไรขาดทุนแม้มองไม่เห็นจาก Candle เดียว

เอกสาร MT5 ระบุว่าแม้กราฟของบางตลาดสร้างจาก Last Price การเทรดยังดำเนินการผ่าน Bid/Ask โหมด Real Ticks จึงช่วยสะท้อน Spread ที่เปลี่ยนในอดีตได้ดีกว่า Fixed Spread แต่ผลทดสอบยังต้องรวม Commission และความหน่วง

สำหรับ EA ที่กำไรเฉลี่ยต่อ Trade เล็ก ต้นทุนเพิ่มเพียงเล็กน้อยอาจเปลี่ยน Expectancy จากบวกเป็นลบ ต้องดู Distribution ของ Spread ในช่วงเวลาเทรด ไม่ใช้ค่าเฉลี่ยทั้งวันแทนช่วงข่าวหรือ Rollover

วิธีตรวจข้อมูลก่อนเชื่อผล

  • ดู History Quality และช่วงสีที่บ่งบอก Gap
  • ตรวจจำนวน Bars/Ticks เทียบกับช่วงวันที่
  • เปิดกราฟดู Spike หรือ Gap ที่ผิดปกติ
  • ตรวจ Symbol Specification และ Session
  • ดู Journal ว่ามีการสร้าง Tick แทนช่วงข้อมูลขาดหรือไม่
  • เปรียบเทียบผลจาก Server/โบรกเกอร์มากกว่าหนึ่งแหล่ง
  • เก็บวันที่ดาวน์โหลดข้อมูล เพราะ History อาจถูกอัปเดตภายหลัง

หากผลต่างมากระหว่าง Real Ticks และ Every Tick ให้หาสาเหตุก่อน ไม่เลือกผลที่ดีกว่า อาจมาจาก Spread, Tick Sequence, Gap หรือเงื่อนไข EA ที่ไวเกินไป

Workflow ทดสอบที่สมดุลความเร็วกับความละเอียด

  1. รัน Visual ช่วงสั้นเพื่อตรวจตรรกะ
  2. ใช้ Open Prices/OHLC คัด Preset เฉพาะเมื่อ EA รองรับ
  3. รัน Every Tick หรือ Real Ticks กับตัวเลือกที่เหลือ
  4. ทำ Stress Test Spread, Commission และ Delay
  5. เปลี่ยน Start Date เพื่อดูความไว
  6. แยก Out-of-Sample และ Forward Test
  7. บันทึก Modeling Mode ในชื่อ Report ทุกครั้ง

คู่มือการตั้งค่าทั้งหมดอยู่ที่ วิธี Backtest EA บน MT5 และหลักอ่านรายงานที่ อ่านผล Backtest EA อย่างไร

คำเตือนความเสี่ยง: Real Ticks เพิ่มความละเอียดของข้อมูลอดีต แต่ไม่จำลอง Market Impact, Liquidity และ Execution ในอนาคตครบ ต้องยืนยันด้วย Out-of-Sample, Forward Test และการใช้ความเสี่ยงที่จำกัด
