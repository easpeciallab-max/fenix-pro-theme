Magic Number บน MT5 คือหมายเลขที่โปรแกรมใช้ติดตามว่าคำสั่ง Order, Deal หรือ Position เกี่ยวข้องกับ EA ใด เปรียบได้กับรหัสประจำชุดกลยุทธ์ ช่วยให้ EA แยกออเดอร์ของตนออกจากการเทรดมือหรือ EA ตัวอื่น แม้จะอยู่ในบัญชีเดียวกัน

Magic Number ไม่ใช่รหัสลับ ไม่ได้เพิ่มความปลอดภัย และไม่ได้ทำให้ผลเทรดดีขึ้น ประโยชน์ของมันอยู่ที่การจัดระเบียบ หากโค้ดของ EA ใช้ Magic อย่างถูกต้อง การกำหนดเลขไม่ซ้ำจะลดโอกาสที่ระบบหนึ่งไปแก้ Stop Loss, ปิด Position หรือคำนวณ Basket ของอีกระบบโดยไม่ตั้งใจ

สารบัญ

  • Magic Number ทำงานอย่างไร
  • กรณีใดต้องแยกเลข
  • วิธีตั้งอย่างเป็นระบบ
  • เปลี่ยนเลขตอนมีออเดอร์ได้ไหม
  • ข้อจำกัดในบัญชี Netting
  • วิธีตรวจและแก้ปัญหา

Magic Number ทำงานอย่างไรใน MT5

ใน MQL5 มี Property สำหรับ Magic ของ Order, Deal และ Position นักพัฒนาสามารถกำหนดค่าเมื่อส่งคำสั่ง แล้วกรองรายการภายหลังเพื่อจัดการเฉพาะรายการที่ตรงกับ ID ของระบบ เช่น EA หมายเลข 12001 จะคำนวณกำไรขาดทุนหรือปิดเฉพาะ Position ที่มี Magic 12001

อย่างไรก็ตาม Magic Number จะช่วยได้ก็ต่อเมื่อโค้ดใช้มันจริง EA บางตัวกรองจาก Symbol อย่างเดียว บางตัวใช้ทั้ง Symbol + Magic และบางตัวมีระบบ Mapping ภายใน ผู้ใช้จึงต้องอ่านคู่มือ ไม่ควรสรุปจากช่อง Input ว่าระบบแยกออเดอร์ครบทุกกรณี

Comment ของ Order เป็นข้อมูลช่วยอ่าน แต่ไม่ควรใช้แทน Magic เพราะ Comment อาจถูกแก้ ย่อ หรือมีรูปแบบต่างกันตาม Trade Server และขั้นตอนของ EA

เมื่อไรต้องใช้ Magic Number ไม่ซ้ำกัน

  • เปิด EA หลายตัวในบัญชีเดียวกัน
  • เปิด EA ตัวเดียวกันหลายกราฟหรือหลาย Symbol
  • ใช้ Preset ต่างกันสำหรับกลยุทธ์คนละแบบ
  • แบ่งบัญชีเป็นหลาย Basket ที่มี Equity/Profit Target แยกกัน
  • มี Trade Copier หรือระบบบริหาร Position อื่นร่วมด้วย
  • ต้องการแยกผลลัพธ์ตามระบบเพื่อวิเคราะห์ภายหลัง

หากเปิด EA เดียวบนกราฟเดียวและไม่มีระบบอื่น Magic เริ่มต้นอาจเพียงพอ แต่ควรบันทึกไว้ เพราะเมื่อเพิ่มกราฟหรือย้าย Preset ภายหลังจะได้ไม่ใช้เลขชนกันโดยไม่รู้ตัว

อ่านภาพรวมการจัดหลายระบบได้ที่ วิธีเปิด EA หลายตัวบน MT5 และคุมความเสี่ยงรวม

วิธีตั้ง Magic Number แบบจัดการต่อได้

ไม่มีเลข “ดีที่สุด” และตัวเลขใหญ่ไม่ได้ปลอดภัยกว่าเลขเล็ก เป้าหมายคือความไม่ซ้ำและตรวจย้อนกลับได้ วิธีใช้งานจริงคือสร้าง Convention ที่ทีมเข้าใจตรงกัน เช่นแบ่งช่วงเลขตามระบบ บัญชี หรือ Symbol

Magic ตัวอย่างการบันทึก
21001 EA A / XAUUSD / Preset Low / H1
21002 EA A / EURUSD / Preset Low / H1
22001 EA B / XAUUSD / Preset Standard / M15

นี่เป็นเพียงรูปแบบบันทึก ไม่ใช่เลขแนะนำสำหรับทุกระบบ ก่อนเปลี่ยนค่าให้ตรวจข้อกำหนดของ EA เพราะบางผลิตภัณฑ์กำหนดช่วงเลข สร้าง Magic อัตโนมัติ หรือใช้เลขเดียวกันเพื่อรวม Basket หลายกราฟ

ตารางควรเก็บอย่างน้อย:

  • เลข Magic
  • ชื่อ EA และ Version
  • ชื่อบัญชี/Server โดยไม่เก็บ Password
  • Symbol และ Timeframe
  • ชื่อไฟล์ SET
  • วันที่เริ่มใช้และผู้แก้ไขล่าสุด

เปลี่ยน Magic Number ตอนมี Position ค้างได้ไหม

ไม่ควรเปลี่ยนโดยไม่ทราบตรรกะของ EA เพราะ Position เดิมยังเก็บ Magic เก่า ส่วน EA หลังโหลดค่าใหม่อาจมองหาเฉพาะ Magic ใหม่ ทำให้ไม่เห็น Position เดิมและไม่จัดการ Stop, Trailing, Basket Close หรือ Recovery ตามแผน

แนวทางที่ปลอดภัยกว่า:

  1. หยุดเปิดออเดอร์ใหม่ตามวิธีที่คู่มือกำหนด
  2. บันทึก Screenshot, Preset และรายการ Position เดิม
  3. ติดต่อผู้พัฒนาว่า Version นี้ติดตาม Position หลังเปลี่ยน Magic อย่างไร
  4. หากต้องรอ Position เดิมจบ ให้คงกราฟเดิมและค่าเดิมไว้
  5. ทดสอบขั้นตอนเปลี่ยนเลขบน Demo ก่อนบัญชีจริง

อย่าลบกราฟหรือวาง EA ชุดใหม่ทันทีโดยคิดว่า Stop Loss ที่ Server มีอยู่จะทดแทนตรรกะทั้งหมด เพราะฟังก์ชันที่ทำงานใน Terminal เช่น Trailing Stop หรือ Basket Exit อาจหยุดไป

Magic Number กับบัญชี Netting

ในบัญชี Hedging สามารถมีหลาย Position ของ Symbol เดียวกันและแต่ละ Position อาจมีข้อมูล Magic แยกกันได้ แต่บัญชี Netting จะรวมสถานะของ Symbol เป็น Position สุทธิหนึ่งรายการ การเพิ่ม Deal จากหลายระบบอาจเปลี่ยน Position เดียวกัน ทำให้การแบ่ง Ownership ด้วย Magic ซับซ้อนขึ้น

ดังนั้น EA หลายตัวที่เทรด Symbol เดียวกันบนบัญชี Netting ต้องถูกออกแบบให้ทำงานร่วมกันโดยเฉพาะ การตั้ง Magic ไม่ซ้ำอย่างเดียวอาจไม่เพียงพอ ควรถามผู้พัฒนาว่ารองรับ Netting, Hedging หรือทั้งสองแบบ และทดสอบการเปิด/ลด/กลับทิศ Position จริงใน Demo

ปัญหาที่พบบ่อยและวิธีตรวจ

EA ปิดออเดอร์ของอีกตัว

ตรวจว่า Magic ซ้ำหรือไม่ จากนั้นดูว่า EA แยกด้วย Symbol + Magic หรือเลือก Position ทั้ง Symbol หากเกิดในบัญชี Netting ให้ตรวจ Compatibility เพิ่ม

EA ไม่จัดการ Position เดิมหลัง Restart

ตรวจว่า Preset, Magic และ Version หลัง Restart ตรงกับก่อนหน้า ดู Experts Log ว่า EA พบ Position จำนวนเท่าไรและมีข้อความ Init/Recovery หรือไม่

รายงานผลรวมหลายระบบปะปนกัน

Export History แล้วแยกด้วย Magic/Comment ตามข้อมูลที่มี หากผู้ให้บริการรายงานผลไม่แยก Magic ควรขอวิธีระบุ Trade ของแต่ละระบบก่อนสรุปประสิทธิภาพ

Magic ซ้ำแต่ยังไม่เกิดปัญหา

การไม่เกิดปัญหาในช่วงสั้นไม่ยืนยันว่าปลอดภัย อาจยังไม่มี Position ซ้อนกันหรือเงื่อนไขแก้ไขออเดอร์ยังไม่เกิด ควรแก้โครงตั้งแต่ก่อนเปิดหลายระบบจริง

ใช้แท็บ Experts และ Journal เพื่อตรวจข้อความจากระบบตาม วิธีอ่าน Log ของ MT5 และจัดความเสี่ยงรวมผ่าน หลัก Money Management สำหรับ EA

คำเตือนความเสี่ยง: Magic Number เป็นเครื่องมือแยกคำสั่ง ไม่ใช่ระบบจำกัดขาดทุน การเปิดหลาย EA ยังเพิ่ม Exposure, Margin Used และโอกาสขาดทุนพร้อมกัน ต้องกำหนดเพดานความเสี่ยงระดับพอร์ตแยกต่างหาก
