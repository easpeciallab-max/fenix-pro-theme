Equity Curve คือเส้นมูลค่าบัญชีที่รวม Balance กับกำไร/ขาดทุนของ Position ที่ยังเปิดอยู่ ช่วยให้เห็น Floating Drawdown และความเสี่ยงระหว่างทางที่ Balance Curve อาจไม่แสดง โดยเฉพาะ EA ที่ถือขาดทุนไว้นาน ปิดกำไรทีละน้อย หรือบริหารหลายออเดอร์เป็น Basket

เส้นที่ไต่ขึ้นเรียบไม่ได้แปลว่าปลอดภัยเสมอ ต้องรู้ว่า Plot จาก Balance หรือ Equity, Sampling ถี่แค่ไหน รวม Deposit/Withdrawal หรือไม่ และมี Open Position ณ จุดสิ้นสุดหรือเปล่า ภาพที่ครอปเฉพาะช่วงสวยไม่มีข้อมูลพอตัดสิน

สารบัญ

  • Balance กับ Equity ต่างกันอย่างไร
  • อ่านความชันและรูปทรง
  • อ่าน Drawdown และ Recovery
  • ดู Distribution ใต้เส้น
  • รูปแบบที่ต้องระวัง
  • เปรียบเทียบหลายเส้นอย่างเป็นธรรม

Balance Curve กับ Equity Curve

เส้น รวมอะไร ข้อจำกัด
Balance ผลของ Deal/Position ที่ปิดแล้วและ Balance Operation ไม่เห็น Floating P/L ของ Position เปิด
Equity Balance + Floating Profit/Loss ตามราคาปัจจุบัน ขึ้นกับ Sampling และราคาที่ใช้ Mark

หาก Balance ขึ้นต่อเนื่องแต่ Equity อยู่ต่ำมาก แปลว่าระบบปิดกำไรแต่ถือขาดทุนค้าง ความต่างระหว่างสองเส้นคือข้อมูลสำคัญ ไม่ควรดู Balance เพียงเพราะเรียบกว่า

อ่านนิยาม Drawdown เพิ่มที่ Drawdown คืออะไร และค่า Report ที่ สถิติ EA อธิบายอย่างไร

ความชันและความนิ่งบอกอะไร

ความชัน

ความชันสูงอาจมาจาก Edge ที่ดีหรือ Risk/Leverage สูง ต้อง Normalize ด้วย Drawdown, Volatility และ Exposure ไม่เปรียบเทียบผลตอบแทนโดยไม่เทียบความเสี่ยง

ความเรียบ

เส้นเรียบอาจเกิดจาก Trade จำนวนมากที่กระจายดี หรือจาก Mark-to-market/Sampling ที่หยาบ รวมถึงกลยุทธ์เก็บกำไรเล็กและซ่อน Loss ใหญ่ การดูความเรียบด้วยตาอย่างเดียวจึงไม่พอ

ช่วงราบ

อาจหมายถึงไม่มีสัญญาณ ตลาดไม่เหมาะ Filter หยุด หรือ Edge เสื่อม ต้องดู Trade Count และ Regime ไม่เรียกทุกช่วงราบว่า “พักระบบตามแผน” โดยไม่มี Log

ขั้นบันได

Winner ใหญ่เป็นช่วงอาจเป็นธรรมชาติของ Trend Following แต่ต้องดูว่าหากพลาด Winner ไม่กี่ครั้งผลรวมเปลี่ยนอย่างไร

อ่าน Drawdown และ Recovery

Drawdown วัดการลดลงจากจุดสูงก่อนหน้าไปจุดต่ำถัดไป มีทั้งจำนวนเงินและเปอร์เซ็นต์ ควรดู:

  • Maximum Drawdown
  • Average/Median Drawdown
  • Drawdown Duration
  • Time to Recovery
  • Underwater Curve: เวลาที่ Equity ต่ำกว่าจุดสูงเดิม
  • Drawdown Clustering ตาม Regime

Maximum จาก Backtest เป็นค่าที่เคยเกิด ไม่ใช่เพดานในอนาคต ใช้ Monte Carlo/Stress Test เพื่อประเมิน Distribution เพิ่ม และกำหนด Risk Budget ต่ำกว่าจุดที่พอร์ต/ผู้ใช้รับไม่ไหว

Recovery ที่เร็วในอดีตอาจพึ่ง Winner เดียว อย่าคำนวณเพียง Recovery Factor; ดู Trade ที่สร้างการฟื้นและความเป็นไปได้ที่ Winner นั้นจะไม่เกิดใน Sample ใหม่

ข้อมูลที่ควรเปิดใต้ Equity Curve

  • Trade-by-trade Return
  • Monthly/Weekly Returns
  • Average Win, Average Loss และ Payoff
  • Maximum Consecutive Losses
  • Holding Time และ MAE/MFE
  • Lot/Exposure ตามเวลา
  • Contribution ของ Top Winners
  • Open Positions ณ วันสิ้นสุด

เส้นเดียวกันอาจมาจากระบบต่างกันมาก เช่น Win Rate สูง/Payoff ต่ำ กับ Win Rate ต่ำ/Winner ใหญ่ การวางแผนทุนและพฤติกรรมผู้ใช้จึงต้องดู Distribution

Scale และความถี่ในการบันทึกทำให้เส้นดูต่างกัน

กราฟที่ใช้แกน Linear กับ Logarithmic ให้ภาพความชันต่างกัน เมื่อบัญชีโตมาก เส้น Linear อาจทำให้ Drawdown ช่วงต้นดูเล็ก ขณะที่ Log Scale ช่วยเปรียบเทียบการเปลี่ยนแปลงเชิงเปอร์เซ็นต์ได้ดีขึ้น ควรแสดงชื่อ Scale และไม่สลับโดยไม่บอก

ความถี่การ Sampling ก็สำคัญ หากบันทึก Equity วันละครั้ง อาจพลาด Floating Drawdown ภายในวัน ระบบที่เปิด Basket ระยะสั้นอาจดูเรียบผิดจริง ควรใช้ข้อมูลระดับ Tick/Minute หรือความถี่ที่สอดคล้องกับ Holding Period และรายงาน Worst Intraday Equity แยกเมื่อทำได้

  • ตรวจว่า Curve ใช้ Time หรือ Trade Number เป็นแกนนอน
  • ดูว่า Equity Mark ด้วย Bid/Ask หรือราคาใด
  • ยืนยันว่า Swap/Commission ถูกหักในจุดใด
  • แยกผลจาก Deposit, Withdrawal และ Credit
  • ใช้ความถี่เดียวกันเมื่อเปรียบเทียบหลายระบบ

รูปแบบที่ควรตรวจให้ลึก

Balance ขึ้น แต่ Equity แยกลง

อาจเป็น Grid/Martingale หรือระบบถือ Loss ตรวจ Basket, Lot Growth, Margin และ Stop Logic

กำไรทั้งหมดเกิดปลายช่วง

อาจพึ่ง Regime เดียวหรือมี Parameter ที่เข้ากับช่วงล่าสุด ทำ OOS/Start-Date Sensitivity เพิ่ม

เส้นตรงผิดธรรมชาติ

ตรวจ Sampling, Deposit/Withdrawal, Missing Data และว่ารายงานรวม Floating หรือไม่ อย่าสรุปว่าเป็น Fraud จากรูปอย่างเดียว แต่ต้องขอข้อมูลต้นทาง

Drawdown ถูกตัดด้วย Deposit

การเติมเงินเพิ่ม Equity และเปลี่ยนเปอร์เซ็นต์ อาจทำให้ Curve ดูฟื้นทั้งที่กลยุทธ์ยังขาดทุน แยก Trading P/L ออกจาก Cash Flow

จบ Report ขณะมี Position ใหญ่

Net Profit ที่ปิดแล้วอาจไม่รวม Floating Loss ต้องดู Equity/Open Trades และขยาย End Date

เปรียบเทียบ Equity Curve อย่างเป็นธรรม

  1. ใช้ช่วงเวลาและ Currency เดียวกัน
  2. แยก Deposit/Withdrawal
  3. Normalize เป็น Return แต่รักษาข้อมูล Absolute Risk
  4. เทียบ Exposure/Leverage
  5. ใช้ต้นทุน/Specification เดียวกัน
  6. ดู OOS/Forward แยกจาก IS
  7. แสดงทั้ง Balance และ Equity
  8. เปิด Metric/Trade List ที่สร้างเส้น

ใช้ วิธีเปรียบเทียบ Backtest กับ Forward Test เพื่อดูว่า Curve ในข้อมูลใหม่ยังมีโครงสร้างใกล้เดิมหรือไม่ และดูผลจริงของ FENIX PRO จาก หน้า Backtest โดยไม่แยกออกจากเงื่อนไขและคำเตือนความเสี่ยง

หากได้รับเพียง Screenshot ให้ขอช่วงวันที่ เงินเริ่มต้น Deposit/Withdrawal, Open Positions, Balance/Equity และ Trade History เพิ่ม ภาพที่ไม่มีแกน ไม่มีหน่วย หรือไม่มีแหล่งข้อมูลใช้ยืนยันได้เพียงว่ามีภาพหนึ่งรูป ไม่เพียงพอสำหรับประเมินระบบหรือวางเงินทุน

คำเตือนความเสี่ยง: Equity Curve เป็นข้อมูลอดีตและขึ้นกับวิธีคำนวณ/บันทึก เส้นที่สวยไม่รับประกันผลลัพธ์ในอนาคต และ Maximum Drawdown เดิมสามารถถูกทำลายได้
