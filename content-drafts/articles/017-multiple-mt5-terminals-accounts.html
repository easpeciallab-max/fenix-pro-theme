การเปิด MT5 หลาย Terminal บนเครื่องเดียวเหมาะเมื่อจำเป็นต้องใช้หลายบัญชี หลายโบรกเกอร์ หรือแยก EA ให้เป็นอิสระ เอกสาร MetaTrader ระบุว่าสอง Instance ไม่สามารถรันจาก Directory เดียวกันพร้อมกันได้ หากต้องการเปิดหลายชุดต้องติดตั้งแพลตฟอร์มในคนละ Directory

สิ่งที่ต้องแยกไม่ใช่เพียง Shortcut เพราะแต่ละ Terminal มี Data Folder, Config, Profile, Log และไฟล์ MQL5 ของตนเอง การคัดลอก EA ลงผิด Data Folder ทำให้เกิดอาการ “อีกหน้ามีไฟล์ แต่อีกหน้าไม่เห็น” และการ Login สลับบัญชีใน Terminal เดียวอาจกระทบ EA ที่เปิดอยู่ตามการตั้งค่า Disable Automated Trading

สารบัญ

  • หลายบัญชีใน Terminal เดียวหรือหลาย Terminal
  • ขั้นตอนติดตั้งหลายชุด
  • แยก Data Folder อย่างไร
  • จัด EA, Preset และ Magic
  • ประเมินทรัพยากรเครื่อง
  • ระบบดูแลและ Restart

ควรใช้รูปแบบไหน

หลายบัญชีใน Terminal เดียว

MT5 สามารถบันทึกหลายบัญชีใน Navigator และสลับ Login ได้ เหมาะกับการตรวจบัญชีทีละบัญชี แต่ Terminal จะเชื่อมต่อ Active Account ได้ครั้งละหนึ่งบัญชี EA บนกราฟจึงทำงานกับบัญชีที่ Login อยู่ ไม่เหมาะกับการรันหลายบัญชีพร้อมกัน

หลาย Terminal บนเครื่องเดียว

แต่ละ Terminal Login คนละบัญชีและรันพร้อมกันได้ เหมาะกับ EA 24/7 หรือการแยก Production/Demo แต่ต้องมี RAM, CPU, Disk และขั้นตอนดูแลมากขึ้น

หลาย VPS

แยก Failure Domain และสิทธิ์เข้าถึงได้ชัดกว่า แต่มีค่าใช้จ่ายและงานบำรุงรักษาเพิ่ม ไม่จำเป็นต้องใช้ VPS แยกทุกบัญชีหากเครื่องเดียวมีทรัพยากรและความเสี่ยงการหยุดพร้อมกันอยู่ในระดับที่ยอมรับได้

วิธีติดตั้ง MT5 หลาย Terminal

  1. ดาวน์โหลด Installer จากโบรกเกอร์หรือแหล่งทางการ
  2. เปิด Installer และเลือก Settings แทนการกด Next แบบ Default
  3. ตั้ง Installation Folder ให้ไม่ซ้ำ เช่น C:\Trading\MT5-Account-A
  4. ตั้งชื่อ Program Group/Shortcut ที่ระบุบัญชีหรือหน้าที่
  5. ติดตั้งชุดถัดไปใน Directory ใหม่ เช่น C:\Trading\MT5-Account-B
  6. เปิดแต่ละ Terminal แล้วใช้ File > Open Data Folder จด Path
  7. Login บัญชีที่ถูกต้องและตั้งชื่อ Shortcut ให้แยกได้
  8. ติดตั้ง EA/Indicator/Preset ลง Data Folder ของแต่ละชุด

หลีกเลี่ยงชื่อโฟลเดอร์ที่มีเพียงเลขลำดับโดยไม่มี Mapping ควรมีตารางว่า Terminal A ใช้ Account/Server/EA ใด แต่ไม่บันทึก Password เป็นข้อความธรรมดาในตาราง

พื้นฐานการเตรียมโปรแกรมอ่านที่ วิธีติดตั้ง MT5 และตำแหน่ง EA ที่ คู่มือติดตั้ง EA บน MT5

เข้าใจ Installation Folder กับ Data Folder

Installation Folder เก็บไฟล์โปรแกรม เช่น terminal64.exe ส่วน Data Folder เก็บข้อมูลที่แก้ไขได้ เช่น MQL5, Config, Logs, Profiles และ Bases ใน Main Mode แต่ละ Installation Path จะสัมพันธ์กับ Instance ID ของ Data Folder

วิธีไม่ให้สับสน:

  • เปิด Data Folder จากเมนูของ Terminal ที่กำลังใช้อยู่เสมอ
  • สร้างไฟล์ข้อความ terminal-map.txt ในโฟลเดอร์เอกสารกลาง ระบุ Shortcut → Installation → Data Folder
  • ตั้งสี Chart Background หรือ Profile Label แยก Demo/Real
  • Pin Shortcut ด้วยชื่อบัญชีที่ปิดบังบางส่วน เช่น MT5-A-Live-01
  • อย่าคัดลอกทั้ง Data Folder ระหว่าง Terminal โดยไม่ตรวจ Config/Account

Portable Mode ทำให้ข้อมูลอยู่ใกล้ Installation Folder แต่มีเงื่อนไข Permission และ UAC ตามเอกสาร MT5 บน RDP/Main Mode มักใช้ Data Folder ใต้ User Profile อย่าเปิด /portable เพียงเพื่อให้ Path ดูง่ายหากยังไม่เข้าใจสิทธิ์ Windows

จัด EA และ Preset ระหว่างหลาย Terminal

  • เก็บ Master Copy ของ EX5/SET แยกจากโฟลเดอร์ที่รันจริง
  • ติดตั้งไฟล์ตาม Version เดียวกันเฉพาะ Terminal ที่อนุมัติ
  • ใช้ Magic Number ไม่ซ้ำเมื่อหลาย EA อยู่ในบัญชีเดียว
  • ถ้าแยกบัญชีแล้ว Magic ซ้ำอาจไม่รบกวนข้ามบัญชี แต่ยังควรบันทึกเพื่อวิเคราะห์
  • ตั้งชื่อ SET ให้มี EA, Version, Symbol, Timeframe และ Risk Profile
  • เก็บ Screenshot ของกราฟและ Inputs ต่อ Terminal
  • ตรวจ License ว่าจำกัดจำนวน Instance/บัญชี/เครื่องหรือไม่

อ่านแนวทาง ID ของออเดอร์ได้ที่ Magic Number บน MT5 และภาพรวมการรวมความเสี่ยงที่ เปิด EA หลายตัวพร้อมกันได้ไหม

ประเมิน CPU, RAM, Disk และ Network

จำนวน Terminal สูงสุดไม่มีเลขเดียว เพราะขึ้นกับ EA, จำนวนกราฟ, Indicator, History และความถี่ของ Tick วิธีที่ถูกต้องคือวัด Resource จริงในช่วงตลาดเคลื่อนไหว ไม่ใช่ดูเฉพาะตอนสุดสัปดาห์

ทรัพยากร สิ่งที่ควรดู
CPU การใช้งานต่อเนื่องและ Spike เมื่อหลาย EA คำนวณพร้อมกัน
RAM Committed Memory, Paging และพื้นที่เผื่อ Update/Restart
Disk พื้นที่ History/Logs, IOPS และ Free Space
Network ความเสถียร Packet Loss และ Latency ไป Trade Server

เพิ่ม Terminal ทีละชุด เฝ้าดู Task Manager และ Experts/Journal หาก CPU/RAM สูงต่อเนื่องหรือ Terminal ตอบสนองช้า ให้ลดกราฟ/Indicator ที่ไม่จำเป็นหรือเพิ่มทรัพยากร ก่อนเพิ่มบัญชีใหม่ อ่านแนวทางที่ เลือก VPS สำหรับ EA

ระบบดูแลหลาย Terminal ไม่ให้พลาด

ใช้ Inventory กลาง

เก็บรายการ Terminal, Account, Server, EA Version, Preset, Magic, Shortcut และเจ้าของงาน อัปเดตเมื่อเปลี่ยนจริงทุกครั้ง

กำหนดลำดับ Start/Stop

หลัง Windows Restart ให้เปิด Terminal ตามลำดับ ตรวจ Connection และ Log ทีละชุด ไม่เปิดทั้งหมดแล้วสรุปจากไอคอนบน Taskbar

ตั้ง Alert แยก

หาก EA/ระบบ Monitoring รองรับ ให้แยกชื่อบัญชีใน Notification เพื่อรู้ว่า Error มาจาก Terminal ใด ไม่ใช้ข้อความ “MT5 disconnected” แบบไม่มี Context

สำรองและทดสอบ Restore

Backup ไฟล์ EA, Preset, Profile และ Mapping นอก VPS ทดสอบเปิด Terminal สำรองโดยไม่เชื่อมต่อบัญชีจริงอัตโนมัติ

แยก Demo และ Real ชัดเจน

ใช้ Shortcut, Wallpaper/Profile และ Folder คนละชื่อ ป้องกันโหลด Preset หรือปิด Terminal ผิดบัญชี

หลาย Terminal ช่วยแยกระบบ แต่เพิ่มจุดที่ต้องดูแล หากไม่มี Inventory และ Monitoring โครงสร้างที่แยกมากขึ้นอาจทำให้ทีมพลาดได้ง่ายกว่า Terminal เดียว

คำเตือนความเสี่ยง: การรันหลายบัญชีบนเครื่องเดียวทำให้ทุกระบบพึ่งพา Windows, Disk, Network และไฟฟ้าชุดเดียวกัน หากเครื่องล้มทุกบัญชีอาจหยุดพร้อมกัน ต้องประเมินความเสี่ยงระดับโครงสร้างและระดับพอร์ต
