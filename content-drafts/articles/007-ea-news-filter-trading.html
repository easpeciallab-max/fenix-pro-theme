ช่วงประกาศตัวเลขเศรษฐกิจสำคัญ ราคาอาจเคลื่อนเร็ว Spread ถ่าง และคำสั่งถูกดำเนินการต่างจากราคาที่คาดไว้ EA บางระบบจึงมี News Filter เพื่อหยุดเปิดออเดอร์ใหม่ก่อนและหลังเวลาข่าวตามเงื่อนไขที่กำหนด แต่ Filter ไม่ได้หยุดตลาด ไม่รับประกันว่าจะไม่มี Slippage และอาจไม่จัดการสถานะเดิมหากผู้พัฒนาไม่ได้เขียนกฎไว้

การใช้ News Filter อย่างถูกต้องต้องตอบให้ได้ว่าใช้แหล่งข่าวใด อ้างอิงเขตเวลาไหน เลือกระดับความสำคัญอย่างไร และเมื่อมีออเดอร์เปิดอยู่ระบบจะทำอะไร บทความนี้แยก “สิ่งที่ Filter ช่วยได้” ออกจาก “ความเสี่ยงที่ยังคงอยู่” เพื่อป้องกันความเข้าใจผิด

สารบัญ

  • ตลาดอาจเกิดอะไรช่วงข่าว
  • News Filter ทำงานอย่างไร
  • เวลา Local, Server และ Calendar
  • สิ่งที่ Filter ป้องกันไม่ได้
  • วิธีทดสอบและตรวจ Log
  • เช็กลิสต์การตั้งค่า

ตลาดอาจเกิดอะไรขึ้นในช่วงข่าว

ข่าวไม่ได้ทำให้ราคาเคลื่อนแรงทุกครั้ง แต่เหตุการณ์ที่ตลาดให้ความสำคัญอาจสร้างเงื่อนไขต่อไปนี้พร้อมกัน

  • Spread ขยาย เพราะราคา Bid และ Ask ห่างกันมากขึ้น
  • Slippage เพิ่ม ราคาเปลี่ยนระหว่างส่งคำสั่งและประมวลผล
  • Liquidity บาง ปริมาณที่ราคาหนึ่งอาจไม่เพียงพอสำหรับคำสั่งทั้งหมด
  • Gap หรือ Price Jump ราคาเคลื่อนข้ามระดับโดยไม่มี Tick ที่ราคากลาง
  • ความหน่วงและ Retcode Server อาจใช้เวลาประมวลผลนานขึ้นหรือปฏิเสธคำสั่งบางประเภท

ผลต่อ EA ขึ้นอยู่กับกลยุทธ์ Scalping อาจเสียเปรียบจากต้นทุนที่สูงขึ้น ส่วน Grid หรือ Martingale อาจสะสมสถานะเร็วเมื่อราคาเคลื่อนทางเดียว อ่านภาพรวมประเภทระบบได้ที่ EA มีกี่ประเภท

News Filter ใน EA ทำงานอย่างไร

News Filter มักอ่านปฏิทินเศรษฐกิจหรือรายการเหตุการณ์ แล้วเปรียบเทียบกับเวลาปัจจุบัน หากอยู่ในหน้าต่างที่กำหนด เช่น ก่อนข่าวและหลังข่าว ระบบจะเปลี่ยนสถานะเป็นงดเทรด การออกแบบอาจต่างกัน เช่น

  • กรองเฉพาะข่าวระดับ High Impact
  • กรองตามสกุลเงินที่เกี่ยวข้องกับ Symbol
  • หยุดเปิดออเดอร์ใหม่ แต่ยังบริหาร Stop Loss และ Take Profit ของสถานะเดิม
  • ปิด Pending Order ก่อนข่าวและวางใหม่ภายหลัง
  • หยุดทั้งระบบเมื่อข้อมูล Calendar ใช้งานไม่ได้ เพื่อไม่ให้เทรดโดยไม่รู้สถานะ

MetaTrader 5 มี Economic Calendar ที่รวบรวมเหตุการณ์และปรับเวลาตามระบบของแพลตฟอร์ม แต่ EA แต่ละตัวอาจใช้แหล่งข้อมูลอื่น จึงต้องอ่านคู่มือของระบบ ไม่ควรสมมติว่า News Filter ทุกตัวใช้ข้อมูลเดียวกัน

เวลา Local, Broker Server และ Calendar ต้องตรงกัน

ความผิดพลาดที่พบบ่อยคือกำหนดเวลาข่าวถูก แต่ EA เทียบกับ Timezone คนละชุด MT5 แสดงเวลา Quote ตาม Trade Server ของโบรกเกอร์ ขณะที่ปฏิทินหรือเว็บไซต์ข่าวอาจแสดงตาม Local Time ของเครื่องหรือเขตเวลาที่เลือก

ก่อนใช้งานควรตรวจ 4 ค่า:

  1. เวลาบน Market Watch ของ MT5
  2. เวลาระบบของ Windows หรือ VPS
  3. Timezone ของแหล่งปฏิทินข่าว
  4. เวลาที่ EA แสดงใน Log หรือ Dashboard

หาก Broker เปลี่ยนเวลาเมื่อเข้าสู่หรือออกจาก Daylight Saving Time ค่า Offset อาจเปลี่ยนตามฤดูกาล ระบบที่ใช้ Offset แบบตายตัวจึงต้องมีขั้นตอนตรวจ Server Time ซ้ำ และไม่ควรสมมติว่าเวลาบน MT5 เท่ากับเวลาประเทศไทยตลอดปี

News Filter ป้องกันอะไรไม่ได้บ้าง

ไม่ลบความเสี่ยงของออเดอร์ที่เปิดอยู่

หาก Filter มีหน้าที่เพียงงดเปิดใหม่ สถานะเดิมยังเผชิญ Gap, Slippage และ Spread ถ่าง Stop Loss เป็นคำสั่งให้ปิดเมื่อถึงเงื่อนไข แต่ราคาที่ได้รับจริงอาจต่างจากระดับที่ตั้งไว้

ไม่รู้เหตุการณ์ที่ไม่มีในปฏิทิน

ข่าวฉุกเฉิน ความเสี่ยงทางภูมิรัฐศาสตร์ หรือถ้อยแถลงที่ไม่ได้กำหนดเวลาล่วงหน้าอาจทำให้ตลาดเคลื่อนแรงโดย Filter ไม่ได้รับสัญญาณ

ไม่รับประกันว่าข้อมูลจะโหลดสำเร็จ

หากอินเทอร์เน็ต ข้อมูล Calendar หรือสิทธิ WebRequest มีปัญหา EA ต้องมีกฎเมื่อข้อมูลหาย ระบบที่เลือก “เทรดต่อ” และระบบที่เลือก “หยุดเทรด” มีผลต่อความเสี่ยงต่างกัน

ไม่ทำให้ Backtest ตรงกับ Live

การจำลองข่าวย้อนหลังต้องมีข้อมูลเหตุการณ์และการตอบสนองของ Spread/Tick ที่เหมาะสม การข้ามช่วงข่าวออกจาก Backtest อาจทำให้ผลดูดี แต่ไม่สะท้อนว่าระบบจะทำอย่างไรเมื่อมีสถานะค้างจริง

วิธีทดสอบ News Filter และตรวจ Log

  1. เลือกเหตุการณ์ที่รู้เวลาแน่นอนและตรวจว่า EA แสดงชื่อกับเวลาตรงกัน
  2. ตั้งหน้าต่างก่อนและหลังข่าวใน Demo แล้วดูว่าเปิดออเดอร์ใหม่หรือไม่
  3. ตรวจ Pending Order ว่าถูกยกเลิก คงไว้ หรือเลื่อนตามกฎ
  4. เปิดสถานะทดสอบขนาดต่ำและดูว่า Stop/Trailing ยังทำงานเมื่อ Filter Active
  5. ตัดอินเทอร์เน็ตหรือปิดแหล่งข้อมูลในสภาพแวดล้อมทดสอบ เพื่อดู Fail-safe ของระบบ
  6. ตรวจแท็บ Experts และ Journal หาข้อความ Calendar, Time Offset และ Error Code
  7. เปรียบเทียบเวลาใน Log กับ Market Watch และเวลาข่าวจริง

หาก EA ไม่ทำงานตามคาด ให้ตรวจขั้นตอนใน EA ไม่ทำงานบน MT5 แก้อย่างไร และอย่าแก้ด้วยการเปิดสิทธิทุกอย่างโดยไม่รู้สาเหตุ

เช็กลิสต์ก่อนเปิด News Filter

  • แหล่งข้อมูลข่าวคืออะไรและต้องใช้อินเทอร์เน็ตหรือ WebRequest หรือไม่
  • กรองข่าวระดับใดและสกุลเงินใด
  • หยุดก่อนข่าวและกลับมาเทรดหลังข่าวกี่นาที
  • เวลาที่ใช้เป็น Local, GMT หรือ Broker Server Time
  • ระบบทำอะไรกับออเดอร์และ Pending Order ที่มีอยู่
  • หากข้อมูลข่าวโหลดไม่ได้ ระบบหยุดหรือเทรดต่อ
  • มีข้อความยืนยันสถานะ Filter ใน Dashboard หรือ Log หรือไม่
  • การตั้งค่ายังคงอยู่หลัง Restart MT5 หรือ VPS หรือไม่

News Filter เป็นส่วนเสริมของการควบคุมความเสี่ยง ไม่ใช่ตัวแทนของการกำหนด Lot, Stop Loss, Exposure และขีดจำกัดขาดทุนรวม ควรใช้ร่วมกับแนวทางใน Money Management สำหรับ EA

คำเตือนความเสี่ยง: การงดเทรดรอบข่าวไม่สามารถกำจัด Gap, Slippage, Spread ถ่าง หรือเหตุการณ์ที่ไม่มีกำหนดล่วงหน้าได้ EA และ News Filter ไม่สามารถรับประกันผลกำไร ผู้ใช้ควรตรวจการตั้งค่าและจำกัดความเสี่ยงให้เหมาะกับทุน
