MetaTrader 5 รองรับการเปิดหลายสำเนาพร้อมกันเมื่อ ติดตั้งแต่ละ Terminal ในคนละ Directory การทำบน VPS ช่วยจัดหลายบัญชีหรือหลายชุด EA แต่เพิ่มความเสี่ยงด้านทรัพยากร ไฟล์ซ้ำ Magic Number และการเปิด Process ซ้อน จึงต้องตั้งมาตรฐานชื่อและ Inventory ตั้งแต่ต้น

แนวทางนี้เหมาะเมื่อมีเหตุผลต้องแยกบัญชีหรือ Environment จริง ไม่ควรเพิ่ม Terminal เพื่อแก้ปัญหาการจัดการที่ยังไม่ชัด และไม่ควรรัน Backtest หนักใน VPS Production เดียวกันโดยไม่มี Resource Limit

สารบัญ

  • วางแผนก่อนติดตั้ง
  • ขั้นตอนติดตั้งแยก Directory
  • Main Mode กับ Portable Mode
  • ตั้งชื่อและแยกออเดอร์
  • คุมทรัพยากร VPS
  • ตรวจหลัง Restart

สร้าง Terminal Inventory

ก่อนดาวน์โหลด ให้ทำตารางหนึ่งแถวต่อ Terminal:

ข้อมูล ตัวอย่างรูปแบบ
Terminal ID T01, T02, T03
Broker/Server ชื่อ Server ตามหน้าล็อกอิน
Account Role Demo, Small Live, Production
Install Path C:\Trading\MT5-T01\
EA/Version ชื่อไฟล์ Version และ Checksum
Magic Range ช่วงเลขที่ไม่ชน Terminal/Strategy อื่น

ห้ามบันทึกรหัสผ่านลง Spreadsheet ที่ไม่มีการป้องกัน Inventory ควรเก็บเฉพาะข้อมูลปฏิบัติการและอ้างอิง Password Manager/Secret Process ของทีม

ติดตั้งทีละชุดให้แยกกัน

  1. ดาวน์โหลด Installer จาก Broker หรือ MetaTrader ที่เชื่อถือได้
  2. เปิด Settings ใน Installer และกำหนด Installation Folder เฉพาะ เช่น MT5-T01
  3. ตั้ง Program Group/Shortcut ให้มี Terminal ID
  4. ติดตั้งและเปิดครั้งแรก จากนั้นยืนยัน Help/About และ Data Folder
  5. ปิด Terminal ก่อนติดตั้งชุดถัดไปเพื่อลดความสับสน
  6. ทำซ้ำโดยใช้ Directory ใหม่ทุกครั้ง
  7. เปิด Task Manager ตรวจว่าแต่ละ Process มาจาก Path ที่ตั้งใจ

เอกสาร MetaTrader ระบุว่าหากต้องการรันหลายสำเนาพร้อมกัน ให้ติดตั้งจำนวนที่ต้องการใน Directory ต่างกัน การ Copy Shortcut อย่างเดียวโดยชี้ executable เดิมไม่ได้สร้าง Installation แยก

Main Mode กับ Portable Mode

ใน Main Mode โปรแกรมมักเก็บข้อมูลผู้ใช้ใน Windows User Data Directory แยกจากโฟลเดอร์ติดตั้ง ส่วน Portable Mode ใช้พารามิเตอร์ /portable เพื่อเก็บข้อมูลใน Installation Folder แต่ต้องมีสิทธิ์เขียนที่เหมาะสม

หลักเลือก:

  • Main Mode: สอดคล้องกับการใช้งาน Windows ปกติและ UAC แต่ต้องตรวจ Data Folder ของแต่ละ Instance
  • Portable Mode: โครงสร้างสำรอง/ย้ายง่ายขึ้นเมื่อ Folder แยกชัด แต่ต้องจัด Permission และ Shortcut Argument ถูกต้อง

อย่าสลับ Mode หลังใช้งานโดยไม่วางแผน เพราะ EA, Preset, Profile และ History อาจอยู่คนละ Data Path ให้เปิด File > Open Data Folder จาก Terminal แต่ละตัวและบันทึก Path จริงใน Inventory

ป้องกันออเดอร์และไฟล์ชนกัน

Magic Number

กำหนด Magic Number/Range ไม่ซ้ำตาม Strategy แม้อยู่คนละ Terminal หากเชื่อมบัญชีเดียวกัน ทุก Terminal เห็น Position ของบัญชีนั้นและอาจจัดการออเดอร์กันผิดหาก Filter ไม่รัดกุม

Account Duplication

ห้ามเปิด EA ชุดเดียวกันบนบัญชีเดียวกันสอง Terminal โดยไม่ตั้งใจ เพราะ Signal เดียวอาจส่งคำสั่งซ้ำ ตรวจ Login, Server, Chart, EA Name และ Magic ทุกครั้งหลัง Restart

Preset และ Version

ใช้ชื่อไฟล์ที่มี Strategy, Symbol, Timeframe, Risk Profile และ Version หลีกเลี่ยงชื่อ final.set หรือ new2.set ตรวจ Checksum ของ EA ก่อนกระจายไปหลาย Terminal

รายละเอียดการดูแลหลาย EA อ่านที่ วิธีรัน EA หลายตัวบน MT5 และโครงสร้างไฟล์ที่ Data Folder, EX5 และ MQ5

คุม CPU, RAM, Disk และ Network

ทุก Terminal มี Process และ Cache ของตนเอง การเพิ่ม Instance จึงเพิ่ม RAM/Disk/Connection แม้เปิดกราฟน้อย ใช้ วิธีเลือกสเปก VPS และตั้ง Resource Budget ต่อ Terminal:

  • จำนวน Chart/EA สูงสุด
  • จำนวน Symbol ใน Market Watch
  • ช่วงเวลาที่อนุญาตให้ Update/Backtest
  • พื้นที่ Log/History และ Retention
  • CPU/RAM Headroom ระดับ Warning/Critical

เปิด Terminal เพิ่มทีละหนึ่งแล้ววัด Peak อย่าติดตั้งครบทั้งหมดก่อนดูทรัพยากร หาก CPU ตันเฉพาะ Tick Burst การดู Average รายชั่วโมงอาจไม่เห็น ต้องเก็บ Sample ที่ถี่และตรวจ Journal ว่ามี Queue/Delay หรือไม่

Auto-start และการตรวจหลัง Restart

Shortcut แต่ละตัวต้องชี้ executable/argument ของ Terminal นั้น ใช้ Startup หรือ Task Scheduler ตามนโยบาย Windows และกำหนด Delay เพื่อไม่ให้ทุก Terminal เปิดพร้อมกันจน CPU/Disk พุ่ง

Checklist หลัง Restart:

  1. จำนวน Process ตรงกับ Inventory ไม่มีซ้ำ/ขาด
  2. แต่ละ Terminal Login ถูก Account และ Server
  3. Connection เป็นปกติและเวลา Tick อัปเดต
  4. AutoTrading/Allow Algo Trading อยู่ตามนโยบาย
  5. Chart, EA, Preset, Magic และ Version ถูกต้อง
  6. ไม่มี Error ใน Expert/Journal
  7. Portfolio Exposure ไม่ซ้ำจาก Instance ที่เปิดเกิน

หาก Auto-start เปิด EA ส่งคำสั่งทันทีหลัง Boot ควรมี Startup Guard รอ Connection, Sync Time/History และตรวจ State ก่อนอนุญาต Entry พร้อมบันทึก Runbook การเปิด Terminal และลำดับตรวจสอบไว้ให้ทีมใช้เหมือนกัน

การสำรองและกู้คืน

สำรอง Inventory, Install Package, EA, Preset, Profile และเอกสาร Version แยกจาก VPS ทดสอบ Restore ลงเครื่องใหม่เป็นรอบ ไม่ถือ Snapshot ที่ไม่เคยกู้เป็น Backup ที่เชื่อถือได้ และไม่คัดลอก Folder ขณะไฟล์กำลังถูกเขียนโดยไม่มีวิธี Consistent Snapshot

สรุป: การรัน MT5 หลาย Terminal ทำได้โดยติดตั้งคนละ Directory และจัด Data/Identity ให้ชัด ความสำเร็จไม่ได้อยู่ที่เปิดได้กี่หน้าต่าง แต่อยู่ที่ไม่มี Process ซ้ำ ออเดอร์ไม่ชน ทรัพยากรมี Headroom และกู้คืนได้ตาม Inventory

คำเตือนความเสี่ยง: การใช้หลาย Terminal หรือหลาย EA อาจเพิ่ม Exposure และความผิดพลาดจากการตั้งค่าซ้ำ VPS/ระบบปฏิบัติการอาจขัดข้องได้ โปรดทดสอบในสภาพแวดล้อมที่ไม่ใช่เงินจริงและมีแผนสำรองก่อนใช้งาน Production อ่าน คำเตือนความเสี่ยงฉบับเต็ม
