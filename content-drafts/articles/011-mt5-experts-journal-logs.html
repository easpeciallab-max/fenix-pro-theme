เมื่อ EA ไม่เปิดออเดอร์ หยุดทำงาน หรือแสดงอาการผิดปกติ จุดเริ่มต้นที่มีประโยชน์ที่สุดไม่ใช่การติดตั้งใหม่ทันที แต่คือแท็บ Experts และ Journal ใน Toolbox ของ MT5 เพราะสองแท็บนี้บันทึกเหตุการณ์คนละระดับและช่วยบอกว่าปัญหาเกิดจากตัว EA, การตั้งค่า, บัญชี, เครือข่าย หรือแพลตฟอร์ม

การอ่าน Log อย่างเป็นระบบช่วยลดการลองผิดลองถูก ก่อนติดต่อ Support ควรจดเวลาที่เกิดอาการ ชื่อ EA, Symbol, Timeframe, Version และคัดลอกข้อความที่เกี่ยวข้องจากทั้งสองแท็บ โดยปิดข้อมูล Login หรือข้อมูลส่วนตัวก่อนส่ง

สารบัญ

  • Experts กับ Journal ต่างกันอย่างไร
  • อ่าน Time, Source และ Message
  • ขั้นตอนวิเคราะห์ปัญหา
  • กลุ่มข้อความที่พบบ่อย
  • เปิดไฟล์ Log ย้อนหลัง
  • ข้อมูลที่ควรส่งให้ Support

แท็บ Experts กับ Journal ต่างกันอย่างไร

Experts: เหตุการณ์จาก EA และ Indicator

Experts Journal แสดงข้อความจาก Expert Advisor และ Indicator ที่กำลังทำงาน เช่น การเริ่มต้น/หยุดโปรแกรม ค่าแจ้งเตือน การพยายามเปิดหรือแก้ไข Position และข้อความที่ผู้พัฒนาเขียนด้วยฟังก์ชัน Print หรือ Alert หาก EA ตรวจพบ License ไม่ถูกต้อง Symbol ไม่รองรับ หรือค่าพารามิเตอร์ไม่สมเหตุผล ข้อความมักปรากฏที่นี่

Journal: เหตุการณ์ระดับแพลตฟอร์ม

Journal แสดงเหตุการณ์ของ MT5 โดยรวม เช่นการเปิดโปรแกรม การเชื่อมต่อ Trade Server การ Login การโหลด History การส่งคำสั่ง และเหตุการณ์ Network หาก EA ส่งคำสั่งแล้ว Server ปฏิเสธหรือ Terminal ขาดการเชื่อมต่อ Journal จะช่วยยืนยันบริบทที่ Experts อย่างเดียวอาจไม่ครบ

อาการ ควรดูที่ใดก่อน
EA ไม่ขึ้นชื่อบนกราฟ Experts และตำแหน่งไฟล์ใน Navigator
มุมกราฟแสดง EA แต่ไม่เปิดออเดอร์ Experts แล้วเทียบ Journal ในเวลาเดียวกัน
MT5 ขึ้น No Connection Journal และสถานะมุมขวาล่าง
คำสั่งถูกปฏิเสธ ทั้ง Experts และ Journal พร้อมรหัส/ข้อความตอบกลับ
EA หยุดหลังเปลี่ยนบัญชีหรือ Profile Journal, Experts และ Options > Expert Advisors

อ่าน Time, Source และ Message ให้เป็น

Log ใน MT5 มีคอลัมน์หลักสามส่วน:

  • Time เวลาที่เกิดเหตุการณ์ ใช้จับคู่ข้อความจาก Experts และ Journal
  • Source แหล่งที่มาของข้อความ เช่น Network, HistoryBase, Experts หรือชื่อ EA
  • Message รายละเอียดเหตุการณ์ ควรอ่านทั้งบรรทัด ไม่ตัดเฉพาะคำว่า Error

เวลาใน Log ของแพลตฟอร์มอ้างอิงเขตเวลาของคอมพิวเตอร์ตามเอกสาร MetaTrader ขณะที่เวลาแท่งราคาและฟังก์ชันบางอย่างใน EA อาจอิง Trade Server จึงควรบอก Timezone ของ VPS/Windows เมื่อส่งข้อมูลให้ผู้พัฒนา

ไอคอนใน Journal แยก Informational, Warning และ Error แต่ข้อความ Informational ก็มีประโยชน์ เช่นบอกว่า EA ถูกถอดออกเพราะเปลี่ยน Chart หรือแพลตฟอร์มเชื่อมต่อ Server ใหม่ ไม่ควรกรองเฉพาะ Error ตั้งแต่ต้น

วิธีวิเคราะห์เมื่อ EA ไม่ทำงานทีละขั้น

  1. หยุดเปลี่ยนหลายอย่างพร้อมกัน: บันทึกสภาพเดิมก่อน ไม่สลับ Preset, Symbol และบัญชีในรอบเดียว
  2. จดเวลาที่แน่นอน: ระบุวันที่และเวลาที่เห็นอาการ เพื่อค้นหา Log ช่วงสั้น ๆ
  3. ตรวจสถานะพื้นฐาน: ดู Connection, Login, ปุ่ม Algo Trading และไอคอน/ชื่อ EA บนกราฟ
  4. เปิด Toolbox: กด Ctrl+T แล้วเลือก Experts และ Journal
  5. หา Source ที่เกี่ยวข้อง: ดูชื่อ EA และข้อความก่อน/หลังเวลาที่เกิดอาการ
  6. จับคู่สองแท็บ: หาก Experts บอกว่าส่งคำสั่ง ให้ดู Journal ว่า Server ตอบกลับอย่างไร
  7. คัดลอกข้อความเต็ม: คลิกขวา Copy หรือเปิดไฟล์ Log ย้อนหลัง
  8. แก้ทีละสาเหตุ: เปลี่ยนหนึ่งจุดแล้วทำซ้ำเพื่อยืนยันผล

หากยังไม่ได้ติดตั้งหรืออนุญาต EA ครบ ให้ย้อนตรวจ ขั้นตอนติดตั้ง EA บน MT5 และ วิธีเปิด Algo Trading ก่อน

กลุ่มข้อความที่พบบ่อยและวิธีคิด

Automated/Algo Trading ถูกปิด

ตรวจทั้งปุ่ม Algo Trading ระดับ Terminal และสิทธิ์ “Allow Algo Trading” ใน Properties ของ EA นอกจากนี้ MT5 มีตัวเลือกให้ปิด Automated Trading อัตโนมัติเมื่อเปลี่ยนบัญชี Profile, Symbol หรือ Timeframe ขึ้นกับการตั้งค่า

ไม่มีการเชื่อมต่อหรือ Login ผิด

ถ้า Journal แสดงการ Disconnect, Authorization Failed หรือ Invalid Account ให้ตรวจ Login, Password และชื่อ Server จากข้อมูลของโบรกเกอร์ ไม่ใช้รหัสผ่านหน้าเว็บไซต์แทน Trading Password และไม่เดา Server จากชื่อใกล้เคียง

คำสั่งซื้อขายถูกปฏิเสธ

อ่านข้อความและรหัสตอบกลับเต็ม สาเหตุอาจเป็น Market Closed, Trade Disabled, Volume ไม่ถูกต้อง, Margin ไม่พอ, Stop Level ไม่ผ่าน หรือราคาที่ส่งใช้ไม่ได้ ข้อความจริงขึ้นกับ Server และขั้นตอนของ EA จึงไม่ควรแก้ด้วยการเพิ่ม Lot หรือเอา Stop Loss ออกโดยไม่เข้าใจ

EA เริ่มทำงานแต่ไม่พบสัญญาณ

การไม่มีออเดอร์อาจเป็นพฤติกรรมปกติหากเงื่อนไขกลยุทธ์ยังไม่ครบ ตรวจ Session, Spread Filter, News Filter, วันเทรด, Symbol และ Timeframe จากคู่มือ หาก Experts ระบุว่า “waiting” หรือ “filter blocked” ต้องตีความตามเอกสารของ EA นั้น

ไฟล์หรือ Resource ไม่พบ

ข้อความ File not found, Cannot load indicator หรือ Library load failed มักชี้ว่าโครงไฟล์ไม่ครบหรือ Permission ไม่ตรง ตรวจ Data Folder ของ Terminal นั้นและหลีกเลี่ยงการคัดลอกทุกไฟล์ไว้โฟลเดอร์เดียว อ่านเพิ่มเรื่อง ไฟล์ EX5 และโครงสร้าง MQL5 หลังบทความดังกล่าวเผยแพร่

เปิดไฟล์ Log ย้อนหลังอย่างไร

แท็บบนหน้าจอเน้นรายการล่าสุด แต่ MT5 เก็บไฟล์ Log รายวัน เมนูคลิกขวาใน Experts หรือ Journal มีคำสั่ง Open สำหรับเปิดโฟลเดอร์ Log และบันทึกรายการปัจจุบันลงไฟล์

  • Platform Log อยู่ในโฟลเดอร์ Logs ของ Data Folder
  • Expert Log อยู่ใน MQL5\Logs
  • ชื่อไฟล์เป็นวันที่รูปแบบ YYYYMMDD.log
  • Strategy Tester มี Log แยกในโครง Tester/Agent

ใช้ Log Viewer เพื่อค้นหาคำตามช่วงเวลา หรือเปิดด้วยโปรแกรมที่รองรับ Unicode อย่าแก้ไฟล์ต้นฉบับก่อนสำรอง เพราะลำดับเหตุการณ์มีประโยชน์ต่อการวิเคราะห์

ข้อมูลที่ควรส่งให้ทีม Support

  • ชื่อและ Version ของ EA
  • MT5 Build และระบบปฏิบัติการ
  • ประเภทบัญชี Demo/Real และชื่อ Server โดยไม่ส่ง Password
  • Symbol, Timeframe และชื่อ Preset
  • เวลาที่เกิดปัญหาพร้อม Timezone ของเครื่อง
  • Screenshot กราฟที่เห็นชื่อ EA และสถานะ Algo Trading
  • ข้อความ Experts/Journal ก่อนและหลังอาการ
  • สิ่งที่เปลี่ยนล่าสุด เช่น Update, Restart, เปลี่ยนบัญชี หรือโหลด Preset

ปิดบัง Login, ชื่อจริง, Email, IP, License Key และข้อมูล Credential ก่อนส่ง Log ในช่องสาธารณะ หาก Support ต้องการไฟล์เต็มให้ส่งผ่านช่องทางที่ยืนยันตัวตนได้

การอ่าน Log เป็นทักษะพื้นฐานของผู้ใช้ระบบอัตโนมัติ เพราะช่วยแยก “EA ไม่ทำงาน” ออกจาก “EA ทำงานปกติแต่ยังไม่มีสัญญาณ” และป้องกันการแก้ค่าความเสี่ยงโดยไม่เกี่ยวกับสาเหตุจริง ดูรายการตรวจเพิ่มเติมที่ EA ไม่ทำงานบน MT5 ต้องเช็กอะไร

คำเตือนความเสี่ยง: หากระบบแสดง Error เกี่ยวกับคำสั่งซื้อขาย อย่าแก้ด้วยการเพิ่ม Lot, ลด Stop Loss หรือปิดระบบป้องกันโดยไม่มีข้อมูลรองรับ ควรหยุดการส่งคำสั่งใหม่จนกว่าจะระบุสาเหตุได้
