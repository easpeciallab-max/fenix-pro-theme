MT5 ขึ้น No Connection หมายถึงแพลตฟอร์มยังเชื่อมต่อ Trade Server ไม่สำเร็จ ส่วน Invalid Account มักเกี่ยวกับข้อมูลบัญชีหรือบัญชีบน Server นั้นไม่สามารถใช้ได้ การแก้จึงต้องแยกอาการก่อน ไม่ควรเริ่มจากลบโปรแกรมหรือติดตั้ง EA ใหม่ เพราะ EA ไม่ใช่ตัวกำหนดสิทธิ์ Login ของบัญชี

ก่อนแก้ ให้เปิดแท็บ Journal และบันทึกข้อความล่าสุด ชื่อ Server ที่เลือก และเวลาที่เกิดปัญหา โดยไม่ส่ง Password ให้ใคร จากนั้นตรวจจากเครือข่ายไปหาบัญชีตามลำดับด้านล่าง

สารบัญ

  • แต่ละสถานะหมายถึงอะไร
  • ตรวจ No Connection
  • ตรวจ Invalid Account
  • เลือก Server ให้ถูกต้อง
  • ใช้ Journal หาสาเหตุ
  • สิ่งที่ไม่ควรทำ

แยก No Connection, Invalid Account และ Investor Login

อาการ ความหมายที่ควรตรวจ
No Connection Terminal ติดต่อ Server ไม่สำเร็จ อาจมาจาก Internet, DNS, Firewall, Server หรือเลือก Server ผิด
Invalid Account Login/Password/Server ไม่ตรง บัญชีหมดอายุ ถูกปิด หรือไม่มีบัญชีนี้บน Server ที่เลือก
Authorization Failed ข้อมูลยืนยันตัวตนไม่ผ่าน ต้องอ่านรายละเอียดใน Journal
เชื่อมต่อได้แต่เทรดไม่ได้ อาจ Login ด้วย Investor Password, ตลาดปิด, Trade Disabled หรือสิทธิ์บัญชีมีข้อจำกัด

Investor Password อนุญาตให้ดูบัญชีและวิเคราะห์ข้อมูล แต่ไม่มีสิทธิ์ส่งคำสั่งซื้อขาย หากเชื่อมต่อได้แต่ EA ส่งคำสั่งไม่ได้ ให้ยืนยันว่ากำลังใช้ Master/Trading Password โดยไม่ต้องส่งรหัสดังกล่าวให้ทีม Support

วิธีตรวจ MT5 No Connection

  1. ตรวจ Internet ของเครื่อง: เปิดเว็บไซต์อื่นและดูว่า Windows/VPS มี Network หรือไม่
  2. ดูสถานะมุมขวาล่าง: คลิกเพื่อเปิดรายการ Server/Rescan หากมี แต่ไม่สลับ Server สุ่ม
  3. เปิด Journal: หา Disconnect, Network Failed, Proxy หรือ Timeout ในเวลาปัจจุบัน
  4. ตรวจ Firewall/Antivirus: ดูว่า terminal64.exe ถูกบล็อกหรือไม่ ไม่ปิดระบบป้องกันแบบถาวร
  5. ตรวจ Proxy/VPN: หากองค์กรหรือ VPS ใช้ Proxy ให้ตรวจ Options ส่วน Server; VPN บางตัวอาจเปลี่ยนเส้นทางหรือบล็อก Port
  6. ตรวจเวลา Windows: เวลา/วันที่ผิดมากอาจกระทบการเชื่อมต่อที่ใช้ Certificate
  7. เช็กประกาศโบรกเกอร์: Server อาจ Maintenance หรือมีการเปลี่ยนชื่อ
  8. ทดลองเครือข่ายอื่น: ใช้เพื่อแยกปัญหา ISP/Router โดยไม่เปลี่ยนบัญชีพร้อมกัน

ถ้า MT5 ชุดอื่นบนเครื่องเดียวเชื่อมต่อได้ แต่ชุดนี้ไม่ได้ ให้เปรียบเทียบ Server, Proxy, Build และไฟล์ Config หากทุกชุดหลุดพร้อมกัน ปัญหามีแนวโน้มอยู่ที่ Network, Windows หรือฝั่ง Server มากกว่า EA

วิธีตรวจ Invalid Account

  1. คัดลอก Login Number จากอีเมล/Portal ของโบรกเกอร์ ไม่พิมพ์จากความจำ
  2. ใช้ Trading Password ไม่ใช่รหัสเว็บไซต์ ไม่ใช่ MQL5.community Password และไม่ใช่ Investor Password
  3. เลือกชื่อ Server ให้ตรงทุกตัวอักษร เช่น Real, Live, Demo และหมายเลข Server
  4. ตรวจว่าบัญชีเป็น MT5 ไม่ใช่บัญชี MT4
  5. ตรวจสถานะบัญชีใน Client Portal ว่ายัง Active
  6. สำหรับ Demo ตรวจวันหมดอายุหรือการลบบัญชีที่ไม่มีการใช้งาน
  7. หากเพิ่งเปลี่ยน Password ให้ใช้รหัสใหม่และลบ Credential เก่าที่ Save ไว้
  8. หากยังไม่ได้ ติดต่อ Support ของโบรกเกอร์พร้อม Login Number และ Server แต่ไม่ส่ง Password

เอกสาร MT5 ระบุว่าบัญชี Demo ที่หมดอายุอาจถูก Server ตอบกลับเป็น Invalid Account และแพลตฟอร์มบางกรณีสามารถสร้าง Demo ใหม่แทนได้ แต่บัญชีใหม่ไม่ใช่บัญชีเดิมและไม่มีประวัติ/การตั้งค่าที่เหมือนกัน จึงต้องตรวจให้ชัดก่อนใช้งาน EA ต่อ

ทำไมชื่อ Server ต้องตรง

Login Number ไม่ได้มีความหมายแบบสากล แต่ผูกกับ Trade Server ของโบรกเกอร์ บัญชีหมายเลขเดียวกันอาจไม่มีอยู่บน Server อื่น การเลือกชื่อโบรกเกอร์ถูกแต่ Server ผิดยังทำให้ Login ล้มเหลวได้

ในหน้าต่าง File > Login to Trade Account ต้องมีสามข้อมูล:

  • Login: หมายเลขบัญชีเทรด
  • Password: Master/Trading Password
  • Server: ชื่อ Server หรือ Address ที่โบรกเกอร์กำหนด

สำหรับบัญชี ZAURIX ใช้คู่มือเฉพาะที่ วิธีติดตั้งและ Login เข้า ZAURIX Server และอย่าใช้ข้อมูลจาก Screenshot ของบุคคลอื่นแทนข้อมูลบัญชีของตนเอง

ใช้ Journal แทนการเดา

เปิด Toolbox ด้วย Ctrl+T แล้วดู Journal ตามเวลาที่กด Login คัดลอกข้อความตั้งแต่เริ่ม Connecting จนถึงบรรทัดสรุป หากข้อความเร็วเกินไป ให้คลิกขวาเปิด Log Viewer หรือไฟล์รายวัน

ตัวอย่างแนวคิดในการอ่าน:

  • ไม่มีข้อความ Connecting เลย: ตรวจว่ากด Login ถูก Terminal และ Network Service ทำงานหรือไม่
  • Connecting แล้ว Timeout: ตรวจเครือข่าย, Server, Firewall และสถานะผู้ให้บริการ
  • Authorization Failed/Invalid Account: กลับไปตรวจ Credential และ Server
  • Connected แล้วหลุดซ้ำ: ตรวจคุณภาพ Network, VPS และ Log รอบเวลาเดียวกัน
  • Connected แต่ Trade Request ถูกปฏิเสธ: แยกไปตรวจ Permission, Market และ Account ไม่ใช่ Login

รายละเอียดการเก็บหลักฐานอ่านต่อที่ วิธีอ่าน Experts และ Journal บน MT5

หลังเชื่อมต่อได้แล้วต้องตรวจ EA อีกครั้ง

การเชื่อมต่อกลับมาไม่ได้หมายความว่า EA เริ่มทำงานครบ ตรวจสิ่งต่อไปนี้:

  • บัญชีและ Server ถูกตัว ไม่ได้เผลอเข้า Demo อื่น
  • Symbol ในกราฟมีราคาอัปเดต
  • Algo Trading เปิด และ EA มี Permission
  • ชื่อ EA/Version/Preset ตรงกับก่อนหลุด
  • EA เห็น Position เดิมและ Magic Number ถูกต้อง
  • Experts/Journal ไม่มี Error หลัง Reconnect

หาก Terminal Restart ระหว่างมี Position ให้ตรวจ Stop, Trailing, Basket และ State ของ EA ก่อนปล่อยระบบต่อ ไม่รีบเพิ่มออเดอร์ชดเชยเพียงเพราะเห็นว่าช่วงหลุด “พลาดสัญญาณ”

สิ่งที่ไม่ควรทำ

  • ส่ง Password หรือไฟล์ Credential ให้คนอื่นผ่านแชต
  • ปิด Firewall/Antivirus ทั้งระบบแบบถาวร
  • ดาวน์โหลด MT5 จากลิงก์ไม่ทราบแหล่งเพื่อแก้ Connection
  • สร้างบัญชีใหม่ก่อนสำรองข้อมูลบัญชีเดิม
  • ลบ Data Folder โดยยังไม่มี Backup Preset/Profile/Log
  • เปลี่ยนหลายค่าในครั้งเดียวจนไม่รู้ว่าสาเหตุจริงคืออะไร
  • เปิด EA ต่อทันทีโดยไม่ตรวจว่า Login ด้วย Master หรือ Investor

ปัญหา Connection แก้ได้เร็วขึ้นเมื่อแยกเป็น Network, Server และ Credential ตามลำดับ หากต้องติดตั้ง MT5 ใหม่จริง ให้ใช้ไฟล์จากโบรกเกอร์หรือแหล่งทางการและทำตาม คู่มือติดตั้ง MT5

คำเตือนความเสี่ยง: ในช่วงที่ MT5 หลุด ฟังก์ชันของ EA ที่ต้องทำงานใน Terminal อาจหยุด แม้ Stop/Take Profit ที่วางบน Server บางรายการยังคงอยู่ ห้ามสมมติว่าทุกระบบป้องกันยังทำงานครบโดยไม่ตรวจสถานะ
