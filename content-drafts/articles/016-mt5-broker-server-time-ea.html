MT5 Server Time คือเวลาที่ Trade Server ของโบรกเกอร์ใช้ประทับข้อมูลราคาและเหตุการณ์ซื้อขาย ซึ่งอาจไม่ตรงกับเวลาประเทศไทย เวลา UTC หรือเวลาบน Windows/VPS EA ที่มี Session Filter, Daily Reset, News Filter หรือกฎปิดออเดอร์ตามเวลาจึงต้องรู้ว่าโค้ดอ้างอิงนาฬิกาใด

การตั้งช่อง Start Hour เป็น 8 ไม่ได้แปลว่าเริ่ม 08:00 น. ประเทศไทยเสมอไป หาก EA อ่าน TimeCurrent หรือ TimeTradeServer ค่า 8 หมายถึง 08:00 ตามเวลาของ Server/ข้อมูลที่ฟังก์ชันนั้นคืน และ Offset อาจเปลี่ยนเมื่อโบรกเกอร์ปรับ Daylight Saving Time

สารบัญ

  • นาฬิกาใน MT5 มีอะไรบ้าง
  • มีผลต่อ EA ตรงไหน
  • วิธีตรวจ Server Time
  • วิธีแปลงเวลาอย่างปลอดภัย
  • ผลของ DST
  • ผลต่อ Backtest และ News Filter

แยก Server Time, Local Time และ GMT

เวลา ความหมาย
Trade Server Time เวลาที่เกี่ยวกับ Server และ Quote ซึ่ง EA มักใช้อ้างอิง Session
Local Time เวลาของ Windows/VPS ที่รัน Terminal
GMT/UTC เวลามาตรฐานที่ใช้เป็นฐานแปลงเขตเวลา
เวลาไทย UTC+7 และไม่มี DST แต่ไม่ได้แปลว่า Server ของโบรกเกอร์เป็น UTC+7

ใน MQL5 มีฟังก์ชันหลายตัว เช่น TimeCurrent, TimeTradeServer, TimeLocal และ TimeGMT ซึ่งให้ความหมายต่างกัน ผู้พัฒนาต้องระบุว่า Input ของ EA ใช้ฐานใด ผู้ใช้ไม่ควรเดาจากเวลาที่เห็นมุม Windows เท่านั้น

เอกสาร MQL5 ระบุว่า TimeTradeServer เป็นเวลาปัจจุบันของ Trade Server ที่คำนวณใน Client Terminal และขึ้นกับการตั้งเวลาเครื่อง ส่วน TimeCurrent เกี่ยวกับเวลาของ Quote ล่าสุดใน Market Watch ใน Strategy Tester เวลาจะถูกจำลองจากข้อมูลประวัติ

Server Time มีผลต่อ EA อย่างไร

  • Trading Session: กำหนดช่วงอนุญาต Entry เช่น London/New York
  • Daily Reset: นับกำไรขาดทุนต่อวันและ Daily Loss Limit
  • Friday Close: ปิดหรือหยุดเปิดก่อนตลาดสุดสัปดาห์
  • News Filter: เปรียบเทียบเวลา Event กับเวลาที่ EA ใช้
  • Swap/Rollover: พฤติกรรมรอบวันใหม่ของ Server
  • Candle: จุดเริ่มแท่ง D1/H4 อาจต่างตาม Server
  • รายงาน: วันที่ของ Deal และการแบ่งผลลัพธ์รายวัน

EA ที่ไม่ใช้เวลาเลยอาจได้รับผลน้อยกว่า แต่ระบบที่เทรดช่วงสั้นหรือหลีกเลี่ยงข่าวอาจเปลี่ยนพฤติกรรมชัดเจนเมื่อ Offset ผิดหนึ่งชั่วโมง

วิธีดูเวลา Server ของโบรกเกอร์

  1. เปิด Market Watch และกราฟ Symbol ที่มี Tick วิ่ง
  2. ดูเวลาของแท่งล่าสุด/เวลาที่โบรกเกอร์แสดงในแพลตฟอร์ม
  3. เทียบกับ UTC จากแหล่งเวลามาตรฐานในขณะเดียวกัน
  4. คำนวณ Offset เช่น Server = UTC+2
  5. จดวันที่ตรวจ เพราะ Offset อาจเปลี่ยนตามฤดูกาล
  6. ยืนยันกับเอกสารหรือ Support ของโบรกเกอร์ โดยเฉพาะวันเปลี่ยน DST

ควรตรวจในช่วงตลาดเปิดและมี Quote เพราะ TimeCurrent อาจสะท้อน Tick ล่าสุด ไม่ใช่นาฬิกาที่เดินอิสระเมื่อไม่มีราคา หาก EA มี Dashboard เวลา ให้ใช้เป็นข้อมูลช่วยแต่ยืนยันกับ Log/Quote ด้วย

ตัวอย่างการแปลงเป็นเวลาไทย

สมมติ Server เป็น UTC+2 และไทยเป็น UTC+7 ไทยเร็วกว่า Server 5 ชั่วโมง ดังนั้น 09:00 Server เท่ากับ 14:00 ไทย แต่ถ้า Server เปลี่ยนเป็น UTC+3 ระยะต่างจะเหลือ 4 ชั่วโมง และ 09:00 Server เท่ากับ 13:00 ไทย

สูตรทั่วไป:

เวลาไทย = เวลา Server + (7 - Offset ของ Server)

ตัวอย่างนี้ใช้ได้เมื่อรู้ Offset ที่ถูกต้อง ณ วันนั้น อย่าบันทึก “บวก 5 ชั่วโมงตลอดไป” เพราะ DST หรือการเปลี่ยนนโยบาย Server อาจทำให้ผิดในอนาคต

Daylight Saving Time ทำให้ค่าเปลี่ยนอย่างไร

ประเทศไทยไม่มี DST แต่ Server หลายแห่งปรับ Offset ตามเขตเวลายุโรปหรือสหรัฐฯ ช่วงเปลี่ยนฤดูกาล Server อาจขยับหนึ่งชั่วโมง แม้เวลาประเทศไทยไม่เปลี่ยน ผลคือ Session Filter ที่เคยตรงกับตลาดอาจเลื่อนไป

แนวทางจัดการ:

  • จด Offset ปัจจุบันและวันที่เริ่มใช้
  • ตั้ง Reminder ตรวจช่วงเดือนที่มักเปลี่ยน DST
  • อ่านประกาศโบรกเกอร์เรื่อง Trading Hours
  • ทดสอบ News Filter ด้วย Event ที่ทราบเวลา
  • หาก EA มี Auto GMT/DST ให้ตรวจ Log ว่าตรวจได้จริง ไม่เชื่อจากชื่อฟังก์ชันอย่างเดียว
  • เก็บ Preset แยก Summer/Winter เฉพาะเมื่อผู้พัฒนากำหนด

อย่าแก้ Offset ระหว่างมี Position หากค่านั้นมีผลต่อ Exit/Session โดยไม่รู้ผลของ Version ปัจจุบัน ควรสอบถามผู้พัฒนาและทดสอบก่อน

ผลต่อ Backtest และ News Filter

ใน Strategy Tester เวลาถูกจำลองจากข้อมูลประวัติของ Symbol และ Trade Server ที่ข้อมูลนั้นสัมพันธ์อยู่ หากนำ Preset Session จากโบรกเกอร์ A ไปทดสอบข้อมูลของโบรกเกอร์ B เวลาแท่งและ Trading Session อาจไม่ตรง ทำให้จำนวน Trade และผลลัพธ์เปลี่ยน

สำหรับ Economic Calendar ของ MQL5 เอกสารระบุว่าฟังก์ชัน Calendar ใช้ Trade Server Time ดังนั้น EA ที่เรียก Calendar โดยตรงควรประมวลผลเวลาในฐานเดียวกัน แต่ EA บางตัวดึงข้อมูลภายนอกเป็น UTC แล้วแปลงเอง ผู้ใช้ต้องอ่านคู่มือของระบบนั้น

อ่านข้อจำกัดของตัวกรองข่าวได้ที่ EA ทำงานช่วงข่าวและ News Filter ช่วยอะไร และตรวจเงื่อนไขโบรกเกอร์เพิ่มเติมที่ เลือกโบรกเกอร์สำหรับใช้ EA ต้องดูอะไร

เช็กลิสต์ก่อนใช้งาน Session

  • รู้ว่า EA ใช้ Server, Local, GMT หรือ Timezone แบบกำหนดเอง
  • ตรวจ Offset ของ Server ณ วันที่ตั้งค่า
  • แปลงเป็นเวลาไทยด้วยสูตรและทดสอบ Event จริง
  • ตรวจผลเมื่อไม่มี Tick/ตลาดปิด
  • ตรวจวันเปลี่ยน DST และ Trading Holiday
  • Backtest ด้วยข้อมูลและ Timezone ที่สอดคล้องกับ Preset
  • ดู Experts Log ว่า EA โหลด Offset/Session เท่าไร
  • บันทึกค่าในเอกสารระบบ ไม่พึ่งความจำ

คำเตือนความเสี่ยง: เวลา Session หรือ News Filter ที่ผิดอาจทำให้ EA เปิดออเดอร์ในช่วงที่ตั้งใจหลีกเลี่ยง ตัวกรองเวลาไม่สามารถรับประกันว่าจะไม่มี Slippage หรือความผันผวนสูง
