FENIX PRO

คู่มือใช้งาน VPS ผ่าน Android

คู่มือแบบภาพประกอบสำหรับเชื่อมต่อ VPS จากมือถือ Android
ด้วยแอป Windows App ของ Microsoft Corporation บน Google Play

ภาพรวม: Google Play > Windows App > Add > PC > ใส่ IP > Credentials > ตรวจค่า > Save > แตะเข้า VPS
1

โหลดแอป Windows App

เข้า Google Play ค้นหา Windows App ของ Microsoft Corporation แล้วกดติดตั้ง

2

เปิดแอปแล้วกด Add

เมื่อเข้าแอปแล้ว กดปุ่ม + หรือ Add เพื่อเพิ่มการเชื่อมต่อ VPS ใหม่

3

เลือก PC

เลือกเมนู PC สำหรับเชื่อมต่อ VPS ด้วยชื่อเครื่องหรือ IP Address

4

ใส่ IP Address ของ VPS

กรอก IP ที่ได้รับในช่อง PC Name หรือ Hostname or IP Address

5

ตั้งค่า Credentials

เลือก Ask When Required หรือกรอก Username และ Password ตามข้อมูลที่ได้รับ

6

ตรวจสอบค่าแล้วกด Save

ตั้งชื่อ Friendly Name เป็น FENIX PRO VPS, Gateway เป็น No Gateway และเปิด Clipboard แล้วกด Save

เช็กก่อนเริ่มใช้งาน

  • มี IP Address ของ VPS
  • มี Username และ Password
  • อินเทอร์เน็ตมือถือหรือ Wi-Fi เสถียร
  • เลือกเมนู PC ไม่ใช่ Workspace
  • Gateway ตั้งเป็น No Gateway
  • เปิด Clipboard เพื่อใช้งานสะดวกขึ้น
หมายเหตุ: VPS เป็นเครื่องสำหรับเปิดใช้งานโปรแกรม/EA ให้ต่อเนื่อง ควรเก็บ Username และ Password เป็นความลับ และตรวจสอบการเชื่อมต่อก่อนเริ่มใช้งานจริง
