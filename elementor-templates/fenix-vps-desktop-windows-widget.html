คู่มือใช้งาน VPS บน Desktop Windows

คู่มือแบบภาพประกอบสำหรับเชื่อมต่อ VPS จากเครื่องคอมพิวเตอร์ Windows ทำตามทีละขั้นจนเข้าสู่หน้า Desktop ของ VPS

ภาพรวม: Start > Remote Desktop Connection > ใส่ IP > Connect > More choices > Use a different account > กรอก Username/Password > Yes > เข้า VPS
1

ค้นหา Remote Desktop Connection

ที่เครื่อง Windows ให้กด Start แล้วพิมพ์ Remote Desktop Connection เพื่อเปิดโปรแกรมเชื่อมต่อ VPS

2

ใส่ IP Address ของ VPS

นำ IP Address ที่ได้รับจากทีมงานไปกรอกในช่อง Computer แล้วกด Connect

3

เลือก More choices

เมื่อหน้าต่าง Windows Security แสดงขึ้น ให้กด More choices เพื่อเปลี่ยนรูปแบบการเข้าสู่ระบบ

4

เลือก Use a different account

เลือก Use a different account แล้วกรอก Username และ Password ของ VPS ตามข้อมูลที่ได้รับ

5

กด Yes เพื่อยืนยัน Certificate

หากมีหน้าต่างแจ้งเตือน Certificate ให้กด Yes เพื่อดำเนินการเชื่อมต่อ VPS ต่อ

6

เข้าสู่หน้า Desktop ของ VPS

เมื่อเชื่อมต่อสำเร็จ จะเห็นหน้า Desktop ของ Windows VPS และสามารถเปิดใช้งานโปรแกรมได้ทันที

เช็กก่อนเริ่มใช้งาน

  • มี IP Address ของ VPS
  • มี Username และ Password
  • อินเทอร์เน็ตมือถือหรือ Wi-Fi เสถียร
  • เลือกเมนู PC ไม่ใช่ Workspace
  • Gateway ตั้งเป็น No Gateway
  • เปิด Clipboard เพื่อใช้งานสะดวกขึ้น
หมายเหตุ: VPS เป็นเครื่องสำหรับเปิดใช้งานโปรแกรม/EA ให้ต่อเนื่อง ควรเก็บ Username และ Password เป็นความลับ และตรวจสอบการเชื่อมต่อก่อนเริ่มใช้งานจริง
