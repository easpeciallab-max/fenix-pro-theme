ติดตั้งแอป • iPhone / Android • Zaurix-Server

คู่มือติดตั้งแอป MT5 และ Login เข้า MT5

เริ่มตั้งแต่ดาวน์โหลดแอป MetaTrader 5 บน iPhone หรือ Android, เปิดแอป, ค้นหาโบรกเกอร์ Zaurix, เลือก Server ให้ถูกต้อง, ใส่ Login และ Password ที่ได้รับจากบัญชี MT5 แล้วเข้าสู่ระบบให้เรียบร้อย

สรุปขั้นตอนเร็ว

  1. 1ติดตั้งแอป MetaTrader 5 จาก App Store หรือ Google Play
  2. 2เปิดแอป MT5 แล้วเข้าเมนู New Account / บัญชีใหม่
  3. 3ค้นหาโบรกเกอร์ด้วยคำว่า zaurix
  4. 4เลือก Zaurix Ltd.
  5. 5ตรวจ Server เป็น Zaurix-Server
  6. 6ใส่ Login และ Password แล้วกดลงชื่อเข้าใช้
สำคัญ: ดาวน์โหลดแอปชื่อ MetaTrader 5 เท่านั้น และ Login MT5 ไม่ใช่อีเมลสมัครเว็บ
ติดตั้ง iPhoneติดตั้ง Androidเปิด MT5ค้นหา Zaurixเลือกโบรกเกอร์ใส่ Loginตรวจสอบแก้ปัญหา
Step 01

ติดตั้งแอป MetaTrader 5

iPhone / iPad

ติดตั้งผ่าน App Store

  1. เปิดแอป App Store บน iPhone หรือ iPad
  2. กดช่องค้นหา แล้วพิมพ์ MetaTrader 5 หรือ MT5
  3. เลือกแอปชื่อ MetaTrader 5
  4. กด รับ / Get แล้วรอติดตั้งให้เสร็จ
  5. เมื่อติดตั้งเสร็จ กด Open / เปิด
DOWNLOAD ติดตั้งแล้ว ไปขั้นตอน Login
เช็กชื่อแอปให้เป็น MetaTrader 5 ก่อนกดติดตั้ง เพื่อป้องกันโหลดผิดแอป

Android

ติดตั้งผ่าน Google Play

  1. เปิดแอป Google Play Store
  2. กดช่องค้นหา แล้วพิมพ์ MetaTrader 5 หรือ MT5
  3. เลือกแอปชื่อ MetaTrader 5
  4. กด Install / ติดตั้ง แล้วรอจนเสร็จ
  5. เมื่อติดตั้งเสร็จ กด Open / เปิด
DOWNLOAD ติดตั้งแล้ว ไปขั้นตอน Login
ถ้าค้นหาแล้วไม่เจอ ให้พิมพ์เต็มว่า MetaTrader 5 และตรวจอินเทอร์เน็ต/บัญชี Google Play
Step 02

เปิดแอป MT5 แล้วเข้าเมนูเพิ่มบัญชี

หลังเปิดแอป MetaTrader 5 ให้ไปที่เมนูตั้งค่าของแอป แล้วเลือกเพิ่มบัญชีใหม่ เช่น New Account / บัญชีใหม่ / Add Account ตามภาษาที่แอปแสดง

  • ถ้าเพิ่งติดตั้งใหม่ แอปอาจพาเข้าหน้าเลือกโบรกเกอร์อัตโนมัติ
  • ถ้ามีบัญชีเดิมอยู่แล้ว ให้เข้าเมนู Settings / ตั้งค่า ก่อน
  • มองหาปุ่ม New Account หรือเครื่องหมาย + เพื่อเพิ่มบัญชี
ถ้าหน้าจอเป็นภาษาไทย คำว่า Broker จะเห็นเป็น “โบรกเกอร์” เหมือนในภาพตัวอย่าง
Step 03

พิมพ์ค้นหาคำว่า zaurix

ที่ช่องค้นหา ให้พิมพ์คำว่า zaurix ตัวพิมพ์เล็กหรือใหญ่ก็ได้ เพื่อให้ระบบแสดงรายชื่อโบรกเกอร์ของ Zaurix

  • แตะช่อง “ใส่ชื่อบริษัทหรือเซิร์ฟเวอร์”
  • พิมพ์ zaurix
  • รอให้รายการ Zaurix Ltd. แสดงขึ้นมา
ก่อนพิมพ์: แตะช่องค้นหา
หลังพิมพ์: zaurix
Step 04

เลือกโบรกเกอร์ Zaurix Ltd.

เมื่อค้นหาแล้ว ให้แตะรายการ Zaurix Ltd. ที่มีโลโก้สีแดงของ Zaurix ตามภาพ

  • เลือกชื่อ Zaurix Ltd.
  • อย่าเลือก MetaQuotes Ltd. ถ้าต้องการล็อกอินบัญชี Zaurix
  • หลังแตะแล้ว ระบบจะพาไปหน้ากรอก Login และ Password
แตะตรง Zaurix Ltd.
Step 05

กรอก Login และ Password ของ MT5

ในหน้าลงชื่อเข้าใช้ ให้ตรวจ Server เป็น Zaurix-Server จากนั้นกรอกเลข Login และรหัสผ่าน MT5 ที่ได้รับหลังเปิดบัญชี

  • ช่องเซิร์ฟเวอร์ต้องเป็น Zaurix-Server
  • ช่องชื่อการลงชื่อเข้าใช้ ให้ใส่เลขบัญชี MT5 หรือ Login
  • ช่องรหัสผ่าน ให้ใส่ Password สำหรับเทรด
  • เปิดบันทึกรหัสผ่านไว้ได้ ถ้าเป็นเครื่องส่วนตัว
  • เมื่อกรอกครบ ปุ่มลงชื่อเข้าใช้จะกดได้
ถ้าปุ่มลงชื่อเข้าใช้ยังเป็นสีเทา แปลว่ายังกรอก Login หรือ Password ไม่ครบ
Server ต้องเป็น Zaurix-Server
กรอก Login และ Password
Step 06

กดลงชื่อเข้าใช้ แล้วเช็กว่าล็อกอินสำเร็จ

หลังกรอกครบ ให้กดปุ่มลงชื่อเข้าใช้ด้านล่าง ถ้าข้อมูลถูกต้อง แอปจะเข้าสู่บัญชี MT5 และจะแสดงข้อมูลราคา/บัญชีเทรด

  • กดปุ่มลงชื่อเข้าใช้
  • รอสักครู่ให้ระบบเชื่อมต่อ Server
  • ถ้าสำเร็จ จะเห็นบัญชีอยู่ในแอป MT5
  • ถ้าขึ้น Invalid account ให้ตรวจ Login, Password และ Server อีกครั้ง
ปุ่ม Login จะกดได้เมื่อกรอกครบ

ถ้า Login ไม่ได้ ให้เช็ก 6 จุดนี้ก่อน

1. Server ผิดต้องเลือกหรือแสดงเป็น Zaurix-Server เท่านั้น
2. ใส่ Login ผิดLogin คือเลขบัญชี MT5 ไม่ใช่อีเมลสมัครเว็บ
3. รหัสผิดประเภทใช้รหัสเทรดจริง ไม่ใช่ Investor Password
4. คัดลอกมีเว้นวรรคลองลบแล้วพิมพ์ใหม่ หรือคัดลอกใหม่แบบไม่มีช่องว่าง
5. อินเทอร์เน็ตไม่เสถียรสลับ Wi‑Fi/4G/5G แล้วลองใหม่
6. บัญชียังไม่พร้อมถ้าเพิ่งเปิดบัญชี ให้รอระบบออก User/Pass หรือแจ้งแอดมินตรวจสอบ
หมายเหตุ: คู่มือนี้ใช้ภาพจริงจากหน้าจอ MT5 บน iPhone ภาษาไทย ลำดับเมนูอาจต่างเล็กน้อยตามเวอร์ชันแอป แต่หลักสำคัญคือดาวน์โหลด MetaTrader 5 ให้ถูกแอป เลือก Zaurix Ltd. และ Server เป็น Zaurix-Server
