FENIX PRO

คู่มือติดตั้ง EA FENIX PRO บน MT5

คู่มือแบบภาพประกอบสำหรับ Windows ทำตามทีละขั้น ตั้งแต่เปิดโฟลเดอร์ วางไฟล์ EA จนถึงเปิด Algo Trading และตรวจค่า Inputs

ภาพรวม: File > Open Data Folder > MQL5 > Experts > วางไฟล์ Fenix Pro > กลับไป MT5 > ลาก EA ลงกราฟ > ติ๊ก Allow Algo Trading > ตรวจ Inputs > OK
1

เปิดโฟลเดอร์ข้อมูลของ MT5

ที่โปรแกรม MetaTrader 5 คลิกเมนู File แล้วเลือก Open Data Folder เพื่อเข้าโฟลเดอร์เก็บไฟล์ของ MT5 บัญชีนี้โดยตรง

2

วางไฟล์ Fenix Pro ในโฟลเดอร์ Experts

เมื่อหน้าต่างโฟลเดอร์เปิดขึ้น ให้เข้า MQL5 > Experts แล้วนำไฟล์ Fenix Pro ไปวางไว้ในโฟลเดอร์นี้

3

กลับมา MT5 แล้วหา EA ใน Navigator

กลับมาที่ MT5 ดูฝั่งซ้ายใน Navigator > Expert Advisors ถ้ายังไม่เห็นชื่อ Fenix Pro ให้ปิดเปิด MT5 ใหม่ หรือคลิกขวาแล้ว Refresh

4

ลาก EA ไปวางบนกราฟที่ต้องการ

เปิดกราฟทองหรือคู่เงินที่ต้องใช้ เช่น XAUUSD.c และเลือก Timeframe ตามคำแนะนำ เช่น M1 จากนั้นลาก Fenix Pro จาก Navigator ไปวางบนกราฟ

5

เปิดสิทธิ์ให้ EA ทำงาน

ในหน้าต่างตั้งค่า EA ที่แท็บ Common ให้ติ๊ก Allow Algo Trading และควรเช็กปุ่ม Algo Trading ด้านบนของ MT5 ให้เปิดอยู่ด้วย

6

ตรวจค่า Inputs แล้วกด OK

เข้าแท็บ Inputs ตรวจค่าตาม preset หรือกด Load ถ้ามีไฟล์ .set จากทีมงาน จากนั้นกด OK เพื่อยืนยันให้ EA ติดบนกราฟ

เช็กก่อนใช้งานจริง

  • เห็นชื่อ Fenix Pro มุมขวาบนของกราฟ
  • ปุ่ม Algo Trading เปิดอยู่
  • เลือก Symbol และ Timeframe ถูกต้อง
  • Lot และความเสี่ยงเหมาะกับเงินทุน
  • อินเทอร์เน็ตและบัญชีเทรดเชื่อมต่ออยู่
  • ถ้ามีไฟล์ preset ให้ Load ก่อนกด OK
หมายเหตุ: EA เป็นเครื่องมือช่วยเทรด ไม่รับประกันผลกำไร ควรทดสอบและตั้งค่าความเสี่ยงให้เหมาะกับบัญชีของผู้ใช้งาน
