# FENIX PRO EA - Elementor Starter

ไฟล์นี้เป็น starter template สำหรับทำหน้าแรกด้วย Elementor โดยยึดเลเอาต์และโทนจากธีม FENIX PRO EA ที่ทำไว้แล้ว

## ไฟล์

- `fenix-pro-ea-home-starter.json` - Elementor page template สำหรับ import

## วิธีใช้

1. เข้า WordPress Admin
2. ไปที่ Templates > Saved Templates
3. กด Import Templates
4. เลือกไฟล์ `fenix-pro-ea-home-starter.json`
5. สร้างหน้าใหม่ เช่น `Home Elementor Draft`
6. ตั้ง Page Template เป็น `FENIX - Elementor Full Width`
7. กด Edit with Elementor
8. กดไอคอน Library แล้วแทรก template `FENIX PRO EA - Home Starter`

## สิ่งที่ควรแก้หลัง import

- เปลี่ยนลิงก์ปุ่ม LINE จาก `#` เป็นลิงก์ LINE OA จริง
- ใส่รูป Backtest / Forward Test จริงใน section Evidence
- ปรับข้อความ SEO หลักให้ตรงกับ positioning ล่าสุด
- เช็ก mobile spacing หลังแก้ข้อความจริง

หมายเหตุ: template นี้ตั้งใจทำเป็นจุดเริ่มต้นเร็ว ไม่ใช่หน้า production สุดท้าย ให้ใช้ Elementor จูนต่อได้เต็มที่
