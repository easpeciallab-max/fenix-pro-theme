คู่มือใช้งาน VPS ผ่าน iPhone iOS

คู่มือแบบภาพประกอบสำหรับเชื่อมต่อ VPS จาก iPhone ด้วยแอป Windows App Mobile ของ Microsoft Corporation

ภาพรวม: App Store > Windows App Mobile > Add > PC > ใส่ IP > Credentials > ตรวจค่า > Save > แตะเข้า VPS
1

โหลดแอป Windows App Mobile

เข้า App Store ค้นหา Windows App Mobile ของ Microsoft Corporation แล้วกดดาวน์โหลดหรือเปิดแอป

2

เปิดแอปแล้วกด Add

เมื่อเข้าแอปแล้ว ให้กดปุ่ม + หรือ Add เพื่อเพิ่มการเชื่อมต่อ VPS ใหม่

3

เลือก PC

เลือกเมนู PC เพื่อเชื่อมต่อ VPS ด้วยชื่อเครื่องหรือ IP Address

4

ใส่ IP Address ของ VPS

แตะช่อง PC Name แล้วกรอก IP Address ของ VPS ที่ได้รับในช่อง Hostname or IP Address

5

ตั้งค่า Credentials

เลือก Ask When Required หรือกรอก Username และ Password ตามข้อมูลที่ได้รับ

6

ตรวจสอบค่าแล้วกด Save

ตรวจค่า Friendly Name, Gateway และ Clipboard ให้เรียบร้อย จากนั้นกด Save

เช็กก่อนเริ่มใช้งาน

  • มี IP Address ของ VPS
  • มี Username และ Password
  • อินเทอร์เน็ตมือถือหรือ Wi-Fi เสถียร
  • เลือกเมนู PC ไม่ใช่ Workspace
  • Gateway ตั้งเป็น No Gateway
  • เปิด Clipboard เพื่อใช้งานสะดวกขึ้น
หมายเหตุ: VPS เป็นเครื่องสำหรับเปิดใช้งานโปรแกรม/EA ให้ต่อเนื่อง ควรเก็บ Username และ Password เป็นความลับ และตรวจสอบการเชื่อมต่อก่อนเริ่มใช้งานจริง
